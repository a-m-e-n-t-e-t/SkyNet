## Описание

Parylene C, газовая фаза, конформное покрытие — вакуумное осаждение полимера (процесс Горхэма, VDP): сублимация циклического димера дихлор[2.2]парациклофана → пиролиз при 450–700 °C и 0,01–1,0 Torr до мономера-радикала пара-ксилилена (100 % мономера без побочных продуктов) → полимеризация на детали при комнатной температуре в камере 1–100 мТорр. Для Parylene C хлор-арильная связь рвётся при 680 °C — окно пиролиза строго контролируется; при диссоциации Cl образуется HCl (защита насосов — холодные ловушки). Свойства покрытия: конформное, беспористое (pinhole-free) от >1,4 нм; скорость осаждения >1 нм/с (>3,6 мкм/ч); диэлектрическая постоянная 3,05–3,2; электрическая прочность 5–6 кВ/mil (~197–236 кВ/мм); Tпл 270 °C; барьер влаги 0,6 г·mil/(100 дюйм²·24 ч). Биосовместимость: «стабилен и принят в биологических тканях, одобрен FDA для ряда медицинских применений; самое биосовместимое покрытие для стентов, дефибрилляторов, кардиостимуляторов» (Wikipedia); современные исследования: Parylene C на титановых имплантах (Micromachines 2025), глазные импланты (2025). Применения: конформное покрытие PCB, влагозащита сенсоров (авто/космос/оборона), имплантируемые устройства, снижение трения катетеров/игл/MEMS, подложки ультратонких гибких плат. В ИИ-проекте — влагозащитный конформный слой электроники «кожи».
