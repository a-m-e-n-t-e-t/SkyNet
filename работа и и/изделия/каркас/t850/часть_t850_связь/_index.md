# Часть: часть_t850_связь

## Описание

Связевой модуль T-850 (канал Skynet-подобной спутниковой линии) — двусторонний короткобurstовый спутниковый трансивер L-диапазона. Референсное исполнение — Iridium 9602 SBD: настоящий спутниковый модем для встроенных применений, передача пакетов до 340 байт, потребление ≤0,8 Вт при передаче, диапазон −40…+85 °C. Габариты 41×45×13 мм и масса 0,030 кг — паспортные данные Iridium 9602 (разработчик: Iridium Communications). Материал — al_6061-t6 (экранирующий корпус радиомодуля).

Родитель: `izdelie_SkyNet-T850` (подсистема: система_связи).
