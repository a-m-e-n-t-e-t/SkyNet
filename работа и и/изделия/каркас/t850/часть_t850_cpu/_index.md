# Часть: часть_t850_cpu

## Описание

Нейросетевой процессор T-850 (второе поколение) — компактный вычислительный модуль с нейроускорителем. Референсное исполнение — COM Express Compact по стандарту PICMG COM.0: типоразмер 95×95 мм, предназначен для мобильных и стационарных встроенных систем, поддержка до 32 ГБ LPDDR4. Габариты 95×95×16 мм — footprint PICMG Compact + теплокрышка; масса 0,13 кг — типовая. Материал — al_6061-t6 (крышка/корпус).

Родитель: `izdelie_SkyNet-T850` (подсистема: вычислительная).
