# Часть: часть_t850_навигация

## Описание

Навигационный блок T-850 — усовершенствованный IMU следующего поколения с расширенным диапазоном угловых скоростей и GNSS-интеграцией. Референсное исполнение — Honeywell HG4930: высокодинамичный тактический MEMS IMU (гироскопы ±400 °/с, выходной поток данных 100 Гц–1000 Гц, встроенный процессор навигации). Габариты 86×79×40 мм, масса ~1,0 кг — паспортные данные HG4930; корпус — литой алюминий с виброизоляцией. Материал — al_6061-t6 (корпус модуля).

Родитель: `izdelie_SkyNet-T850` (подсистема: навигация).
