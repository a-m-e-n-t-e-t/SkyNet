# Часть: часть_hk_tank_двигатель

## Описание

Газотурбинный двигатель AGT1500 (Honeywell/Avco-Lycoming) — 1500 л.с., двухвальный осецентробежный турбокомпрессор с рекуператором. Аналог энергоблока HKTank: габариты и масса по datasheet Honeywell (1.6×1.02×0.71 м, 1134 кг).

## Принцип работы

Двухвальная газовая турбина с рекуперативным теплообменником: воздух → компрессор → рекуператор → камера сгорания → турбины (HP+LP) → выхлоп. Топливо — JP-8/дизель, расход ~3 L/км на 68-тонном шасси.
