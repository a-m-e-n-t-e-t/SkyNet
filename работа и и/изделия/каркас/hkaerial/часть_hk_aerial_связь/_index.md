# Часть: часть_hk_aerial_связь

## Описание

Радиомодуль datalink БПЛА (референс: Doodle Labs Helix Mesh Rider, 46.9×35×20.7 мм, 41 г, Blue UAS-совместимый): многодиапазонный mesh-радиомодуль военного класса; узел связи HK Aerial — такой модуль с коммутацией разнесённых антенн в алюминиевом экране.

## Принцип работы

Self-healing mesh-протокол ретранслирует трафик через соседние узлы сети; адаптивный выбор частотного канала снижает уязвимость к глушению; два MMCX-выхода работают на разнесённые антенны для устойчивого канала при маневрировании.
