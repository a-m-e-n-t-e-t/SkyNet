# Часть: часть_cameron_рука_левая (×2)
## Описание

Модуль приводной руки (плечо/предплечье, подтип servo_arm_small) терминатора TOK715 — Cameron Phillips из «Terminator: The Sarah Connor Chronicles» (перепрограммированная терминаторша, отправленная из 2027 года для защиты Джона и Сары Коннор). Cameron — продвинутая модель: эндоскелет из колтана (термостойкий сплав, более совершенный, чем титановый T-600), поверх — живая ткань для полного имитационного проникновения; компактный женский каркас требует лёгких приводов суставов руки. Инженерный референс — серводействители с волновой передачей (Harmonic Drive): стандарт для верхних конечностей гуманоидов и коллаборативных манипуляторов (обзор Wang et al., 2021: коммерческие манипуляторы применяют волновую передачу ради высокого передаточного отношения, точности и малого шума; harmonic-приводы — самый распространённый тип суставов верхних конечностей гуманоидов). Рука не несёт вес тела, поэтому удельный момент ниже, чем у ног (~4–8 Н·м/кг): для модуля 5.0 кг это оценка ~20–40 Н·м в плечевом/локтевом суставе.

Родитель: `izdelie_SkyNet-Cameron` (подсистема: приводная_система).

## Принцип работы

Суставной привод с волновой передачей: электродвигатель через гибкое зубчатое колесо (Harmonic Drive-принцип) передаёт момент на звено руки — эллиптический генератор волн деформирует гибкое колесо, зацепление идёт в двух противоположных зонах, что даёт большое передаточное отношение одной ступенью и практически нулевой люфт — критично для точной жестикуляции и манипуляций. Референс конфигурации — гуманоид ARMAR-4 (KIT, 63 DoF): приводные единицы объединяют двигатель, волновую передачу, датчики положения и момента в одном суставном модуле. Тепловыделение привода (~1 Вт покоя) отводится корпусом к эндоскелету.
