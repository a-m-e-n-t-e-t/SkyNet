# Часть: часть_cameron_эндоскелет

## Описание

Компактный женский эндоскелет терминатора TOK715 — Cameron Phillips из «Terminator: The Sarah Connor Chronicles» (перепрограммированная терминаторша из 2027 года, защита Джона и Сары Коннор). Несущая рама малого габарита под имитацию женского телосложения: по канону TSCC эндоскелеты этой серии выполнены из колтана — термостойкого сплава, более совершенного, чем титановый эндоскелет T-600; поверх эндоскелета — живая ткань для полного имитационного проникновения. Масса 35 кг (53.8 % изделия — компактный каркас класса ~65 кг). Габариты торс-модуля получены масштабированием от торса T-600 (700×500×250 мм @ 150 кг) по кубическому корню массового отношения (35/150)^(1/3) ≈ 0.616 → 430×310×150 мм; проверка: 150 × 0.616³ = 35.0 кг.

Родитель: `izdelie_SkyNet-Cameron` (подсистема: каркас).

## Принцип работы

Лёгкая несущая рама: тонкостенные титановые профили с рёбрами жёсткости воспринимают боевые нагрузки при минимуме массы (35 кг для машины класса ~65 кг) — компактный каркас даёт преимущество в скорости реакции и незаметности. Суставные узлы — интерфейсы под компактные волновые приводы (см. модуль ноги); полость торса вмещает топливную ячейку и терморегуляцию. Термостойкость (канон: колтан) снижает уязвимость к нагреву по сравнению с титановым T-600.
