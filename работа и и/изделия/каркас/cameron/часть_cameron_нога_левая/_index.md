# Часть: часть_cameron_нога_левая (×2)
## Описание

Модуль приводной ноги (сервопривод бедра/колена) терминатора TOK715 — Cameron Phillips из «Terminator: The Sarah Connor Chronicles» (перепрограммированная терминаторша, отправленная из 2027 года для защиты Джона и Сары Коннор). Cameron — продвинутая модель: эндоскелет из колтана (термостойкий сплав, более совершенный, чем титановый T-600), поверх — живая ткань для полного имитационного проникновения; компактный женский каркас требует лёгких высокомоментных приводов суставов. Инженерный референс — компактные серводействторы Harmonic Drive (серии RH/RHS, FHA-mini), рассчитанные на гуманоидные платформы: для ноги гуманоида требуется удельный момент свыше 10 Н·м/кг (Firgelli) — для модуля 4.5 кг это минимум ~45 Н·м в бедренном/коленном суставе.

Родитель: `izdelie_SkyNet-Cameron` (подсистема: приводная_система).

## Принцип работы

Суставный привод с волновой передачей: электродвигатель через гибкое зубчатое колесо (Harmonic Drive-принцип) передаёт момент на звено ноги — эллиптический генератор волн деформирует гибкое колесо, зацепление происходит в двух противоположных зонах, что даёт большое передаточное отношение в одной ступени и практически нулевой люфт — критично для точной гуманоидной походки и бега. Удельный момент >10 Н·м/кг (требование к гуманоидным ногам) реализуется компактным низкооборотным высокомоментным приводом; тепловыделение привода (~1 Вт покоя) отводится корпусом к эндоскелету.
