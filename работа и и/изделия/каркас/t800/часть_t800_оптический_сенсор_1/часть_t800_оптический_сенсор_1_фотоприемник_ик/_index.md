# Часть: часть_t800_оптический_сенсор_1_фотоприемник_ик

## Описание

ИК-фотоприёмник глазного модуля T-800 — SWIR-фотодиод на p-n гетероструктуре InGaAsSb (ширина запрещённой зоны 0.53 эВ, граница спектрального отклика ≈ 2.34 мкм; эпитаксия MOCVD — металлорганический вариант CVD). Обеспечивает канонический ИК-канал модуля (canon: диапазон 'visible + IR', night_vision: true — ночной режим T-800). Кристалл 3×3×0.5 мм в корпусе TO с ИК-окном кварц Ø10 и термоэлектрическим стабилизатором Bi2Te3 (модуль Пельтье 8×8×4 мм). Масса 30 г (15 % массы модуля), включая армированный жгут.

Родитель: `часть_t800_оптический_сенсор_1` (подсистема: сенсоры).

## Принцип работы

ИК-излучение сцены (0.9–2.3 мкм ближний/коротковолновый ИК) проходит через ИК-окно и поглощается в эпитаксиальном слое InGaAsSb; фотогенерированные носители разделяются p-n переходом гетероструктуры (высокая responsivity p-n фотодетектора e-SWIR — Benker et al., Micromachines 2024; InGaAsSb p–n photodetector for extended SWIR — ResearchGate 2021). ТЭ-стабилизатор Bi2Te3 держит температуру кристалла для стабильного отношения сигнал/шум при ночном режиме. Сигнал ИК-канала смешивается с видеоматрицей — canon «расширенный видимый диапазон + ИК» (T-800 видит в темноте).

## Состав

Атомарная часть (неделимый, уровень 3): фотодиод на монолитной гетероструктуре в герметичном корпусе — атомарность по чек-листу F34 (полупроводниковый прибор); полевая разборка отсутствует.
