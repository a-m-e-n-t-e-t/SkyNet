# Часть: часть_t1000_миметический_полисплав

## Описание

Полная корпус-масса жидкометаллического терминатора Skynet T-1000 Advanced
Prototype (mimetic polyalloy) — единственная часть изделия `izdelie_SkyNet-T1000`,
составляющая 100% его массы (120 кг по канону модели). Первый терминатор во
франшизе без эндоскелета: целиком состоит из жидкого металла, деплоится в прошлое
в виде металлической сферы и принимает default humanoid shape — полицейского из
«Terminator 2: Judgment Day» (1991) в исполнении Robert Patrick. Морфирует в любую
форму сходного объёма, которого касается (руки — в крюки и ножи; сложные механизмы
с движущимися частями и объекты заметно меньшего объёма — невозможны), может
расплющиваться тонким слоем по полу, имитируя его текстуру для засады.

Родитель: `izdelie_SkyNet-T1000` (подсистема: вычислительная).

## Принцип работы

Каждая наночастица — self-similar часть единого целого: распределённый liquid
molecular brain (hivemind миллиардов частиц) даёт продвинутое рассуждение,
самоосознание и автономность от Skynet (по канону — причина снятия серии с
производства). По novelization фильма — «наноморф»: сканирует молекулярную
структуру касанием и визуально имитирует её. Разрушенные фрагменты при сближении
сливаются с основной массой (самовосстановление); может формировать независимые
инструменты — копьё, трекинг-устройство. Способен чинить других терминаторов,
вливая в них жидкий металл (Genisys). Уязвимости: длительная заморозка (LN2,
−196 °C) даёт сбой морфинга, +1500 °C (расплав стали) — деструкция, химически
агрессивные реагенты (Genisys). Range 14 km. Может формировать лезвия, копировать
людей, проходить через щели.

## Состав

Промежуточная часть (уровень 2). Дочерних частей нет — вся вычислительная
подсистема T-1000 реализована в самой полисплавной массе.
