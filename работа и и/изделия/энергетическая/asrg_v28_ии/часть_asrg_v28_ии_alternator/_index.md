# Часть (ИИ-улучшенная): часть_asrg_v28_ии_alternator

## Описание

Линейный альтернатор ASRG v28 — возвратно-поступательное движение поршня с якорем наводит ЭДС в катушках статора. Ключевая ИИ-замена: магниты NdFeB → SmCo — NdFeB теряет магнитные свойства уже при ~80 °C, тогда как SmCo-магниты термостабильны до 320–350 °C (канон material_smco: TC-марки EEC 2:17-TC с обратимым α(Br) от −0,030 до +0,012 %/K, стабильность поля до 320 °C, (BH)max до 159 кДж/м³; коррозионная стойкость без никелевого покрытия). Ограничение масштаба: Ø статора ≤ 200 мм (литейный предел). Выработка секции: 420 Вт DC (пересчёт бюджета). Против предка (часть_asrg_alternator: обмотки copper) — магнитная система изменена, обмотки Cu сохранены (канон material_copper).
