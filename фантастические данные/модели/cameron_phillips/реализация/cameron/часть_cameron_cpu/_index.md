# Часть: часть_cameron_cpu

## Описание

Вычислительный модуль (CPU) робота SkyNet-Cameron — референс Raspberry Pi Compute Module 4: SoC Broadcom BCM2711 (4 ядра Arm Cortex-A72 1.5 ГГц), до 8 ГБ LPDDR4, eMMC-память, Wi-Fi/BT, форм-фактор 55×40×4.7 мм с разъёмом SODIMM-совместимого типа — «compact form factor with 55 mm x 40 mm x 4.7 mm dimensions for deeply embedded applications» (Mouser/RTL). Модуль несёт логику управления походкой и интерфейсами каркаса.

Масса 0.3 кг — канон декомпозиции; реальная масса модуля CM4 — порядка десятков грамм: каноническое значение агрегирует модуль, несущую плату и радиатор в одну вычислительную сборку. Габарит 55×40×4.7 мм — паспортный размер CM4, не дефолтный fallback.

Родитель: `izdelie_SkyNet-Cameron` (подсистема: вычислительная).
