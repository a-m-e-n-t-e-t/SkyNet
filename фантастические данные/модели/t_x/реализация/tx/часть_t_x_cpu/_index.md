# Часть: часть_t_x_cpu

## Описание

Нейросетевой центральный процессор T-X — модуль высокопроизводительных вычислений с ускорителем вывода нейросети. Референсное исполнение — вычислительный модуль COM Express Basic по стандарту PICMG COM.0: типоразмер 125×95 мм (максимальный из серийных Computer-on-Module), до 32 ГБ памяти, TDP 40–65 Вт. Габариты 125×95×20 мм — footprint PICMG + теплораспределительная крышка; масса 0,19 кг — типовая для модуля Basic с крышкой. Материал — al_6061-t6 (теплосъёмная крышка модуля).

Родитель: `izdelie_SkyNet-TX` (подсистема: вычислительная).
