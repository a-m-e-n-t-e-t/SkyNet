# SkyNet-T20

## Описание

T-20 — ранний гусеничный дрон; лёгкое вооружение; малая автономия.

По верифицированным данным Fandom (проверено 2026-11-06, страница получена через web-архив): T-20 — «Advanced Utility T-20 Server Robot» (Cyberdyne System Series 20 Utility Service Unit), прозвище «Technobot» — **колёсный сервисный робот** Skynet, НЕ боевая единица. Спроектирован для продвинутых сервисных задач на серверных фермах Skynet, объектах TDE (временного смещения) и ленд-поездах (Land-Trains); **не имеет боевого программирования**. Исходная модель — для бытовых и обслуживающих задач; предполагались адаптируемые варианты для сельского хозяйства и горных работ на том же базовом шасси. Антропоморфная форма со специализированными руками по десять пальцев на каждой — точная работа с инструментами; расширенный доступ к техническим файлам. Изначальная модель Cyberdyne, с Судного дня конструктивно не менялась — только обновлялись процессоры (текущая версия 33.1). Ведёт себя кооперативно с людьми поблизости (принимает их за сотрудников или инфильтраторов), но действия во вред Skynet мгновенно вызывают тревогу. В романе Terminator 3: Rise of the Machines два T-20 эскортируют T-X к Континуум-транспортеру. Появления: роман T3: Rise of the Machines, The Terminator RPG (Mission Report 002: Rush Hour Express), The T2 RPG Sourcebook. РАСХОЖДЕНИЕ С ФАЙЛОМ: по канону T-20 — колесный сервисный робот без оружия, а не гусеничный боевой дрон с лёгким вооружением; классификация (наземный_гусеничный), ТТХ второго блока (плазма-пушки, танк с 2 башнями) и функции патруль/охрана оставлены до отдельной реклассификации (F13/F33-таксономия), как для T-300 (#705)/T-950 (#708)/T-400 (#707). Атрибуция TSCC (work_007) источником не подтверждается — канонные появления: роман T3 и RPG-материалы.
