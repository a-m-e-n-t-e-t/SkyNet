# Часть: часть_hk_aerial_навигация

## Описание

Инерциально-спутниковый навигационный модуль БПЛА-класса (референс: VectorNav VN-300 Dual GNSS/INS, MIL-STD-пакет 56×56×23 мм, 125 г): двухантенный GNSS-приёмник с MEMS-инерциальным блоком в армированном алюминиевом корпусе; узел навигации HK Aerial строится вокруг такого модуля.

## Принцип работы

Два разнесённых GNSS-приёмника разрешают курс по базовой линии, MEMS-гироскопы и акселерометры сшивают навигационное решение между обновлениями GNSS; готовое решение (координаты, скорость, кватернион ориентации) выдаётся в автопилот по UART/SPI.
