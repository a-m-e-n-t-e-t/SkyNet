# Sandbox archive (v9.20–v9.31)

Эта директория содержит скрипты, которые **выполнялись вручную из Z.ai sandbox**
в период v9.20 → v9.31 (до появления транзакционной инфраструктуры v9.37).

## История

До v9.37 cron-агент делал правки файлов через inline `sed`/`python -c`, без
единых инструментов. Многие миграции выполнялись one-shot скриптами прямо из
sandbox, которые **не отслеживались в git** и пропадали при рециклинге
sandbox.

v9.39.2 (этот коммит) — историческая архивация: 30 файлов перенесены из
`/home/z/my-project/scripts/` (вне репозитория) в
`scripts/_archive_oneoff/sandbox/` (в репозитории). Они отработали своё и
больше не нужны, но представляют историческую ценность:

репозитория от версии к версии. Каждый патч — точечное исправление
схемы/данных/генераторов.
