# 07. Алгоритм заполнения карточки исследовательской группы (§10.2, схема v11.0)

> Карточка группы: `реальные данные/исследовательские_группы/<id>.md` (пример: `nasa_glenn.md`). Шаблон: `шаблоны/исследовательской_группы.md` (в `шаблоны/`).
> На группу ссылаются материалы через поле `исследовательская_группа` (F7 = 1.0 — обязательное поле материала).

## Предусловия

1. Дедупликация: `реальные данные/исследовательские_группы/_список_исследовательских_групп.md`.
2. Группа нужна как цель ссылки из материалов (F7) — проверить, какие материалы будут на неё ссылаться.

## Этап 1. Данные группы

1. `id: group_<имя>` (пример: `group_nasa_glenn`); `тип: исследовательская_группа` (фиксировано).
2. `название` — полное название; `локация` — страна/город.
3. `специализация` — список направлений (аналог «функций» у моделей): покрытия, источники_энергии, керамика...
4. (опц.) `сайт_url`, `год_основания`, `ключевые_проекты` — список названий проектов/разработок.
5. Метаданные v11.0: `реальность: реальный`; `доступность: промышленный` (или по факту); `источник {тип, url, проверено}`; `создано/обновлено`.

## Этап 2. Тело карточки

1. `## Описание` — кто такие, чем известны, ключевые разработки.
2. `## Локация` — страна, город, площадки (повествование без повторения строковых значений).
3. `## Специализация` — раскрытие каждого направления: что именно делает группа в нём.
4. `## Связанные материалы и изделия` — ТОЛЬКО обратные ссылки: материалы с полем `исследовательская_группа` = id этой группы (F7); изделия при наличии.
5. `## Источники`, `## Чек-лист`.

ВАЖНО (v11.0): счётчик «изделий_в_группе_счёт» в карточке УДАЛЁН — вычисляемое значение ведёт CI в сводном индексе. Хранить вычисляемое в карточке = гарантированное расхождение после каждой правки.

## Этап 3. Самопроверка

- [ ] `id` совпадает со ссылками `исследовательская_группа` в карточках материалов.
- [ ] Данные не дублируются: название/локация/специализация — в front matter; тело — повествование (F26).
- [ ] Обратные ссылки указывают на существующие карточки материалов/изделий.
- [ ] Вычисляемых счётчиков в карточке нет.

## Этап 4. Валидация и коммит

```bash
python3 scripts/generate_lists.py
```

Коммит: `feat(группы): group_<имя> — <название>`.

## Типичные ошибки ИИ

- Вымышленная группа или локация (только из источника; веб-поиск официального сайта).
- Счётчик материалов вшит в карточку (вычисляемое — только CI).
- Обратные ссылки не собраны из карточек материалов.
- Специализация одним словом без раскрытия в теле.
