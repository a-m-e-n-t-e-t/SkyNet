# 11. Алгоритм ведения списков и сводного реестра

> Сводные списки `_список_*.md` (11 шт.), зеркала `работа и и/` и `_сводный_реестр.md`.
> Шаблоны: `шаблоны/списка_*.md` (10) + `шаблоны/сводного_реестра.md`.
> ПРАВИЛО №1: списки генерирует СКРИПТ `scripts/generate_lists.py`, а не ИИ вручную. Ручной режим — исключение (нет Python), с честным `генератор: вручную`.

## Когда что использовать

| Ситуация | Действие |
|---|---|
| Есть Python (локально) | `python3 scripts/generate_lists.py` |
| Пуш карточек в GitHub | CI `update-lists.yml` сам запустит sync + генерацию и автокоммит |
| Изменены шаблоны | `python3 scripts/validate_templates.py` |
| Python недоступен | ручное ведение по правилам ниже; `генератор: вручную` ЧЕСТНО |

## Конвейер после коммита карточек

```bash
python3 scripts/sync_materials.py      # пустые шаблоны для ссылок без карточек (идемпотентен)
python3 scripts/generate_lists.py      # 11 списков + зеркала + реестр
python3 scripts/generate_lists.py --check   # сверка (код 1 при расхождении)
```

Сверка CI: сумма секций = `всего`; каждая карточка зоны — в списке; каждая запись ведёт к существующему файлу; отставание списка от карточек = диагностируемая метрика, а не молчаливый долг.

## Правила ручного ведения (когда скрипт недоступен)

1. **Формат записи** — ровно три поля: `- id — Название → путь`. Числа, TLR, цены, доли массы, вариант структуры в записях ЗАПРЕЩЕНЫ (F26: источник значений — всегда карточка).
2. **Полнота секций**: все группы классификационного enum присутствуют ВСЕГДА, включая пустые «(0)» со строкой `- — нет —` (пустая группа — факт трекинга полноты, а не ошибка).
3. **Сортировка** — по алфавиту id внутри секции; произведения — по номеру work_NNN; реализации — секция на модель × 3 типа.
4. **Счётчики front matter** (машиночитаемо для CI): сумма секций = `всего`; число записей = числу карточек зоны.
5. **Тот же коммит**: список обновляется вместе с карточками зоны (не «потом»); поле `генератор` указывается честно (`scripts/generate_lists.py` | `вручную`).
6. **Реестр**: таблица «Домены и типы» (карточек + доля % от ИТОГО, сумма долей = 100.0%) + таблица «Покрытие списками» (путь, обновлено, генератор, статус: актуален|отстал). Пустые зоны (0 карточек) НЕ удалять.

## Самопроверка

- [ ] В записях нет чисел/цен/TLR (F26); формат — «id — Название → путь».
- [ ] Все секции enum присутствуют, пустые — с «- — нет —».
- [ ] Сумма счётчиков секций = `всего` = числу карточек зоны.
- [ ] Каждая запись ведёт к существующему файлу; битых ссылок нет.
- [ ] `обновлено` = дата коммита; `генератор` честный.
- [ ] Реестр: доли пересчитаны от ИТОГО; пустые зоны не удалены.

## Коммит

- Со скриптом: коммит карточек → CI автокоммит списков `[skip ci]`.
- Вручную: `chore(списки): обновление <зона> — <причина>` в том же коммите, что и карточки, либо сразу после.

## Типичные ошибки ИИ

- Список правится руками при доступном скрипте (дрейф счётчиков гарантирован).
- Числа/цены в записях списка (нарушение F26).
- Пустые секции удалены «для чистоты» (теряется трекинг полноты).
- Список обновлён не в том коммите, что и карточки зоны.
- `генератор: scripts/generate_lists.py` указан при ручном ведении (нечестно; CI-сверка выявит).
