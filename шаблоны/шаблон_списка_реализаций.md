## Чек-лист (перед коммитом)

- [ ] Счётчики = факту: `всего` = `реальная` + `фантастическая` + `доработанная_ии`; `моделей_с_реализациями` = числу секций моделей.
- [ ] У каждой модели все три подсекции (пустые — с «- — нет —», не удалены).
- [ ] `базовая_модель` каждой записи существует (карточка модели канона); обратные ссылки `реализация_промышленная` / `реализация_ии` — в карточке модели.
- [ ] Каждая папка реализации в `результаты/модели/` присутствует в ведомости (CI-сверка `ls` ↔ ведомость).
- [ ] В записях нет свойств и чисел (F26) — только id, тип, путь.
- [ ] `обновлено` = дата коммита; `генератор` указан честно (скрипт/вручную).
