# SkyNet — Список фантастических материалов (канон)

> **Единый источник данных.** Канон-факты, фантастические свойства и реальный аналог-вдохновение — в карточках (`material_<имя>.md`, §12.3a); GitHub отрендерит front matter таблицей. Список — только навигация: id, файл, аналог-вдохновение, счётчик произведений (F26).

## фантастические материалы (N)

| id | имя_файла | вдохновлён_реальным | N_произведений |
|---|---|---|---:|
| material_<имя> | `<имя>.md` | <id_реального_аналога> | N |
| material_<имя2> | `<имя2>.md` | — | N |

## Чек-лист (перед коммитом)

- [ ] Счётчики front matter = числу строк таблицы; `с_реальным_аналогом` = числу строк с заполненным аналогом.
- [ ] Единая секция (класс один — §12.3a); сортировка по алфавиту id.
- [ ] Каждый id существует: файл `<имя>.md` в папке домена; битых ссылок нет.
- [ ] Каждая карточка фантастического материала присутствует в списке (сверка `ls` ↔ список; CI).
- [ ] N_произведений = числу обратных ссылок поля `материалы_в_произведении` карточек произведений (v11.0).
- [ ] `обновлено` = дата коммита; `генератор` указан честно (скрипт/вручную).
