# SkyNet — Сводный реестр базы знаний

> **Единый источник данных.** Свойства карточек — в самих карточках (front matter);
> навигация внутри зоны — в списках `_список_*.md`. Реестр — верхний уровень:
> сколько каких карточек в каждом домене и какие списки их покрывают (F26).

## Домены и типы

| Домен | Тип карточки | Карточек | Доля % | Путь |
|---|---|---:|---:|---|
| реальные данные | изделие | N | 0.0% | `реальные данные/изделия/` |
| реальные данные | часть | N | 0.0% | `реальные данные/изделия/` (папки `часть_*`) |
| реальные данные | материал | N | 0.0% | `реальные данные/материалы/` |
| реальные данные | технология | N | 0.0% | `реальные данные/технологии/` |
| реальные данные | стандарт | N | 0.0% | `реальные данные/стандарты/` |
| реальные данные | исследовательская_группа | N | 0.0% | `реальные данные/исследовательские_группы/` |
| фантастические данные | модель_SkyNet | N | 0.0% | `результаты/модели/` (карточки `<имя>.md`) |
| фантастические данные | произведение | N | 0.0% | `фантастические данные/произведения/` |
| работа и и | изделие (обёртки + части) | N | 0.0% | `работа и и/изделия/` |
| работа и и | материал | N | 0.0% | `работа и и/материалы/` |
| работа и и | технология | N | 0.0% | `работа и и/технологии/` |
| **ИТОГО** | | **N** | **100.0%** | |

## Чек-лист (перед коммитом)

- [ ] Числа «Карточек» = количеству файлов с соответствующим `тип:` (CI-сверка);
      сумма строк = `ИТОГО` = `счётчики.всего_карточек`.
- [ ] Доли пересчитаны от ИТОГО; сумма долей = 100.0%.
- [ ] Каждая строка «Покрытия» — существующий файл; «отсутствует» = зона без
      списка (кандидат на создание по соответствующему шаблону списка).
- [ ] Статус «отстал» присваивается только при дате списка < даты последнего
      коммита карточек зоны (CI-проверка по git log).
- [ ] Свойства карточек в реестр не копируются (F26) — только счётчики и пути.
- [ ] `обновлено` = дата коммита; `генератор` указан честно (скрипт/вручную).
