# SkyNet — Ведомость частей изделий

> **Единый источник данных.** B-BOM — в карточках изделий: `дочерние_части`,
> `материалы_частей` (с `оптимальная_структура.вариант_id`, F62),
> `наследуемые_материалы`, `технологии_частей`. Ведомость — только навигация:
> где лежит каждая часть и её уровень. Числа и материалы в ведомости
> не дублируются (F26).

## <подсистема> (N изделий)

### izdelie_<имя> (уровень 1)

- `часть_<изделие>_<имя>` (уровень 2) — <Название> → `<подсистема>/<изделие>/<часть>/_index.md`
- `часть_<изделие>_<имя2>` (уровень 3) — <Название> → `<подсистема>/<изделие>/<часть2>/_index.md`

### izdelie_<имя2> (уровень 1, неделимая)

- — декомпозиция не требуется: `уровень_иерархии: неделимый` —

## Чек-лист (перед коммитом)

- [ ] Каждая часть списка есть в `дочерние_части` родителя (и наоборот — CI-сверка).
- [ ] `родитель` карточки части = id секции/родителя в ведомости.
- [ ] Уровень в скобках = `уровень_номер` карточки части (2–4).
- [ ] Подсистема части = подсистема верхнего изделия (наследование §12.6).
- [ ] Ведомость не содержит материалов, долей и цен (F26) — только id/уровень/путь.
- [ ] Счётчики front matter = факту; `всего_частей` = Σ уровней {2,3,4}.
- [ ] `обновлено` = дата коммита; `генератор` указан честно (скрипт/вручную).
