## Чек-лист перед коммитом

- [ ] Кристаллическая_структура заполнена как сложное поле-список: ≥1 вариант; для каждого — `существует` (при «да» — свойства заполняются), `основные` (кристаллография + базовые физ.-механические), `дополнительные` (опц., вкл. `химическая_стойкость` по средам); enum — 14 значений (F5).
- [ ] Выбор оптимальной структуры — в карточках изделий (`материалы_частей.оптимальная_структура`, F62); в карточке материала — только меню вариантов.
- [ ] исследовательская_группа указана или `требует_верификации` (F7).
- [ ] Числа имеют источники; null-поля обоснованы текстом.
- [ ] Данные не дублируются: все числа — только в front matter; тело карточки — повествование и ссылки.
- [ ] Дубли имён полей свойств отсутствуют (пример дефекта из предложения: «минимальная_рабочая_температура» дважды → вторая должна быть «максимальная»); единицы измерения — в имени поля.
- [ ] Если материал в ≥2 применениях — заполнены варианты_по_применению.
- [ ] Если ≥2 структурных варианта доступны — заполнено сравнение_структур.
- [ ] Для фантастического материала — правила §12.3a соблюдены (без реального состава).
