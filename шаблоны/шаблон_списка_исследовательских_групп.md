# SkyNet — Список исследовательских групп

> **Единый источник данных.** Название, локация и специализация — в карточках групп (`group_<имя>.md`, v11.0); GitHub отрендерит front matter таблицей. Список — только навигация: id, файл, локация, счётчики связей (F26). Вычисляемые счётчики (бывший `изделий_в_группе_счёт`) ведёт этот список и CI — в карточке их нет (v11.0).

## группы (N)

| id | имя_файла | локация | N_материалов | N_изделий |
|---|---|---|---:|---:|
| group_<имя> | `<имя>.md` | <страна/город> | N | N |
| group_<имя2> | `<имя2>.md` | <страна/город> | N | N |

## Чек-лист (перед коммитом)

- [ ] Счётчики front matter = числу строк таблицы; `всего` = `групп_с_материалами` + `групп_без_материалов`.
- [ ] Сортировка по алфавиту id; классификационные секции не вводятся (нет enum §10.2).
- [ ] Каждый id существует: файл `<имя>.md` в папке домена; битых ссылок нет.
- [ ] Каждая карточка группы присутствует в списке (сверка `ls` ↔ список; CI).
- [ ] N_материалов = числу карточек материалов с полем `исследовательская_группа` = id (F7).
- [ ] `обновлено` = дата коммита; `генератор` указан честно (скрипт/вручную).
