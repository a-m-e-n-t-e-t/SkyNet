# Требования к ИИ-улучшенному варианту модели

1. Из `работа и и/` + `реальные данные/` как fallback
2. Покрытие_функций(ии) ≥ max(0.80, покрытие_функций(пром)) (P035)
3. ии_перепроектирован.статус = true только если improved ≠ original
4. F49: доля_перепроектированных ≤0.30
5. F64: improved не разрушает идентичность (P065)
6. верификация improved обязательна (веб-поиск или расчёт)
