```yaml
# Ti-6Al-4V — титановый α+β сплав (поликристаллический по применению)

## Описание
Титановый сплав Ti-6Al-4V, используемый в каркасе гуманоидных терминаторов. 
Кристаллическая структура: **поликристаллическая** выбрана по применению (каркас: циклическая 
нагрузка + изотропность + усталостная прочность), согласно P062 и таблице §12.3. Допущение 
«моно- всегда лучше» — НЕВЕРНО: у моно- усталостная прочность в 5–10 раз ниже (95 vs 560 МПа 
при 10^7 циклов), но ползучесть при 850°C выше (150 vs 35 МПа). 

Поэтому в `варианты_по_применению` указаны 3 применения с разными оптимальными структурами:
- каркас_гуманоидный → поли- (усталостная прочность + цена)
- лопатка_микротурбины → моно- (крип при 850°C)  
- пружина_клапанная → поли- (усталостная долговечность 10^8 циклов)
```
