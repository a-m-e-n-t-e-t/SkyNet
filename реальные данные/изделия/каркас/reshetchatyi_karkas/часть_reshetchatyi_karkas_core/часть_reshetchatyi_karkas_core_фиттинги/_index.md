# Часть: часть_reshetchatyi_karkas_core_фиттинги

## Описание

Узловые фиттинги решётчатого каркаса — комплект из 16 CNC-бобышек Al 6061-T6 (бланк 32×32×28 мм, поковка/плита ASTM B247), стыкующих торцы 8 стрингеров (по 2 узла на стрингер) с торцевыми диафрагмами. Масса узла ≈ 35.6 г (32×32×28 мм × 0.46 заполнение × 2.7 г/см³), комплект ≈ 0.57 кг (22.8% массы core). Узлы объединяют сходящиеся стержни фермы и передают усилия на диафрагмы — классическая схема трубчатой фермы со сварными/болтовыми узлами.

Родитель: `часть_reshetchatyi_karkas_core` (подсистема: каркас).

## Принцип работы

Фиттинг — узел фермы: концентрирует сходящиеся осевые усилия стрингеров и передаёт их на листовую диафрагму через болтовое соединение; сечение подобрано под запас прочности выше стрингера (узел не слабее стержня).

## Состав

Атомарная часть (неделимый, уровень 3): компактная фрезерованная бобышка — атомарность по чек-листу F34 (узлы соединений — атомарный класс).
