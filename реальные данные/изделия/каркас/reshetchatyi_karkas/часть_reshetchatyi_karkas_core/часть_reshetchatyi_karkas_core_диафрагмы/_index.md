# Часть: часть_reshetchatyi_karkas_core_диафрагмы

## Описание

Диафрагмы решётчатого каркаса — комплект из 2 торцевых листовых рамок 440×370×2 мм из листа Al 6061-T6 (ASTM B209, состояние T651), контур и перфорация выполнены фрезерованием ЧПУ; заполнение листа 65 % (35 % — облегчающие вырезы). Каждая диафрагма 440×370×2×0.65×2.7 г/см³ ≈ 571 г, комплект ≈ 1.14 кг (45.6% массы core). Воспринимают поперечные сдвиговые нагрузки и задают геометрию сечения решётки, связывая стрингеры через узловые фиттинги.

Родитель: `часть_reshetchatyi_karkas_core` (подсистема: каркас).

## Принцип работы

Диафрагма — торцевая силовая рамка: замыкает контур решётки, воспринимает сдвиг и кручение, распределяет нагрузки от стрингеров по периметру. Перфорация снижает массу при сохранении сдвиговой жёсткости (принцип изогрид/сотовых панелей спутниковых платформ).

## Состав

Атомарная часть (неделимый, уровень 3): единая фрезерованная листовая деталь — атомарность по чек-листу F34 (конструкционные листовые элементы); полевая разборка отсутствует.
