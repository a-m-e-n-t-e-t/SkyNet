# Часть: часть_t800_гиро_навигация

## Описание

Блок гироскопической навигации T-800 — тактический инерциальный измерительный модуль (IMU) на MEMS-гироскопах и акселерометрах с алгоритмами ориентации. Референсное исполнение — Sensonor/Safran STIM300: тактический класс точности (смещение гироскопа <0,2 °/ч), диапазон ±400 °/с, питание 5 В, потребление 1,5 Вт, рабочий диапазон −40…+85 °C. Габариты 39×45×22 мм и масса 0,055 кг — паспортные данные STIM300 (корпус — анодированный алюминий 6061). Материал — al_6061-t6: жёсткий немагнитный корпус с низким термодрейфом.

Родитель: `izdelie_SkyNet-T800` (подсистема: навигация).
