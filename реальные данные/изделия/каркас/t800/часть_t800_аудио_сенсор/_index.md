# Часть: часть_t800_аудио_сенсор

## Описание

Аудиосенсор черепа T-800: микрофонный MEMS-элемент на базе Knowles SiSonic — реальный стандарт микроакустики. Референс: аналоговый MEMS-микрофон Falcon (SPH11C3LR5H): SNR 64 дБ, акустический overload point 134 дБ SPL, корпус 4.72×3.76×1.25 мм (серия SiSonic: кремниевая MEMS-мембрана + ASIC в медно-пластиковом LGA-корпусе, design guide Knowles). Для охвата звука T-800 используется массив таких элементов (канон декомпозиции агрегирует позицию как один аудиосенсор).

Масса 0.1 кг — канон декомпозиции (агрегирует массив + предусилители + подводящую плату; один MEMS-чип ~5 мг). Габарит 4.7×3.8×1.2 мм — по datasheet Knowles SiSonic, не дефолтный fallback.

Родитель: `izdelie_SkyNet-T800` (подсистема: сенсоры).
