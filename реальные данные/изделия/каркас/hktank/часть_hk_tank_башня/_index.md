# Часть: часть_hk_tank_башня

## Описание

Башня MBT на базе M1A2: лобовая композитная броня (Chobham/DU-усиленный модуль), борта из RHA Class B толщиной 80 мм. Башня вращается на 360°, несёт 120-мм орудие M256.
