# Часть: часть_cameron_сенсоры

## Описание

Сенсорный массив Cameron — комбинированная опто-акустическая матрица восприятия: MEMS-микрофоны широкого диапазона, фотодиоды окружающего/ИК-диапазона и плата предварительной обработки сигналов. Референсное исполнение — платы массивов MEMS-микрофонов XENSIV (Infineon): плотная установка микрофонов с перфорированным акустическим экраном, гибкая полиимидная подложка с жёсткими зонами. Габариты 48×36×8 мм и масса 0,040 кг — оценка по типовым платам MEMS-массивов с полиимидной подложкой.

Родитель: `izdelie_SkyNet-Cameron` (подсистема: сенсоры).
