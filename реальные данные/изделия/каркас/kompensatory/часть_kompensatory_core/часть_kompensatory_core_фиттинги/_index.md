# Часть: часть_kompensatory_core_фиттинги

## Описание

Концевые фиттинги сильфона — комплект из 2 колец Ø90 (наружный диаметр) × Ø82 (расточка) × 8 мм из Inconel 718 (AMS 5662, деформируемое состояние криогенная_техника: закалка 1066 °C + двойное старение). Каждое кольцо π×(4.5²−4.1²)×0.8 см × 8.19 г/см³ ≈ 71 г с учётом сварных бортов, комплект ≈ 145 г (58 % массы core). Наружный борт принимает торцы крайних гофр (EBW-стык), внутренний бурт — присоединение к трубопроводу/патрубку сборки; кольца задают соосность и воспринимают осевую нагрузку сильфонной секции.

Родитель: `часть_kompensatory_core` (подсистема: каркас).

## Принцип работы

Концевое кольцо — силовой торец сильфона: замыкает крайние гофры (EBW по наружному бортру), передаёт осевое усилие упругой секции на присоединительные поверхности, центрирует гофры (соосность 7-конволюционной секции). Жёсткое кольцо против «распушения» крайних гофр — конструктивное требование edge-welded сильфонов ( Metal Bellows Bellows 101: концевые фиттинги привариваются после сварки диафрагм в секцию).

## Состав

Атомарная часть (неделимый, уровень 3): единое точёное/фрезерованное кольцо — атомарность по чек-листу F34 (фланец/кольцо); полевая разборка отсутствует.
