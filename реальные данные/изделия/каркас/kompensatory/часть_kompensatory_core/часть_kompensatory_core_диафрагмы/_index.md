# Часть: часть_kompensatory_core_диафрагмы

## Описание

Диафрагмы сильфона — комплект из 14 штампованных тарелок Ø88 мм из фольги Inconel 718 толщиной 0.15 мм (AMS 5662, состояние: закалка 1066 °C + двойное старение 718/621 °C — деформируемое состояние криогенная_техника). Каждая диафрагма π×4.4²×0.015 см × 8.19 г/см³ ≈ 7.5 г, комплект ≈ 105 г (42 % массы core). Диафрагмы свариваются попарно по внутренним кромкам (EBW) в двухгофровые пары → 7 гофр сильфонной секции высотой ~19 мм между концевыми фиттингами.

Родитель: `часть_kompensatory_core` (подсистема: каркас).

## Принцип работы

Диафрагма — полуволна сильфона: пара диафрагм, сваренная по внутренним кромкам (edge welding), образует гофру; наружные кромки привариваются к соседним парам и концевым фиттингам, формируя осевой упругий ход. Тонкая фольга 0.15 мм обеспечивает малую осевую жёсткость при высоком давлении (критерий гибкой стенки), Inconel 718 — высокотемпературная стойкость и усталостная прочность гофр (EJMA-класс сильфонов).

## Состав

Атомарная часть (неделимый, уровень 3): единая штампованная фольговая тарелка — атомарность по чек-листу F34 (упругий элемент/пружина); полевая разборка отсутствует.
