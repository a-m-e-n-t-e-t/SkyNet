# Часть: часть_loop_heat_pipe_core

## Описание

Контурная тепловая труба (LHP) — капиллярная помпа в испарителе обеспечивает перенос тепловой мощности против гравитации на десятки см. Референсное исполнение — контурная тепловая труба (испаритель + паро-жидкостные линии ~150×80×30). Габариты 150×80×30 мм, масса 0.15 кг — паспортные данные (контурная тепловая труба).
