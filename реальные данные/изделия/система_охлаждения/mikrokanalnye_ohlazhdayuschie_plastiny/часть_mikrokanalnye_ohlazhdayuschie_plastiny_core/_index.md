# Часть: часть_mikrokanalnye_ohlazhdayuschie_plastiny_core

## Описание

Микроканальная охлаждающая пластина — медная плита с фрезерованными каналами 0.3–0.5 мм: съём теплового потока до 100 Вт/см². Референсное исполнение — микроканальная охлаждающая пластина (медь, 100×60×5). Габариты 100×60×5 мм, масса 0.1 кг — паспортные данные (микроканальная охлаждающая пластина). Материал — copper: медь Cu-ETP (C11000, проводниковая).
