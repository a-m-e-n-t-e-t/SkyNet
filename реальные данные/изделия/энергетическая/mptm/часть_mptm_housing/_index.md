# Часть: часть_mptm_housing

## Описание

Корпус (housing) изделия — несущий защитный кожух узла: референс — блок электроники управления (компактный корпус ЭКУ). Обеспечивает жёсткость конструкции, отвод тепла и защиту внутренних компонентов; кабельные вводы и монтажные точки по стыковочным поверхностям. Габариты 220×160×90 мм, масса 3.5 кг — оценка по типовым изделиям класса (блок электроники управления). Материал — al_6061-t6: конструкционный алюминиевый сплав 6061-T6.

Родитель: `izdelie_mptm` (подсистема: энергетическая).
