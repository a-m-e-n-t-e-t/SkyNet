# Часть: часть_mptm_controls

## Описание

Электроника управления MPTM — модуль управления и телеметрии: микроконтроллер реального времени, драйверы исполнительных механизмов, шина служебной связи (CAN/RS-485), контроль питания и температур. Референсное исполнение — типовые платы управления на МК STM32 (класс Nucleo/F4): ядро 168–480 МГц, слои силовых драйверов и гальваноразвязки, интерфейсы CAN/UART. Габариты 70×50×25 мм, масса 0,080 кг — оценка по плате управления в алюминиевом корпусе-экране. Материал — al_6061-t6 (корпус-экран).

Родитель: `izdelie_mptm` (подсистема: энергетическая).
