# Часть: часть_mptm_heat_exchanger

## Описание

Паяный пластинчатый теплообменник (BPHE) контура утилизации тепла микро-ТЭЦ: пакет гофрированных пластин из нержавеющей стали AISI 316L, вакуумно-паяных медью (типоразмер SWEP B10, NoP=8). Длина пакета 287 мм, ширина 117 мм, высота 4.4+2.34×NoP = 23.1 мм, масса 1.18+0.12×NoP = 2.14 кг (формулы product sheet SWEP B10); порты F1–F4 24 мм, расход до 9 м³/ч, класс давления S/M по EN 13345. Компактность BPHE — до 90 % меньше объём по сравнению с кожухотрубными аппаратами той же мощности.

Родитель: `izdelie_mptm` (подсистема: энергетическая).

## Принцип работы

Гофрированные (шевронные) пластины образуют чередующиеся каналы двух контуров: горячий теплоноситель (ОГЖ/масло системы утилизации) отдаёт теплоту через тонкую стенку пластины воде отопительного контура — противоток даёт высокую среднюю разность температур и коэффициент теплопередачи 3–7 кВт/(м²·К). Медь пайки герметизирует каждый контакт пластин; турбулизация потока шевронами интенсифицирует теплообмен при малых габаритах.
