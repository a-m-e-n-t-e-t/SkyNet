# Часть: часть_tpv-lenty_pv_cells

## Описание

Лента PV-ячеек TPV-системы: монолитный ряд гетероструктурных ячеек InGaAsSb (зона 0.50–0.55 эВ, λcutoff ≈ 2.3–2.5 мкм) на подложках GaSb, площадь панели 20×10 мм, толщина с подложкой ~0.5 мм. Эпитаксия LPE (двухслойная структура по NTRS 19960007899) практически согласована с GaSb по решётке; ячейки преобразуют ИК-излучение W-эмиттера 1200–1500 K. Номинальная электрическая выработка ленты 5 Вт — PV-ячейки являются единственным генератором TPV-системы: ИК-свет → электричество via photovoltaic effect при PV-КПД ~40 % (MIT LaPotin et al., Nature 2022; Antora Energy, серийное производство 2023).

## Принцип работы

Фотоны с E > Eg (0.55 эВ) поглощаются в базе InGaAsSb, генерируя пары; p-n переход собирает носители, выдающая плотность тока при 1500 K эмиттере достигает единиц А/см². Длинноволновые фотоны проходят через узкозонную структуру и уводятся на охлаждение/отражатель.

## Состав

Промежуточная часть (уровень 2): монолитный ленточный ряд последовательных InGaAsSb/GaSb ячеек (епитаксиальная гетероструктура на подложке) — цельный полупроводниковый компонент.
