# Часть: часть_mikroreaktor_deleniya_heat_exchanger

## Описание

Промежуточный теплообменник микрореактора деления (5 МВт э / 15 МВт т, canon масса 500 кг): компактный печатный теплообменник (PCHE) из аустенитной нержавеющей стали 316L, изготовленный диффузионной сваркой стоп листов с химически травленными микроканалами (технология Alfa Laval/Heatric). Расчётные параметры по TDS производителя: давление до **1250 бар** (18,125 psig), температура от −196 до **+800 °C** для 316/316L SST — с запасом покрывает условия высокотемпературного контура микрореактора (гелий/sCO2-цикл Брайтона). Габариты блока 560×400×280 мм согласованы с canon массой 500 кг (объём ~63 л × плотность 316L 8.03 г/см³); PCHE на ~85 % компактнее и легче кожухотрубных аналогов той же тепловой мощности. Диффузионная сварка без присадочного металла сохраняет свойства родительского материала и целостность микроканалов — критично для первого контура (ORNL: PCHE — кандидат на IHX/SHX реакторов Generation IV).

Родитель: `izdelie_mikroreaktor_deleniya` (подсистема: энергетическая).

## Принцип работы

Тепло первичного контура (гелий/тепловые трубы/расплав-соль) передаётся рабочему телу энергопреобразования (sCO2-цикл Брайтона) через стопку диффузионно-сваренных листов 316L с химически травленными микроканалами: развитая удельная поверхность теплообмена (микроканалы) даёт большие коэффициенты теплопередачи при малом объёме; разделительные перегородки ~0.5–2 мм удерживают разницу давлений контуров (до 1250 бар расчётных). Режимы и потокораспределение асимметричны (шаблоны травления настраиваются под конкретный тепловой баланс); блоки можно сваривать в модули для наращивания мощности.
