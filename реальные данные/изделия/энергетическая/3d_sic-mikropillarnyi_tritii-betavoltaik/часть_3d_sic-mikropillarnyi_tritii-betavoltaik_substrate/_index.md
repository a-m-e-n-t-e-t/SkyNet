# Часть: часть_3d_sic-mikropillarnyi_tritii-betavoltaik_substrate

## Описание

Подложка 4H-SiC 500 мкм для 3D-микростолбовых (micropillar) структур тритиевой бета-вольтаики на кристалле 10×10 мм; вертикальные столбы увеличивают площадь контакта с тритиевым слоем.
