# Часть: часть_termoelektricheskii_postoyannyi_magnit_clamping

## Описание

Прижимной крепёж термоэлектрического генератора с постоянными магнитами: набор из 8 нержавеющих болтов M4×35 (AISI 304/A2-70) по углам модуля с пружинными шайбами, создающий постоянное сжатие керамических панелей Пельтье-стека ~1 МПа. Нержавеющая сталь исключает гальванические пары с медными контактами и тепловое ослабление затяжки при 150–200 °C.

## Принцип работы

Упругая затяжка болтов компенсирует термическое расширение слоёв модуля (Bi2Te3-стек, медные шины, керамика Al2O3) при термоциклировании, предотвращая сдвиговый отказ паяных соединений; момент затяжки ~2 Н·м с пружинной шайбой поддерживает контактное давление.
