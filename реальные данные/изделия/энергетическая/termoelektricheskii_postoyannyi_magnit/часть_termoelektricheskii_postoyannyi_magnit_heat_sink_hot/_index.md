# Часть: часть_termoelektricheskii_postoyannyi_magnit_heat_sink_hot

## Описание

Горячий радиатор (heat sink горячей стороны) термоэлектрического модуля: экструзионный ребристый профиль 40×40×20 мм (шаг рёбер 4 мм, тепловое сопротивление ~0.6 К/Вт с принудительным обдувом) — типовое решение для отвода полного теплового потока TEC-модуля (референс посадки 40×40 мм, datasheet TEC1-12706: модуль перекачивает Qc до ~50 Вт; горячая сторона должна рассеять Qc + P_эл). Рёбра вертикальные, основание 4 мм — согласовано с холодной пластиной (часть_..._heat_sink_cold) по контуру 40×40 мм.

Масса 0.1 кг — канон декомпозиции (реальный радиатор 40×40×20 мм с рёбрами ~35–50 г). Габарит 40×40×20 мм — типовой профиль hot-side радиатора, не дефолтный fallback.

Родитель: `izdelie_termoelektricheskii_postoyannyi_magnit` (подсистема: энергетическая).
