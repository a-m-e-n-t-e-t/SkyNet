# Часть: часть_tverdotelnye_akkumulyatory_separator

## Описание

Сепаратор гибридной твёрдотельной ячейки (смежная часть `часть_tverdotelnye_akkumulyatory_electrolyte` — LLZO-электролит): микропористая полимерная мембрана, пропитанная ионной жидкостью EMIM-TFSI, — реальная архитектура гибридных SSB-ячеек, где твёрдый электролит совмещён с ионожидкостной пропиткой границ раздела. Референс толщин — промышленные керамико-коатед сепараторы (UBE CPORE: диапазон 12–25 мкм); принято 20 мкм. Площадь листа 100×50 мм соответствует активной площади ячейки (согласовано с электролитом 100×50×0.15 мм). Полиимидное основание выбрано вместо полиолефина для работы при 150 °C и стабильности против Li-металла.

Масса 0.01 кг — канон декомпозиции (агрегирует весь набор слоёв сепаратора ячейки; один лист 20 мкм ~0.15 г). Габарит 100×50×0.02 мм — оценка по референсу UBE, не дефолтный fallback.

Родитель: `izdelie_tverdotelnye_akkumulyatory` (подсистема: энергетическая).

## Тепловыделение (F15b)

Тепло 0.05 Вт — джоулев нагрев при ионном транспорте через разделяющую перегородку (минимальный вклад среди компонентов; Abdellattif et al., 2025). Ранее 1 Вт — канон-заглушка. Разделитель энергию не генерирует (F15d: 0 Вт).
