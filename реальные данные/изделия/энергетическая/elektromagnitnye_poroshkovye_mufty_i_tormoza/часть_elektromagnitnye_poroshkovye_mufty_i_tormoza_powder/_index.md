# Часть: часть_elektromagnitnye_poroshkovye_mufty_i_tormoza_powder

## Описание

Рабочее тело (магнитный порошок) рабочей камеры электромагнитной порошковой муфты/тормоза: карбонильное железо — сферический порошок Fe ≥99.5 %, получаемый разложением Fe(CO)₅; типичный гранулометрический состав 1.5–4.5 мкм. Обзорная литература по магнитореологическим системам прямо фиксирует выбор CIP как магнитного компонента благодаря «высокой магнитной насыщенности и низкой остаточной намагниченности» — то же требование обратимости муфты: без тока катушки порошок не передаёт момент, при намагничивании выстраивается в цепочки в зазоре ротор-статор. Эквивалентный объём камеры 50×50×40 мм (~100 см³) соответствует канонической массе 0.3 кг при насыпной плотности засыпки ~3 г/см³ (плотность частиц 7.86 г/см³).

Масса 0.3 кг — канон декомпозиции (суммарная засыпка рабочих камер всех муфт/тормозов изделия). Габарит 50×50×40 мм — расчётный эквивалент камеры по насыпной плотности, не дефолтный fallback.

Родитель: `izdelie_elektromagnitnye_poroshkovye_mufty_i_tormoza` (подсистема: энергетическая).
