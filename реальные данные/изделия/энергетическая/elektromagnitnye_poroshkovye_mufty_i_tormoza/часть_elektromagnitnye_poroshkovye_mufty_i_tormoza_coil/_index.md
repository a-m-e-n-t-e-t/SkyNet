# Часть: часть_elektromagnitnye_poroshkovye_mufty_i_tormoza_coil

## Описание

Катушка возбуждения порошковой муфты (муфта 5 кг класса Mitsubishi SH-170030, момент линеен по току возбуждения): кольцевая обмотка 120×40×50 мм из медного обмоточного провода ПЭТВ-2 в пазу магнитопровода. Масса ≈800 г (16% номинала 5 кг).

## Принцип работы

Ток катушки создаёт аксиальный поток через рабочий зазор с магнитным порошком — цепочки частиц связывают ведущую и ведомую полумуфты, момент растёт практически линейно с током до насыщения магнитопровода; обмотка работает в режиме S1 с перегревом, ограниченным классом изоляции провода.

## Состав

Промежуточная часть (уровень 2). Дочерних частей нет.
