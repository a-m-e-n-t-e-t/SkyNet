# Часть: часть_mmrtg_connector

## Описание

Электрический соединительный узел MMRTG — интерфейс вывода мощности термоэлектрического генератора: силовые шины выхода (номинал 28 В, ~110 Вт) и цепи телеметрии температуры. Референсное исполнение — электрический интерфейс MMRTG (NASA RPS): герметизированные космические разъёмы в прочном корпусе, стойкость к вибрации вывода, защита от радиационного поля источника. Габариты 60×45×35 мм, масса 0,12 кг — оценка по силовому разъёмному узлу генератора. Материал — al_6061-t6 (корпус-экран узла).

Родитель: `izdelie_mmrtg` (подсистема: энергетическая).
