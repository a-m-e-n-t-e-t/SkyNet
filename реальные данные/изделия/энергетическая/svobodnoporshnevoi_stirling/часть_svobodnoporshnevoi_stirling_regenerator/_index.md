# Часть: часть_svobodnoporshnevoi_stirling_regenerator

## Описание

Кольцевой регенератор между горячим и холодным теплообменниками вытеснителя: матрица из спечённого случайноволокнистого войлока нержавеющей стали (Bekaert Bekipor 316L, волокно 12–22 мкм, пористость ~90–91%). Габариты — кольцевая геометрия: наружный Ø65 мм / внутренний Ø45 мм, длина 55 мм, ~500 слоёв — по реальному кольцевому регенератору 3-кВт класса SERENUM05 (Toshiba/NDA, 2005); длина 55 мм подтверждается дизайном свободнопоршневого FSP-конвертора Sunpower (NASA/CR—2010-216750, Table 20).

## Принцип работы

Регенератор — тепловой аккумулятор цикла Стирлинга: при перетекании газа из полости расширения в полость сжатия пористая матрица отбирает и запасает тепло, при обратном ходе возвращает его газу; эффективность регенератора напрямую определяет КПД двигателя. Случайноволокнистая матрица сочетает большую удельную поверхность теплообмена с низким гидравлическим сопротивлением; осевую теплопроводность матрицы минимизируют.
