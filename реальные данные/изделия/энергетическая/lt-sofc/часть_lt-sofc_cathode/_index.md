# Часть: часть_lt-sofc_cathode

## Описание

Воздух-электрод (катод) LT-SOFC в составе стека 150×150 мм (родитель: `izdelie_lt-sofc`). Выполнен пористым композитом LSM/YSZ 50/50 wt.% на основе LSM-20 (La0.8Sr0.2MnO3-δ) — стандартного катодного материала твердооксидных ТЭ (коммерческие ячейки Nexceris, NETL). Слой толщиной 50 мкм (типично 20–50 мкм для анод-поддерживаемых ячеек) с пористостью 30 % обеспечивает подвод O2 к тройной фазовой границе кислород/LSM/YSZ; электронная проводимость LSM 200 S/cm при 800 °C, ТКЛР 11.4×10⁻⁶ K⁻¹ согласован с 8YSZ-электролитом (часть_lt-sofc_electrolyte, 10 мкм).

## Принцип работы

1/2 O2 + 2e⁻ → O²⁻. LSM катализирует восстановление кислорода.

## Энергетический баланс (F15d)

Катод — кислородный электрод: восстановление O2 (1/2 O2 + 2e⁻ → O²⁻) замыкает электрохимическую цепь. Пара «анод↔катод» — совместный генератор стека: учётная разбивка номинала родителя 200 Вт — по 100 Вт на электрод (Elcogen elcoCell: SOFC генерирует электричество электрохимическим процессом). По отдельности электроды мощность не отдают — значение отражает вклад пары.

Тепло 0.1 Вт — активационное перенапряжение восстановления кислорода на LSM/YSZ-границе.

## Состав

Промежуточная часть (уровень 2). Дочерних частей нет.
