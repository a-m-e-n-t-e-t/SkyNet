# Часть: часть_vodorodnye_toplivnye_elementy_catalyst_cathode

## Описание

Катодный катализаторный слой (ORR — реакция восстановления кислорода) мембранно-электродного блока водородного топливного элемента: платиновый катализатор Pt/C (40–50 мас.% Pt на саже Vulcan XC-72), нанесённый на протон-проводящую мембрану (CCM-архитектура). Загрузка Pt на катоде 0.4 мг/см² — промышленный стандарт; толщина слоя 10–15 мкм (исследование Schneider et al., J. Electrochem. Soc. 2023: влияние Pt loading и толщины слоя катода на производительность PEMFC). Активная площадь 25 см² (50×50 мм) — согласована с анодной частью `часть_vodorodnye_toplivnye_elementy_catalyst_anode` (50×50 мм).

Масса 0.01 кг — канон декомпозиции (агрегирует слой с токосъёмным GDL; реальный слой Pt/C на 25 см² ~20 мг Pt). Габарит 50×50×0.015 мм — оценка по литературе PEMFC, не дефолтный fallback.

Родитель: `izdelie_vodorodnye_toplivnye_elementy` (подсистема: энергетическая).
