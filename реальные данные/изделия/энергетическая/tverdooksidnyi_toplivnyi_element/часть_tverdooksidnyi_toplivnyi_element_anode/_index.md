# Часть: часть_tverdooksidnyi_toplivnyi_element_anode

## Описание

Анод (топливный электрод) планарного SOFC — пористый кермет Ni-YSZ, наиболее распространённый анодный материал отрасли. Анод-поддерживаемая конструкция: слой NiO/YSZ толщиной 400 мкм выполняет роль механической поддержки ячейки 150×150 мм, рабочая температура 700–800 °C. Композит NiO + 8YSZ (65:35 wt.%) после восстановления NiO→Ni в топливной атмосфере (начало с ~400 °C, полное при 850–1000 °C) образует трёхфазную перколяционную структуру: связная Ni-фаза (электронная проводимость 400–600 S/см при 800 °C), связный YSZ-каркас (ионный транспорт O²⁻, ТКЛР-согласование с электролитом 10.5×10⁻⁶ К⁻¹) и связная поровая сеть ~40% (подача H2); усадка Ni-фазы на 33 об.% при восстановлении сама формирует поры. Реакция окисления водорода H2 + O²⁻ → H2O + 2e⁻ протекает на тройных фазовых границах (TPB); ТКЛР кермета 12.7×10⁻⁶ К⁻¹ (40 об.% Ni) против 16.9×10⁻⁶ К⁻¹ у чистого Ni. Состав с повышенным Ni (65:35) даёт 383.9 мВт/см² при 800 °C на прямом аммиаке (Monash/CSIRO, 2025).
