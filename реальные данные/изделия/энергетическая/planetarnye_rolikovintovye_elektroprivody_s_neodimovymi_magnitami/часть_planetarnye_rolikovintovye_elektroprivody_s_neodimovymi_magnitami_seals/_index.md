# Часть: часть_planetarnye_rolikovintovye_elektroprivody_s_neodimovymi_magnitami_seals

## Описание

Уплотнение (wiper/seal) планетарной роликовинтовой пары электропривода: скребковое кольцо на гайке, отсекающее абразивную пыль и удерживающее пластичную смазку в резьбовых канавках. Референс — каталог SKF «Roller screws» (технические данные и размеры планетарных роликовинтовых пар, включая wiper-уплотнения): посадочный контур уплотнения для винта Ø20 мм — фланец ~30 мм, толщина ~5 мм. Материал — FKM/Silikon-эластомерная композиция (стойкость к литиевым смазкам, диапазон −40…+150 °C, типовое решение SKF/трибология).

Масса 0.1 кг — канон декомпозиции (реальное уплотнение ~3–5 г; канон агрегирует полный комплект уплотнений привода: входной/выходной лабиринт, торцевые крышки). Габарит 30×30×5 мм — по каталогу SKF, не дефолтный fallback.

Родитель: `izdelie_planetarnye_rolikovintovye_elektroprivody_s_neodimovymi_magnitami` (подсистема: энергетическая).
