# Часть: часть_planetarnye_rolikovintovye_elektroprivody_s_neodimovymi_magnitami_bearings

## Описание

Подшипниковый узел винта планетарного роликовинтового электропривода с неодимовыми магнитами: радиально-упорные шариковые подшипники класса screw-drive. Референс — SKF 7205 BEP: посадочные размеры 25×52×15 мм, net weight 0.126 кг (каталог SKF); габарит 25×52×15 подтверждён и для специализированной серии подшипников винтовых передач 760205 (контактный угол 15°/25°, металл GCr15/100Cr6). Серия 760xx рассчитана на высокие осевые нагрузки винтовых приводов: комплект двух подшипников «дуплекс» фиксирует винт по оси с обеих сторон.

Масса 0.3 кг — канон декомпозиции (комплект из двух подшипников 0.126 кг + корпусы-стаканы — согласуется с каноном). Габарит 25×52×15 мм — по каталогу SKF, не дефолтный fallback.

Родитель: `izdelie_planetarnye_rolikovintovye_elektroprivody_s_neodimovymi_magnitami` (подсистема: энергетическая).
