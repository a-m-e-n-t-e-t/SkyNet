# Часть: часть_vysokotemperaturnyi_sverhprovodyaschii_podshipnik_hts_element

## Описание

HTS-элемент высокотемпературного сверхпроводящего подшипника — массивный керамический блок YBCO, создающий пассивное магнитное подвешивание над постоянными магнитами (эффект Мейснера + пиннинг потока). Референсное исполнение — массивные YBCO-блоки CAN Superconductors: типовой элемент 30×30×15 мм, левитационная сила до 100 Н при 77 К, работает в жидком азоте. Габариты 30×30×15 мм — типовой выпускной размер блока; масса 0,080 кг при плотности YBCO ~6,0 г/см³ (13,5 см³ → 81 г). Материал — ybco (YBa₂Cu₃O₇).

Родитель: `izdelie_vysokotemperaturnyi_sverhprovodyaschii_podshipnik` (подсистема: энергетическая).
