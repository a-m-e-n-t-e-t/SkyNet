# Часть: часть_coilgun_barrel

## Описание

Ствол электромагнитного ускорителя (референс: naval EMRG — 90-мм канал с медными рельсами, снаряды 2.4–15 кг на скоростях до 2500 м/с): две соосные токопроводящие шины из бериллиевой меди в диэлектрической обойме; длина ствола — по осевому габариту изделия 5000 мм, внешний диаметр ≈300 мм с учётом катушек и структуры (оценка).

## Принцип работы

Импульс тока мегаамперного класса от конденсаторного банка проходит по рельсам через арматуру снаряда; взаимодействие тока арматуры с полем рельс создаёт силу Лоренца, разгоняющую снаряд вдоль канала; композитная обойма воспринимает расталкивающие усилия рельс.
