# Часть: часть_ni-63_betavoltaik_4h-sic_substrate

## Описание

Подложка 4H-SiC толщиной 350 мкм (стандартная промышленная пластина) для p-n/p-i-n структуры бета-вольтаического элемента с Ni-63; утончение пластины до 50 мкм повышает собираемость бета-частиц.
