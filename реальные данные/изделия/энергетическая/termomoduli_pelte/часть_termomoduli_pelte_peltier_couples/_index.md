# Часть: часть_termomoduli_pelte_peltier_couples

## Описание

Комплект термоэлектрических пар термомодуля Пельтье: 127 p/n-пар из теллурида висмута Bi₂Te₃ — референс стандартного одно­ступенчатого модуля TEC1-12706 («127 couples, 40 mm × 40 mm size single stage module», datasheet Thermonamic 2022). Пары — вертикальные колонки p- и n-проводимости, соединённые последовательно медными шинами на керамических пластинах Al₂O₃ (96%); footprint комплекта 40×40 мм, высота колонок ~2.5 мм (полная высота модуля с керамикой 3.9 мм).

Масса 0.01 кг — канон декомпозиции; реальная масса Bi₂Te₃-колонок модуля TEC1-12706 ~10 г из ~23 г полной массы — согласуется с каноном. Габарит 40×40×2.5 мм — по datasheet Thermonamic, не дефолтный fallback.

Родитель: `izdelie_termomoduli_pelte` (подсистема: энергетическая).
