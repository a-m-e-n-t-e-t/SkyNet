# Часть: часть_alyuminievo-vozdushnye_toplivnye_elementy_anode

## Описание

Сменный расходуемый анодный блок алюминиево-воздушного топливного элемента — пластина из коммерчески чистого алюминия марки 1100 (серия 1xxx, ≥99.0 % Al, ASTM B209). При разряде алюминий электрохимически окисляется в щелочном электролите (раствор KOH): Al + 3OH⁻ → Al(OH)₃ + 3e⁻. Алюминий — один из самых ёмких расходуемых анодов: теоретическая удельная ёмкость 2980 мА·ч/г, теоретическая удельная энергия по топливу 8100 Вт·ч/кг, стандартный электродный потенциал −1.66 В (RSC Adv. 2024). Основные потери: самокоррозия с выделением водорода (2Al + 2H₂O + 2OH⁻ → 2Al(OH)₄⁻ + 3H₂) и пассивация оксидной плёнкой Al₂O₃ — для их подавления в референсных системах применяют высокочистый Al (99.99 %) либо легирование Ga–In–Zn/Sn; в коммерческой демонстрации Phinergy/Alcoa (2013–2014) батарея собрана из 50 сменных пластин, каждая обеспечивает ≈20 миль хода электромобиля. Рабочее напряжение ячейки на практике 1.2–1.6 В при теоретическом OCP 2.74 В.

Родитель: `izdelie_alyuminievo-vozdushnye_toplivnye_elementy` (подсистема: энергетическая). Габариты анода — оценка: одиночная сменная пластина 180×130×30 мм (≈704 см³ Al, ρ 2.70 г/см³ → 1.9 кг = 0.38 номинальной массы модуля 5 кг), размещается внутри корпуса 200×150×100 мм вместе с электролитом и воздушным катодом.

## Принцип работы

Анод работает как расходуемый «топливный» электрод: при подключении внешней цепи атомы алюминия отдают по три электрона и в щелочной среде KOH переходят в раствор в форме алюминат-ионов Al(OH)₄⁻ (при контакте с электролитом — гидроксид Al(OH)₃), а освобождённые электроны через нагрузку поступают на воздушный катод, где восстанавливают кислород из воздуха. Суммарная реакция разряда: 4Al + 3O₂ + 6H₂O → 4Al(OH)₃. Электрод не восстанавливается зарядом — после выработки пластина заменяется новой, а отработанный электролит с гидроксидом алюминия направляется на регенерацию (электролиз/переплав обратно в Al). Побочный процесс — самокоррозия с выделением H₂ (реакция 2Al + 2H₂O + 2OH⁻ → 2Al(OH)₄⁻ + 3H₂, до нескольких процентов ёмкости): её подавляют чистотой металла, легированием (Ga, In, Zn, Sn) и добавками в электролит. Тепловыделение анода (~30 Вт при номинале ячейки 100 Вт) складывается из анодной поляризации (~0.2–0.3 В на токе ~83 А) и коррозионных потерь.
