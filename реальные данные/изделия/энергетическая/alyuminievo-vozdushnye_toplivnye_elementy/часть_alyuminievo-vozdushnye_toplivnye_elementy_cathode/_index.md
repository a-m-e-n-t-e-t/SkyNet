# Часть: часть_alyuminievo-vozdushnye_toplivnye_elementy_cathode

## Описание

Воздушный катод алюминиево-воздушного топливного элемента — газодиффузионный электрод: воздух (O₂) проходит с внешней стороны через гидрофобный углеродный слой с катализатором (Ag/MnO₂/C), электрохимически восстанавливаясь на трёхфазной границе; изнутри — контакт с щелочным электролитом и токосъёмная никелевая сетка. Референсное исполнение — воздушные катоды Al-air элементов (Wikipedia: Aluminium–air battery): листовые ГДЭ площадью 100–200 см², толщина 2–4 мм. Габариты 105×85×3 мм (рабочая площадь ~100 см² с рамкой), масса 0,080 кг. Материал — karbon (углеродные материалы ГДЭ).

Родитель: `izdelie_alyuminievo-vozdushnye_toplivnye_elementy` (подсистема: энергетическая).
