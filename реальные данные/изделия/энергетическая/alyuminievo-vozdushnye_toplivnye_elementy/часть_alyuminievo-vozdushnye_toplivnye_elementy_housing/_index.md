# Часть: часть_alyuminievo-vozdushnye_toplivnye_elementy_housing

## Описание

Корпус (housing) изделия — несущий защитный кожух узла: референс — батарея Al-air (корпус с воздушными каналами). Обеспечивает жёсткость конструкции, отвод тепла и защиту внутренних компонентов; кабельные вводы и монтажные точки по стыковочным поверхностям. Габариты 420×300×250 мм, масса 12 кг — оценка по типовым изделиям класса (батарея Al-air). Материал — al_6061-t6: конструкционный алюминиевый сплав 6061-T6.

Родитель: `izdelie_alyuminievo-vozdushnye_toplivnye_elementy` (подсистема: энергетическая).
