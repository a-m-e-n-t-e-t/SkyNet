# Часть: часть_alyuminievo-vozdushnye_toplivnye_elementy_air_electrode

## Описание

Воздушный газодиффузионный электрод (GDE, воздушный катод) алюминиево-воздушного топливного элемента: пористый лист толщиной 350 мкм из токопроводящей углеродной сажи, связанной 20% PTFE, с катализатором MnO₂ и токосъёмником из никелевой сетки. Спецификация реального коммерческого аналога — воздушный электрод MOC (Gaskatel, Германия, позиция 82010): восстановление кислорода 200 мА/см² при 0.75 В vs. RHE, оптимальная среда — щелочной электролит pH > 7, температура < 50 °C, поставка листами 10×10 см.

Габариты — оценка: лист 200×150 мм по посадочному месту родителя (≈300 см² активной площади из смежных сегментов 10×10 см); при 200 мА/см² и ~1.2 В на элемент это даёт ≈72 Вт на сторону — для номинальных 100 Вт родителя используется двусторонняя работа или два электрода. Масса — оценка ≈0.01 кг (поверхностная плотность ~300 г/м² × 300 см²; прямой источник массу не публикует).

Родитель: `izdelie_alyuminievo-vozdushnye_toplivnye_elementy` (подсистема: энергетическая).

## Принцип работы

Кислород из воздуха диффундирует через гидрофобные PTFE-каналы к трёхфазной границе «газ–электролит–катализатор» и восстанавливается: O₂ + 2H₂O + 4e⁻ → 4OH⁻ (+0.40 В). Ионы OH⁻ мигрируют через щелочной электролит (KOH, pH > 7) к алюминиевому аноду, замыкая ток 4Al + 3O₂ + 6H₂O → 4Al(OH)₃ (≈1.2 В на элемент на практике). Никелевая сетка отводит ток от углеродного слоя; PTFE удерживает электролит в мелких порах, не пуская его в газовые каналы. Тепловыделение в электроде ≈40 Вт — джоулево тепло + теплота перенапряжения ОРР при рабочем токе ≈83 А (100 Вт / 1.2 В).
