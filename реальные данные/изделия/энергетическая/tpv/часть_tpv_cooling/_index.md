# Часть: часть_tpv_cooling

## Описание

Узел охлаждения TPV-массива: микроканальная алюминиевая холодная пластина 100×100×12 мм с принудительным водяным контуром. Референс — TPV-система MIT/NREL 2022 (LaPotin et al., Nature): TPV-массив 10×10 см работает при тепловом потоке 1.8 Вт/см² — при КПД ~40% на массив приходится >180 Вт паразитного тепла, требующего активного съёма для стабилизации температуры ячеек ( bandgap-стабильность). Микроканалы 1×1 мм, шаг 2 мм — типовая геометрия серийных cold plates.

Масса 0.1 кг — канон декомпозиции (реальная пластина 100×100×12 мм с водой ~350 г; канон агрегирует контур без теплоносителя). Габарит 100×100×12 мм — по контуру массива 10×10 см, не дефолтный fallback.

Родитель: `izdelie_tpv` (подсистема: энергетическая).
