# Часть: часть_emi-generator_antenna

## Описание

Рупорная антенна EMI-генератора `izdelie_emi-generator`: пирамидальный field-generating рупор класса ETS-Lindgren 3162-01 — 1.2–1.4 ГГц, создаёт поле 600 В/м при подводимой мощности <500 Вт (макс. 550 Вт CW, разъём Type N, 50 Ом, VSWR ≤2:1 тип. 1.5:1). Габариты по опорной реализации: апертура 647.7×746.8 мм, длина 1062.7 мм. Опорная масса 3162-01 с монтажной оснасткой — 23.6 кг; canon-масса части 20 кг — инженерная оценка алюминиевой конструкции рупора без поворотного крепежа. Конструкция — алюминиевый сплав 6061-T6 (материал базы `al_6061-t6`): высокая электропроводность, малая масса, стойкость к коррозии; применяется в automotive EMC-испытаниях по GMW 3097 и Ford ES-XW7T-1A278-AC.

Родитель: `izdelie_emi-generator` (подсистема: энергетическая).

## Принцип работы

Пирамидальный рупор трансформирует волноводную моду (TE10) в направленный луч: расширяющийся рупор согласовывает волновое сопротивление волновода со свободным пространством, формируя линейно поляризованный луч с апертурным раскрывом 647.7×746.8 мм. Рупор класса field-generating специально рассчитан на генерацию сильных полей: 600 В/м на рабочей дистанции при <500 Вт входной мощности (1.2–1.4 ГГц, VSWR ≤2:1) — используется для EMC/EMI-испытаний компонентов (GMW 3097, Ford ES-XW7T-1A278-AC). Алюминиевая конструкция 6061-T6 обеспечивает высокую отражательную способность и минимальные омические потери; низкий VSWR защищает выходной каскад генератора от отражённой мощности.
