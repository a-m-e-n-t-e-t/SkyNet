# Часть: часть_perovskite_tandem_junction_box

## Описание

Распределительная коробка (junction box) перовскит-кремниевого тандемного модуля: приём трёх шинных лент ячеек, байпасные диоды (3 шт.), силовой выходной разъём MC4-класса. Референсное исполнение — типовые PV junction box серийных солнечных модулей: литьё термопласта с характеристикой устойчивости к 105–125 °C на подложке модуля, IP68. Габариты 96×64×18 мм, масса 0,15 кг — типовые для коробки модуля 400–500 Вт. Материал — peek: термопласт высокой теплостойкости (перовскитные модули чувствительны к температурным режимам пайки).

Родитель: `izdelie_perovskite_tandem` (подсистема: энергетическая).
