# Часть: часть_superkondensatory_electrode_neg

## Описание

Негативный электрод ячейки суперконденсатора (симметричный EDLC): конструктивно идентичен позитивному (часть_superkondensatory_electrode_pos) — лента активированного угля на углеволоконной подложке 1720×60×0.15 мм. Референс — ячейка Maxwell BCAP3000 (3000 Ф, 2.7 В, Ø60×172 мм): в симметричных EDLC оба электрода из одного материала, ёмкость обеспечивается двойным электрическим слоем на развитой углеродной поверхности (~1500–2000 м²/г).

Масса 0.1 кг — канон декомпозиции (реальная загрузка электрода ~80–100 г). Габарит — оценка по геометрии референс-ячейки, не дефолтный fallback. Парная позиция: допустимое F25-совпадение сигнатуры с электродом_pos (≤2 файлов).

Родитель: `izdelie_superkondensatory` (подсистема: энергетическая).
