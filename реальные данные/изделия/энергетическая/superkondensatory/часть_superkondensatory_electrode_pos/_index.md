# Часть: часть_superkondensatory_electrode_pos

## Описание

Позитивный электрод ячейки суперконденсатора (симметричный EDLC): лента активированного угля на углеволоконной подложке. Референс — ячейка Maxwell BCAP3000 (3000 Ф, 2.7 В, цилиндр Ø60×172 мм): рулонная электродная секция шириной 60 мм разворачивается в ленту длиной ~1.7 м, толщина электродного листа ~150 мкм (два электрода + сепаратор намотаны на вывод-токосъём). В симметричном EDLC позитивный и негативный электроды идентичны по конструкции (парная позиция, см. часть_superkondensatory_electrode_neg).

Масса 0.1 кг — канон декомпозиции; реальная углеродная загрузка электрода ячейки 3000 Ф ~80–100 г — согласуется с каноном. Габарит 1720×60×0.15 мм — оценка по геометрии ячейки Ø60×172, не дефолтный fallback.

Родитель: `izdelie_superkondensatory` (подсистема: энергетическая).
