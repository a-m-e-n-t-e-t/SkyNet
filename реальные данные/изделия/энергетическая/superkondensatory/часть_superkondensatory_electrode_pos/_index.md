# Часть: часть_superkondensatory_electrode_pos

## Описание


Масса 0.1 кг — канон декомпозиции; реальная углеродная загрузка электрода ячейки 3000 Ф ~80–100 г — согласуется с каноном. Габарит 1720×60×0.15 мм — оценка по геометрии ячейки Ø60×172, не дефолтный fallback.


> **Парная часть (v9.35, F26):** 2 идентичных экземпляра (объединены из двух файлов с маркерами top/pos и bottom/neg). Масса_kg — за ОДИН экземпляр, доля_массы_родителя учитывает обе штуки.

Родитель: `izdelie_superkondensatory` (подсистема: энергетическая).
