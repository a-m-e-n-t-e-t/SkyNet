# Часть: часть_kondensatory_keramicheskie_ceramic_layers

## Описание

Диэлектрические слои MLCC 0805-класса (класс Murata GRM21: 1 мкФ, 50 В); керамический чип между зонами торцевой терминации — 1.5×1.25×1.25 мм (длина = корпус 2.0 минус 2×0.25 мм Cu-терминации, ширина и толщина по корпусу): X7R-диэлектрик на легированном BaTiO3 (Dy/Ho/Y-оксиды, Mg, Si, Mn — core-shell BME-структура), εr ~3000, ΔC/C ±15 % в −55…+125 °C (EIA RS-198, класс II). Слои толщиной ~1–10 мкм чередуются с Ni-внутренними электродами и ко-спекаются при 1150–1350 °C в восстановительной атмосфере (NASA NTRS 20150004115: типовое ко-спекание ~1350 °C). Номинал части: εr 3000, V_max 50 В (канон).

## Принцип работы

Сегнетоэлектрическая поляризация тетрагонального BaTiO3 (P4mm, спонтанная поляризация 0.15–0.26 C/m²) обеспечивает высокую диэлектрическую проницаемость керамики; ёмкость MLCC C = ε0·εr·N·A/d набирается сотнями тонких слоёв между Ni-электродами. Core-shell микроструктура (легированные оболочки вокруг BaTiO3-ядра) сглаживает температурную зависимость εr до класса X7R и делает диэлектрик совместимым с Ni-электродами в восстановительном обжиге: оболочка подавляет восстановление титана и миграцию кислородных вакансий под постоянным смещением. X7R — рабочая керамика для развязки и фильтрации в диапазоне −55…+125 °C.
