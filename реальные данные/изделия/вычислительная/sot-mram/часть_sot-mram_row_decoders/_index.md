# Часть: часть_sot-mram_row_decoders

## Описание

Блок дешифраторов строк SOT-MRAM-кристалла (чип 8×8×1 мм класса IMEC SOT-MRAM LL-cache 2023): кремниевый логический блок 1.6×1.1×0.4 мм на общей подложке, CMOS-логика выборки строки из 2¹⁰ состояний затворов. Масса ≈0.4 г (13.3% номинала 3 г).

## Принцип работы

Дешифратор принимает адрес шины и активирует единственную строку слов через ступени преддекодера — разнесение путей записи/чтения SOT-ячейки (по IMEC) позволяет декодеру управлять линиями слов без конфликтов с туннельным током записи; блок размещается у периферии массива для минимальной длины словных линий.
