# Часть: часть_sot-mram_sense_amplifiers

## Описание

Блок sense-усилителей SOT-MRAM-кристалла (чип 8×8×1 мм, технология с раздельными путями записи/чтения по IMEC 2023 и 1 Kb MUX-демонстрацией 2024): кремниевый блок 1.4×0.9×0.4 мм с дифференциальными компараторами токов MTJ. Масса ≈0.5 г (16.7% номинала 3 г).

## Принцип работы

Sense-усилитель сравнивает сопротивление выбранной MTJ с опорной ячейкой и защёлкивает бит — SOT-развязка записи (ток по тяжёлому металлу) от чтения убирает disturb-канал, поэтому усилитель может работать с меньшим запасом по току и выше по скорости, чем в STT-MRAM.
