# Часть: часть_brainchip_akida_2_substrate

## Описание

Корпусная подложка нейроморфного SoC BrainChip AKD1000 (Akida 2: 1.2 TOPS, 8 МБ SRAM, веса 1/2/4/8 бит). Footprint 15×15 мм соответствует canon корпусу BGA родителя (согласован с инкапсулянтом 15×15×1 и подложечным периметром декомпозиции); толщина 0.6 мм — середина типового диапазона IC-подложек 0.1–1.5 мм (NextPCB). Подложка разводит I/O кристалла под шаг шаров BGA для поверхностного монтажа на edge-устройствах.

Родитель: `izdelie_brainchip_akida_2` (подсистема: вычислительная).

## Принцип работы

Для edge-SoC подложка решает задачу перехода от КМОР-шага кристалла к технологичному шагу BGA (0.4–0.8 мм) без промежуточной платы: перераспределительные слои развивают I/O, земляные и питательные полигон-слои снижают импеданс питания нейроморфной фабрики. PTFE-основание даёт стабильную диэлектрическую проницаемость и низкие потери; промышленный стандарт для BGA — BT-ламинат (Tg ≥185°C, Dk ~4.0, КТР 3–8 ppm/°C по X-Y), согласованный по КТР с кремнием для ресурса шариков пайки при термоциклах (JEDEC). Термомеханическая развязка особенно важна для пассивно охлаждаемого edge-исполнения Akida.
