# Часть: часть_gr801_noel-v_risc-v_pins

## Описание

Шариковый массив BGA — внешние выводы радиационно-стойкого процессора GR801 (Cobham Gaisler: нейроморфный AI-движок GRAIN + одноядерный NOEL-V RISC-V) под органическим пакетом 23×23×1.5 мм (`часть_gr801_noel-v_risc-v_package`; семейство GR740 выпускается в CCGA625/CLGA625/PBGA625). Массив 22×22 = 484 шарика с шагом 1.0 мм и диаметром 0.4 мм (типовое соотношение 50–60 % шага); размах 21×0.1×... = 21.4 мм. Шарики — эвтектический Sn63/Pb37 (tпл 183 °C, материал базы `splav_sn-pb`); для бессвинцовой сборки используется SAC305 (в базе материалов отсутствует). Масса — расчёт: 484 × V(Ø0.4 мм) × ρ = 8400 кг/м³.

## Принцип работы

484 шарика распределяют питание, сигнальные цепи NOEL-V (SDR/DDR-интерфейс памяти, SpaceWire, CAN, UART/SPI) между пакетом и платой. Массированный массив под рад-стойким чипом дублирует цепи питания для равномерного подвода тока при переключениях нейроморфного движка GRAIN. Оплавленные шарики задают высоту стояния ~0.3 мм; при орбитальной эксплуатации важна стойкость массива к термоциклированию (−55…+125 °C) — эвтектический припой с однородной микроструктурой снижает риск усталостных трещин.
