# Часть: часть_halve_pcb

## Описание

Несущая плата HALVE в форм-факторе M.2 2280: 22×80 мм, толщина PCB 0.8 мм ±10 % по спецификации NGFF; компоненты до 1.5 мм на сторону, компактный edge-AI модуль нейроморфного процессора.
