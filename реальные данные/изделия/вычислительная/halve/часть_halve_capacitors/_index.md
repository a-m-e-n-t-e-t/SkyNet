# Часть: часть_halve_capacitors

## Описание

Блокировочные MLCC-конденсаторы типоразмера 0805 (корпус 2.0×1.25×0.8 мм) для фильтрации цепей питания нейроморфного процессора HALVE: Murata GRM21BR60J106ME19, 10 мкФ, 6.3 В, X5R, ±20%. Сглаживание импульсных токов при событийной активности нейронов; X5R-диэлектрик на BaTiO3 с Ni-внутренними электродами и медной торцевой терминацией.

## Принцип работы

MLCC BME-конструкции: слои BaTiO3-керамики (X5R, класс II) чередуются с Ni-электродами, торцевая Cu-терминация с Ni/Sn-покрытием обеспечивает пайку оплавлением; ёмкость формируется параллельным включением сегнетоэлектрических слоёв.
