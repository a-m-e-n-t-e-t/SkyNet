# Часть: часть_pcm_controller

## Описание

Контроллер PCM-кристалла (чип 12×12×1 мм, архитектура 3D XPoint класса Intel Optane с ячейками между metal 4/metal 5 по TechInsights 2017): кремниевый блок управления 1.8×1.3×0.4 мм с планировщиком программирования (SET-импульсы с наклонным фронтом, RESET с закалкой). Масса ≈0.7 г (7% номинала 10 г).

## Принцип работы

Контроллер транслирует адрес в выборку слова/битиры и формирует профили импульсов: RESET — короткий сильный импульс аморфизации, SET — более длинный с наклонным фронтом кристаллизации; verify-чтение после каждой операции удерживает распределение сопротивлений ячеек в окне считывания.
