# Часть: часть_pcm_cell_array

## Описание

Массив PCM-ячеек из GST (Ge2Sb2Te5): ячейки толщиной 20 нм при ширине 66–124 нм; обратимый переход аморфное↔кристаллическое с контрастом сопротивления ~5 порядков.
