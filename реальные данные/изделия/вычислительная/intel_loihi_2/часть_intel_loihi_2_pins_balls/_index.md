# Часть: часть_intel_loihi_2_pins_balls

## Описание

Шариковый массив BGA (Ball Grid Array) — внешние выводы процессора Intel Loihi 2, расположенные на нижней стороне корпусной подложки `часть_intel_loihi_2_substrate` (10×10×0.6 мм). Массив 11×11 = 121 шарик с шагом 0.8 мм — стандартный шаг FBGA по JEDEC Design Guide 4.5; диаметр шарика 0.4 мм (50 % шага, типовое соотношение для пайки оплавлением). Шарики изготовлены из эвтектического припоя Sn63/Pb37 (tпл 183 °C) — материал базы репозитория `splav_sn-pb`; для бессвинцовой сборки применяется SAC305, отсутствующий пока в базе материалов. Масса массива — расчёт: 121 × V(шарик Ø0.4 мм) × ρ = 8400 кг/м³.

Родитель: `izdelie_intel_loihi_2` (подсистема: вычислительная).

## Принцип работы

При монтаже на плату-носитель (76×76 мм, `часть_intel_loihi_2_pcb`) шарики оплавляются в печи и образуют одновременно механическое крепление и электрическое соединение подложки с платой. Высота стояния оплавленного шарика (~0.3 мм) определяет паразитную индуктивность и сопротивление цепей питания — критично для асинхронного массива нейронных ядер с резкими токами при спайковой активности. Массив 121 шарик покрывает питание (несколько доменов), SPI/JTAG-управление, периферийный ввод-вывод и межчиповые линии для многочиповых систем (Kapoho Point — 8 чипов, Hala Point — до 1152 чипов).
