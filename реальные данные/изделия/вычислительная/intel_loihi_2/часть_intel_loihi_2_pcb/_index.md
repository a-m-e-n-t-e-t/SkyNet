# Часть: часть_intel_loihi_2_pcb

## Описание

Несущая плата Kapoho Point для чипов Loihi 2: ультракомпактная плата около 3×3 дюйма (76×76 мм, 'размером с кредитную карту' — М. Дэвис), четыре чипа Loihi 2 (Intel 4) на верхней стороне; ламинат FR-4 толщиной 1.6 мм.
