# Часть: часть_ibm_northpole_package

## Описание

Корпус FCBGA (перевёрнутый кристалл на органической подложке с медным теплораспределителем): референс-класс FCBGA-2743 — пакет 55×55 мм NVIDIA A100 PCIe для кристалла 826 мм², ближайший публичный аналог 800-мм² NorthPole (размеры пакета IBM не раскрывает). Высота сборки ~3.0 мм = подложка 1.2 + кристалл 0.775 + теплораспределитель 1.0 мм (см. части substrate/die/thermal_spreader) + underfill/припой. Заполнение — кварценаполненный эпоксидный компаунд: капиллярный underfill в зазоре кристалл-подложка и формовочный компаунд вокруг бампов. Канон 0.02 кг согласуется с суммой реальных компонентов ~18 г (подложка ~8 + Cu-IHS 7.2 + кристалл 1.4 + компаунд ~1.5 г).

## Принцип работы

Корпус FCBGA выполняет три функции: электрический переход кристалл→карта PCIe через массив BGA (2743 вывода в референсе FCBGA-2743), механическая защита кристалла 800 мм² и отвод тепла через Cu-IHS — ASE классифицирует такой конструктив как термически усиленный HFC-BGA (FCBGA + heat spreader из Cu/Al). Ключевой материал заполнения — кварценаполненный эпоксидный underfill: он жёстко связывает кристалл (CTE 2.6 ppm/K) с органической подложкой (14–17 ppm/K), гася сдвиг в C4-микробамперах при термоциклировании −55…+150 °C по JESD22-A104; класс материала — Henkel Loctite ECCOBOND UF 9000AG с высокой Tg и CTE <20 ppm/K.
