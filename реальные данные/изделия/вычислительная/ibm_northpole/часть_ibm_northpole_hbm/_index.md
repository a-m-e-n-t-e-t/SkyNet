# Часть: часть_ibm_northpole_hbm

## Описание

HBM-подсистема памяти нейроморфного сопроцессора IBM NorthPole: 3D-стек DRAM класса HBM3. Конструктив — реальный референс 8-Hi стека Micron/SK hynix: восемь DRAM-кристаллов 16 Gb, соединённых сквозными кремниевыми переходами (TSV), на кремниевой базовой пластине (base logic die); ширина шины 1024 бита, интерфейс JEDEC JESD238 (HBM3, 6.4 Gb/s/pin). Типовой footprint стека ~11×10 мм при высоте 8-high сборки ~1.2 мм — по данным Micron («a single stack … in a package only about 11 mm × 10 mm») и презентации SK hynix Hot Chips 28 (package dimensions HBM Gen1/Gen2).

Масса 0.01 кг — канон декомпозиции (доля 0.15 от родителя); реальная масса 8-Hi стека ~1–2 г — каноническое значение агрегирует стек с теплоотводом-интерпозером. Каноническое тепловыделение 1 Вт сохранено (теплопростой резервного стека). Габарит 11×10×1.2 мм — оценка по package Micron/SK hynix, не дефолтный fallback.

Родитель: `izdelie_ibm_northpole` (подсистема: вычислительная).
