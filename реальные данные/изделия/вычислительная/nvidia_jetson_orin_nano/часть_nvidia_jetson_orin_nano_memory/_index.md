# Часть: часть_nvidia_jetson_orin_nano_memory

## Описание

Чип LPDDR5 SDRAM — оперативная память модуля Jetson Orin Nano (8 ГБ, 64-битная шина, до 102 ГБ/с): типоразмер TFBGA 200-ball 11.5×13×0.6 мм — стандартный корпус LPDDR5 x32 по семейству стандартов JEDEC JESD209-5C (пакеты LFBGA/TFBGA/WFBGA в каталоге Micron LPDDR5). Питание VDD1 0.5 В, VDD2/VDDQ ~1.1 В, скорости до 6400 MTPS; масса ~0.27 г (расчёт по объёму 89.7 мм³ × ~3.0 г/см³).

## Принцип работы

LPDDR5 работает в реверсивном режиме тактирования (clock forwarding от контроллера SoC), DVFS памяти согласован с DVFS ядер: при снижении нагрузки частота шины падает со снижением VDD1 до 0.5 В — главное преимущество энергоэффективности LPDDR5 перед LPDDR4x (~20 % меньше энергия на бит). Короткая трассировка внутри модуля между SoC и чипами памяти (шаг 0.5 мм, ~200 шариков) критична для 6400 MTPS: цельность сигналов поддерживается калибровкой DQS и обучением тракта при инициализации.
