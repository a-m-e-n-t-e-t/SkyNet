# Часть: часть_nvidia_jetson_orin_nano_pmic

## Описание

PMIC (Power Management IC) модуля Jetson Orin Nano — контроллер питания, распределяющий входное напряжение VDD_IN 5 В несущей платы («Main power — Supplies PMIC and other registers», таблица пинов DS-11105-001 v1.2) по доменам модуля: ядра SoC (GPU+CPU, режимы 7/15 Вт для 8GB и 7/10 Вт для 4GB), LPDDR5-память, eMMC и интерфейсный ввод-вывод (все интерфейсы модуля опираются только на on-module voltage rails). Пластиковый QFN-корпус 6×6×0.9 мм (типовой для модульных PMIC — оценка, точные BOM-позиции NVIDIA не публикует); масса ~81 мг (расчёт по объёму компаунда ~2.5 г/см³). Управление — PMC (Power Management Controller) SoC: контроль переходов напряжений при DVFS-переходах, power-gating неактивных доменов; телеметрия мощности — один 3-канальный INA (шины CPU_GPU_CV, Core и вход модуля).

## Принцип работы

PMIC синхронизирует последовательность включения доменов (power sequencing выполняется на модуле, DS-11105 §3.6) и через PMC отдаёт платформенному менеджеру питания управление переходами напряжений SoC при DVFS-переходах — для энергоэффективных режимов 7/15 Вт Jetson Orin Nano. Многофазная топология распределяет ток ядер по каналам, снижая пульсации; телеметрия 3-канального INA (CPU_GPU_CV, Core, вход модуля) даёт платформе данные для бюджетирования мощности; тепловыделение регуляторов — часть бюджета модуля, снимаемая радиатором через PCB-полигоны. Защиты (OVP/UVP/OCP/OTP) и watchdog удерживают модуль в безопасном состоянии при питании от нестабильных источников (бортовые 5 В носителей); опциональная батарея PMIC_BBAT поддерживает RTC напрямую от onboard PMIC при отсутствии VDD_IN.
