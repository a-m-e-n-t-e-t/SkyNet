# Часть: часть_nvidia_jetson_orin_nano_connectors

## Описание

Комплект разъёмов и жгутов изделия: Разъём питания Jetson Orin Nano — DC barrel jack Ø5.5×2.5 мм: вход 9–19 В, латунные контакты, PCB-монтаж с фиксацией. Референсное исполнение — DC-гнездо barrel Ø5.5/2.5 мм (серия Kycon KLDX, оценка). Габариты 9×6.5×10.5 мм, масса 0.008 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

## Принцип работы

Стыковка по схеме «вилка/розетка» (DC-гнездо barrel Ø5.5/2.5 мм (серия Kycon KLDX, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
