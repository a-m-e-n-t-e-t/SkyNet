# Часть: часть_nvidia_jetson_orin_nano_soc

## Описание

Системный кристалл (SoC) NVIDIA Orin в составе модуля Jetson Orin Nano: 6 ядер Arm Cortex-A78AE, GPU Ampere архитектуры (1024 CUDA-ядра, 32 Tensor-ядра) и аппаратные ускорители PVA/DLA. SoC Orin — единый кристалл для всей линейки Jetson Orin (AGX Orin / Orin NX / Orin Nano), в младших модулях часть кластеров отключена: площадь кристалла 200 мм² (~14.1×14.1 мм), корпус flip-chip BGA (FCBGA-2644 по классификации TechPowerUp), 8 нм техпроцесс Samsung. Габарит части 14.1×14.1×2.0 мм — кристалл с высотой FCBGA-пакета ~2 мм (оценка); NVIDIA не публикует размеры корпуса SoC отдельно, носитель — модуль SO-DIMM 69.6×45 мм по datasheet DS-11105-001.

Масса 0.01 кг — канон декомпозиции; реальный пакет SoC с подложкой ~5–8 г. Габарит — оценка по die size 200 мм² и типовой высоте FCBGA, не дефолтный fallback.

Родитель: `izdelie_nvidia_jetson_orin_nano` (подсистема: вычислительная).
