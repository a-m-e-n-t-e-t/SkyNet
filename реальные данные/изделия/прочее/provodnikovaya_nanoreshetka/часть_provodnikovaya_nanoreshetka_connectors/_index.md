# Часть: часть_provodnikovaya_nanoreshetka_connectors

## Описание

Комплект разъёмов и жгутов изделия: Микростык проводниковой нанорешётки — Nano-D 9-контактный (биполярные драйверы строк/столбцов, калибровочный регистр). Референсное исполнение — Nano-D (Omnetics), 9 контактов, шаг 0.635 мм (оценка). Габариты 9.7×5.6×4.8 мм, масса 0.005 кг — оценка по типовым изделиям класса. Материал — becu: бериллиевая бронза (контакты, CuBe; золотое покрытие по Ni).

Родитель: `izdelie_provodnikovaya_nanoreshetka` (подсистема: прочее).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Nano-D (Omnetics), 9 контактов, шаг 0.635 мм (оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
