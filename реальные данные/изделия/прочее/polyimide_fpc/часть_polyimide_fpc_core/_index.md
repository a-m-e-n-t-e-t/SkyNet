# Часть: часть_polyimide_fpc_core

## Описание

Полиимидная гибкая плата (FPC) — 2–4 слоя с медными проводниками: межблочные динамические соединения. Референсное исполнение — полиимидная FPC (120×90, многослойная). Габариты 120×90×1 мм, масса 0.025 кг — паспортные данные (полиимидная FPC). Материал — poliimid: полиимид (гибкая подложка).
