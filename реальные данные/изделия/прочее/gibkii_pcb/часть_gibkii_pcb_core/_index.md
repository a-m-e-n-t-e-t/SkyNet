# Часть: часть_gibkii_pcb_core

## Описание

Гибкая печатная плата — полиимидная подложка (25–125 мкм) с медными проводниками: динамические изгибы до 10⁶ циклов. Референсное исполнение — гибкая печатная плата (полиимид, 100×80, двухслойная).
