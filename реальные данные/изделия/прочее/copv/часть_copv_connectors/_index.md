# Часть: часть_copv_connectors

## Описание

Комплект разъёмов и жгутов изделия: Герметичные проходные разъёмы instrumentation COPV — MS3450 размера 16: цепи датчиков давления/температуры баллона со стеклянной герметизацией вводов. Референсное исполнение — MIL-DTL-5015 (MS3450), размер корпуса 16, герметичный (оценка). Габариты 33.3×33.3×45 мм, масса 0.12 кг — оценка по типовым изделиям класса. Материал — al_6061-t6: алюминиевый сплав 6061-T6 (корпуса).

Родитель: `izdelie_copv` (подсистема: прочее).

## Принцип работы

Стыковка по схеме «вилка/розетка» (MIL-DTL-5015 (MS3450), размер корпуса 16, герметичный (оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
