# Часть: часть_slm_eos_m290_mounting

## Описание

Комплект фиксации платформы построения SLM-станции EOS M 290 (зона построения 250×250×325 мм): 8× винтов M10×30 DIN 912 из нержавеющей стали A2-70 прижимают съёмную платформу построения к базовой плите, 4 клиновые стопорные планки снимают люфт по периметру 250×250 мм. Комплект рассчитан на замену платформы между циклами печати без выхода станка из вакуумного режима (инертный аргон, <0,1 % O₂). Масса комплекта ≈ 210 г.

Родитель: `izdelie_slm_eos_m290` (подсистема: прочее).

## Принцип работы

Винтовой клиновой зажим: равномерный момент затяжки M10 (≈45 Н·м) по 8 точкам прижимает платформу к базовой плите; клиновые планки компенсируют допуск посадочного паза и исключают смещение при рехонометрии лазера.
