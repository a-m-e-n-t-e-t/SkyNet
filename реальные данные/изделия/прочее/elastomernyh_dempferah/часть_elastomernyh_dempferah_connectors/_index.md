# Часть: часть_elastomernyh_dempferah_connectors

## Описание

Комплект разъёмов и жгутов изделия: Стык эластомерных демпферов — pogo-pin разъём 4-контакта: безстыковое подключение датчиков вибрации на демпфированной плате (допуск смещения ±0.5 мм). Референсное исполнение — Spring-Loaded pogo-pin, 4 контакта (Mill-Max, оценка). Габариты 6.4×6.4×8 мм, масса 0.003 кг — оценка по типовым изделиям класса. Материал — becu: бериллиевая бронза (контакты, CuBe; золотое покрытие по Ni).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Spring-Loaded pogo-pin, 4 контакта (Mill-Max, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
