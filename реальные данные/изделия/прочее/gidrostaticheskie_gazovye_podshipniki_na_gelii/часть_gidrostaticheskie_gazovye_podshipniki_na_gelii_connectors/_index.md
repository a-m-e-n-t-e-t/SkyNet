# Часть: часть_gidrostaticheskie_gazovye_podshipniki_na_gelii_connectors

## Описание

Комплект разъёмов и жгутов изделия: Разъём датчиков газостатического подшипника на гелии — Deutsch DT06-2S (уплотнения IP68, вибростойкая фиксация): датчик давления наддува. Референсное исполнение — Deutsch DT 2-контактный (DT06-2S, корпус PA66, оценка). Габариты 36.3×24.6×17.3 мм, масса 0.03 кг — оценка по типовым изделиям класса. Материал — neilon_6_66: нейлон 6/6 (PA66, корпус разъёма).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Deutsch DT 2-контактный (DT06-2S, корпус PA66, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
