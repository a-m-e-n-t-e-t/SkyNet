# Часть: часть_ads-b_priemnik_core

## Описание

Приёмник ADS-B (1090 МГц) для приёма телеметрии воздушных целей — РЧ-фронтенд с SDR-демодулятором и USB/LVDS-выходом. Референсное исполнение — приёмник ADS-B класса RTL-SDR/FlightAware USB-стика (типовые ~90×46×14 мм, 50 г). Габариты 90×46×14 мм, масса 0.05 кг — паспортные данные (приёмник ADS-B класса RTL-SDR/FlightAware USB-стика). Материал — al_6061-t6: конструкционный алюминиевый сплав 6061-T6.

Родитель: `izdelie_ads-b_priemnik` (подсистема: сенсоры).

## Принцип работы

Приёмный тракт ADS-B: антенный вход (MCX/SMA, 50 Ом) → малошумящий РЧ-фронтенд и тюнер R820T2 (1090 МГц ES / 978 МГц UAT) → демодулятор RTL2832U и декодирование Mode S/ES-пакетов → цифровой выход (USB/RS-232/MAVLink) к автопилоту. Основной источник тепла узла — РЧ-тюнер и демодулятор: тюнер R820T2 потребляет 120–178 мА при 3.3 В (0.4–0.6 Вт), типовой USB-приёмник класса RTL-SDR в сборе — 260–280 мА при 5 В (~1.4 Вт); канон 1.0 Вт — внутри реального диапазона 0.75–1.4 Вт (pingRX Pro — 0.75 Вт).
