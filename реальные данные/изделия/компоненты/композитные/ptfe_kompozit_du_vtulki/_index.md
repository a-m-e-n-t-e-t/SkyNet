# Материал: PTFE-композит DU-втулок (metal-polymer self-lubricating)

## Описание

DU-втулка — тонкостенный самосмазывающийся подшипник скольжения из трёх связанных слоёв: низкоуглеродистая стальная подложка (0.7–2.0 мм) для прочности и точной посадки, спечённая пористая бронза (0.20–0.35 мм) для теплопроводности и адгезии, рабочий слой PTFE с наполнителями (0.01–0.03 мм) для сухого трения без смазки. Конструкция DU (Glacier, ныне GGB) — родоначальник класса metal-polymer plain bearings; выпускается миллионными тиражами эквивалентными производителями (JBM-10, VIIPLUS, Slidura и др.). Работает всухую в диапазоне −195…+280 °C, не требует обслуживания весь срок службы узла. Пара трения: вал (сталь, Ra ≤ 0.8, твёрдость ≥ 50 HRC для тяжёлых режимов) по PTFE-слою.

## Физические свойства

- Плотность: **≈7500 кг/м³** — расчётная оценка по слоистой композиции типовой втулки (сталь ~83% толщины × 7850 + пористая бронза ~15% × 7040 + PTFE ~2% × 2200); производители в TDS плотность металлополимера не публикуют.
- Конструкция (JBM-10 / DU-B, bushingmfg, metalpolymerbearings): стальная подложка 0.7–2.0 мм (Cu/Sn-плакировка против коррозии), бронза 0.20–0.35 мм, PTFE+наполнители 0.01–0.03 мм.
- Толщина стенки стандартных втулок по ISO 3547: 1.0–2.5 мм (série E/D).

## Механические характеристики (подшипниковые)

- Макс. статическая нагрузка: **250 Н/мм²**; динамическая (низкая скорость/качание): **140 Н/мм²**; вращение: **60 Н/мм²** (Slidura TDS, bushingmfg).
- PV-предел (сухо): **1.8 Н/мм²·м/с** долговременно, **3.6** кратковременно; смазка повышает лимит.
- Макс. скорость скольжения: **2 м/с** (сухо), >3 м/с (со смазкой).
- Коэффициент трения (сухо): **0.02–0.20** (приработка к валу снижает трение к нижней границе).
- Выше 100 °C — увеличить монтажный зазор (CTE 11×10⁻⁶/K, рекомендация производителя).

## Тепловые свойства

- Рабочий диапазон: **−195…+280 °C** (bushingmfg: −195…+280; Slidura TDS: −200…+280) — единственный массовый подшипниковый материал для криогенных температур без замерзающей смазки.
- Теплопроводность композита: **42 Вт/(м·К)** (Slidura TDS; эквиваленты GGB-совместимых марок указывают 40–60 Вт/(м·К) после приработки) — бронзовый промежуточный слой отводит тепло трения в стальную подложку и седло.
- CTE: **11×10⁻⁶ /K** (Slidura TDS) — близко к стали, что предотвращает отслоение слоя при термоциклировании.

## Эксплуатационные характеристики

- Самосмазываемость: PTFE-слой переносит плёнку на вал при приработке; работа «всухую» без обслуживания.
- Химическая инертность PTFE: вода, топлива, растворители, криожидкости; не загрязняет продукт (пищевые/текстильные линии).
- Варианты подложки: сталь (Cu/Sn-плакированная), бронза CuSn8 (коррозионная стойкость + теплоотвод), нержавеющая AISI 304/316 (мойка, пищевое/медицинское); соседний тип DX — POM-покрытие 0.3–0.5 мм с лунками под запас смазки для более скоростных узлов.
- Классический DU содержит свинец в рабочем слое; современные марки DU-B/lead-free — бессвинцовые (RoHS).

## Технологии получения

- Лента-полуфабрикат: плакированная сталь → спекание бронзового порошка → прокатка/пропитка PTFE-суспензией с наполнителями → гибка втулок в размер ISO 3547 (разъёмные wrapped bushings) или штамповка фланцевых/торцевых форм.
- Запрессовка в седло с натягом (калибровка шаром после запрессовки).
