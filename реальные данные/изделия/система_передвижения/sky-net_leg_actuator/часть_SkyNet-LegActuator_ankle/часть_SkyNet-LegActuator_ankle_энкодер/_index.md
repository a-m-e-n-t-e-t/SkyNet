# Часть: часть_SkyNet-LegActuator_ankle_энкодер

## Описание

Пара абсолютных магнитных энкодеров голеностопа — обратная связь по углам pitch/roll. Родитель: `часть_SkyNet-LegActuator_ankle` (двухосевой дифференциальный привод голеностопа, pitch+roll, момент ~120 Н·м, масса модуля 0.875 кг).

## Принцип работы

Кольцевой магнит на валу каждого двигателя проходит над чипом Холла: абсолютный угол вала → FOC-коммутация фаз и обратная связь по положению pitch/roll без инкрементального счёта
