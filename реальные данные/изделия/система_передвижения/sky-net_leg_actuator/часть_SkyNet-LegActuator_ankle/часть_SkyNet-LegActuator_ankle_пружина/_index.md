# Часть: часть_SkyNet-LegActuator_ankle_пружина

## Описание

Series-elastic торсионная пружина голеностопа (серия C) — гашение удара при постановке стопы. Родитель: `часть_SkyNet-LegActuator_ankle` (двухосевой дифференциальный привод голеностопа, pitch+roll, момент ~120 Н·м, масса модуля 0.875 кг).

## Принцип работы

Торсионная деформация пружины между выходным фланцем дифференциала и посадкой стопы: при ударе постановки стопы угол упруго отклоняется, пиковый момент редуктора ограничен; серия C — расчётная жёсткость для массы робота 90 кг
