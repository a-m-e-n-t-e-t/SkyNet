# Часть: часть_SkyNet-LegActuator_hip_тормоз

## Описание

Пружинный нормально-замкнутый удерживающий тормоз тазобедренного привода: пакет пружин сжимает якорь с фрикционными накладками к зубчатому диску; снятие — подачей тока в катушку. Держит звено при обесточивании (безопасность позы, ISO 9283). Масса 0.13 кг (10.5% родителя 1.225 кг).

Родитель: `часть_SkyNet-LegActuator_hip` (подсистема: система_передвижения).

## Принцип работы

В исходном состоянии пакет тарельчатых пружин ASTM A229 прижимает якорь с фрикционными накладками к зубчатому диску на валу — момент передаётся без скольжения (нормально-замкнутая схема безопасна при потере питания). При подаче тока катушка тянет якорь, преодолевая пружины, — вал свободен и двигатель работает; при обесточивании пружины мгновенно возвращают тормоз. Тепловыделение в удержании отсутствует (нет относительного движения).

## Состав

Атомарная часть (неделимый, уровень 3): закупочный тормозной модуль (пружины+якорь+диск+катушка), регулировка и замена — целиком. Атомарность по чек-листу F34: подтип «тормоз».
