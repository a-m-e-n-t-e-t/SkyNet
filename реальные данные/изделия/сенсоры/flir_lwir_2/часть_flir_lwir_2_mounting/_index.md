# Часть: часть_flir_lwir_2_mounting

## Описание

Люлька LWIR-ядра Tau 2 (корпус ~43×43×33 мм, ~100 г без объектива по spec 102-PS242-40): алюминиевая плита 55×55×5 мм с 4× резьбовыми M2.5 по посадочным отверстиям ядра и центральным окном Ø38 мм под объектив. Масса ≈18 г (3.6% номинала 0.5 кг).

## Принцип работы

Ядро крепится 4× M2.5 по штатным точкам корпуса Tau 2 (IDD FLIR) — окно не перекрывает конус объектива, плита отводит тепло от задней крышки и держит оптическую ось перпендикулярно базовой плоскости носителя.
