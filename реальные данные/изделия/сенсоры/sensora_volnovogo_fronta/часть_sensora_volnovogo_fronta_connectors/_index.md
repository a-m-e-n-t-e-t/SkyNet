# Часть: часть_sensora_volnovogo_fronta_connectors

## Описание

Комплект разъёмов и жгутов изделия: ВЧ-стык датчика волнового фронта Шэка–Гартмана — TNC с резьбовой стыковкой (стабильный импеданс при вибрациях для адаптивной оптики). Референсное исполнение — TNC резьбовой ВЧ-разъём (IEC 60169-7, 50 Ом). Габариты 14.3×14.3×21.3 мм, масса 0.018 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_sensora_volnovogo_fronta` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (TNC резьбовой ВЧ-разъём (IEC 60169-7, 50 Ом)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
