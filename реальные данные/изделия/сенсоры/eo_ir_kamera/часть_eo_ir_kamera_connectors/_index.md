# Часть: часть_eo_ir_kamera_connectors

## Описание

Комплект разъёмов и жгутов изделия: Видеостык EO/IR камеры — BNC jack для аналогового видеовыхода TV-канала и синхронизации кадров. Референсное исполнение — BNC ВЧ-разъём (IEC 60169-8, 50 Ом, байонет). Габариты 14.5×14.5×27.5 мм, масса 0.02 кг — паспортные данные стандарта/каталога. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_eo_ir_kamera` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (BNC ВЧ-разъём (IEC 60169-8, 50 Ом, байонет)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
