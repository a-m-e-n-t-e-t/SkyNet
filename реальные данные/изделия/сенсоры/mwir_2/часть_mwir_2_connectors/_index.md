# Часть: часть_mwir_2_connectors

## Описание

Комплект разъёмов и жгутов изделия: Комплект соединителей MWIR-модуля (3–5 мкм) — Micro-D 31-контактный с экранированными парами для аналоговых выходов ФПУ. Референсное исполнение — Micro-D MIL-DTL-83513, корпус /01-31 (31 контакт). Габариты 36.30×5.33×8.13 мм, масса 0.04 кг — паспортные данные стандарта/каталога. Материал — becu: бериллиевая бронза (контакты, CuBe; золотое покрытие по Ni).

Родитель: `izdelie_mwir_2` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Micro-D MIL-DTL-83513, корпус /01-31 (31 контакт)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
