# Часть: часть_mwir_2_mounting

## Описание

Тепловой интерфейс-кронштейн MWIR-ядра Neutrino (охлаждаемый модуль с линейным криокулером по brochure): титановая планка Ti-6Al-4V 65×50×6 мм с 4× M3 по фланцу ядра и изолированной бобышкой отвода тепла криокулера. Масса ≈22 г (4.4% номинала 0.5 кг).

## Принцип работы

Ядро крепится к планке по фланцу с моментом по IDD — Ti-6Al-4V снижает теплоперетоки от корпуса к холодной зоне (низкая σ≈7 Вт/м·К), бобышка направляет тепло криокулера в радиатор, минуя FPA.

## Состав

Промежуточная часть (уровень 2). Дочерних частей нет.
