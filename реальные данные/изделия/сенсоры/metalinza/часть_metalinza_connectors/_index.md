# Часть: часть_metalinza_connectors

## Описание

Комплект разъёмов и жгутов изделия: Оптический стык металинзы с волоконным трактом — LC-duplex адаптер для подвода/отвода ИК-излучения по одномодовому волокну. Референсное исполнение — LC-duplex оптический адаптер (типовой корпус 15.2×10.2 мм). Габариты 15.2×10.2×12.5 мм, масса 0.008 кг — оценка по типовым изделиям класса. Материал — poliimid: полиимид (термопластичные корпуса/шлейфы).

Родитель: `izdelie_metalinza` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (LC-duplex оптический адаптер (типовой корпус 15.2×10.2 мм)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
