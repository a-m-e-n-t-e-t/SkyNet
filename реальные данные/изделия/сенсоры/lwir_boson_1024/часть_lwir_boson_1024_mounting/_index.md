# Часть: часть_lwir_boson_1024_mounting

## Описание

Адаптер крепления LWIR-ядра Boson+ 1024 (вес 7.5 г без линзы, 4× M1.6×0.35 на задней крышке): жёсткая пластина 32×32×4 мм из Ti-6Al-4V с окном под оптику и 4× резьбовыми посадками M1.6. Титан выбран для высокой изгибной жёсткости при малой массе (большой формат 1024 чувствителен к деформациям фокальной плоскости). Масса ≈18 г.

## Принцип работы

Крепление по штатной схеме Boson+: 4× винта M1.6×0.35 в заднюю крышку; жёсткая титановая пластина держит плоскостность посадки ядра при термокачаниях и вибрациях, передавая тепло на кронштейн через контактную площадку.

## Состав
