# Часть: часть_aesa_radar_core

## Описание

Передающий модуль AESA-радара — антенная плата с приёмо-передающими каналами, распределительной сетью и жидкостным теплосъёмом. Референсное исполнение — AESA-модуль (антенная плата с T/R-каналами, оценка по типовым X-полосным платам). Габариты 140×90×20 мм, масса 0.35 кг — оценка по типовым изделиям класса (AESA-модуль (антенная плата с T/R-каналами, оценка по типовым X-полосным платам)). Материал — al_6061-t6: конструкционный алюминиевый сплав 6061-T6.

Родитель: `izdelie_aesa_radar` (подсистема: сенсоры).
