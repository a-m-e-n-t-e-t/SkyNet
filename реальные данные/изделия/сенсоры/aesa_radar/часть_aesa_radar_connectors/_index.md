# Часть: часть_aesa_radar_connectors

## Описание

Комплект разъёмов и жгутов изделия: ВЧ-стык AESA-модуля — SMA bulkhead jack: тактовый/опорный сигнал и мониторный выход T/R-каналов. Референсное исполнение — SMA ВЧ-разъём (IEC 61169-15, 50 Ом, шестигранник 8 мм). Габариты 8×8×14 мм, масса 0.01 кг — паспортные данные стандарта/каталога. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_aesa_radar` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (SMA ВЧ-разъём (IEC 61169-15, 50 Ом, шестигранник 8 мм)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
