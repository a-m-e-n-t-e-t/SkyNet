# Часть: часть_flir_boson_640_connectors

## Описание

Комплект разъёмов и жгутов изделия: Комплект соединителей тепловизионного модуля FLIR Boson 640 — Micro-D жгут с 37 сигнальными цепями (видео LVDS, питание, UART). Референсное исполнение — Micro-D MIL-DTL-83513, корпус /01-37 (37 контактов, шаг 0.635 мм). Габариты 41.91×5.33×8.13 мм, масса 0.045 кг — паспортные данные стандарта/каталога. Материал — becu: бериллиевая бронза (контакты, CuBe; золотое покрытие по Ni).

Родитель: `izdelie_flir_boson_640` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Micro-D MIL-DTL-83513, корпус /01-37 (37 контактов, шаг 0.635 мм)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
