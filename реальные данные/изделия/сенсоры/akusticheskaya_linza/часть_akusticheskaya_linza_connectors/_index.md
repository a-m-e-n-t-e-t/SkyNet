# Часть: часть_akusticheskaya_linza_connectors

## Описание

Комплект разъёмов и жгутов изделия: ВЧ-стык акустической линзы с приёмным трактом — SMB jack для сигнала пьезоэлектрического приёмника ультразвукового диапазона. Референсное исполнение — SMB защёлкиваемый ВЧ-разъём (IEC 60169-15, 75 Ом). Габариты 9.5×9.5×11.8 мм, масса 0.008 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_akusticheskaya_linza` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (SMB защёлкиваемый ВЧ-разъём (IEC 60169-15, 75 Ом)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
