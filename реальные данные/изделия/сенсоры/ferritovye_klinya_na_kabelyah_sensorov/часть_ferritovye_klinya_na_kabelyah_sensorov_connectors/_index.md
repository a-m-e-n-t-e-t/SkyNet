# Часть: часть_ferritovye_klinya_na_kabelyah_sensorov_connectors

## Описание

Комплект разъёмов и жгутов изделия: Коммутационный разъём кабельного хозяйства сенсоров — D-sub DC-37, стальной корпус; рядом с ним на жгуте — ферритовые клип-фильтры подавления синфазных помех. Референсное исполнение — D-sub DC-37 (IEC 60603-2, размер D-корпуса 69.34×12.55 мм). Габариты 69.34×12.55×8.6 мм, масса 0.05 кг — паспортные данные стандарта/каталога. Материал — stal_st3: конструкционная сталь Ст3 (корпуса с цинковым покрытием).

Родитель: `izdelie_ferritovye_klinya_na_kabelyah_sensorov` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (D-sub DC-37 (IEC 60603-2, размер D-корпуса 69.34×12.55 мм)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
