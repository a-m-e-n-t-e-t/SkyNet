# Часть: часть_ferritovye_klinya_na_kabelyah_sensorov_core

## Описание

Клип-фильтры на ферритах для кабелей сенсоров — подавление синфазных РЧ-помех (демпфирование ВЧ-наводок). Референсное исполнение — ферритовые кольцевые фильтры на кабелях (клип-фильтр ~30×15×15). Габариты 30×15×15 мм, масса 0.02 кг — паспортные данные (ферритовые кольцевые фильтры на кабелях). Материал — magnitnaya_rezina_ferritovyi_poroshok: магнитная резина с ферритовым порошком.
