# Часть: часть_mwir_nbn_640_mounting

## Описание

Поддон-адаптер MWIR-модуля SCD Sparrow (XBn Blackbird 640×512, корпус 58×62×42 мм, 300 г): плита 70×66×5 мм с 4× отверстиями M3 по периметру габарита модуля и вырезом 30×30 для криокулерного теплового интерфейса снизу. Алюминий 6061-T6. Масса ≈62 г.

## Принцип работы

Модуль Sparrow фиксируется 4× винтами M3 к плите-поддону по штатным точкам корпуса; вырез снизу открывает зону холодного пальца криокулера, а плита распределяет нагрузку 300-граммового модуля на носитель без локальных перекосов FPA.
