# Часть: часть_ads-b_priemnik_connectors

## Описание

Комплект разъёмов и жгутов изделия: Антенный ВЧ-стык приёмника ADS-B (1090 МГц) — MCX snap-on jack для компактной антенны на бортовой платформе. Референсное исполнение — MCX ВЧ-разъём (IEC 61169-36, 50 Ом, snap-on). Габариты 6.35×6.35×11.9 мм, масса 0.005 кг — паспортные данные стандарта/каталога. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_ads-b_priemnik` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (MCX ВЧ-разъём (IEC 61169-36, 50 Ом, snap-on)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Собственное тепловыделение — только I²R-потери на контактных сопротивлениях: миллиомный диапазон при токах приёмника до 0.3 А даёт менее 5 мВт — пренебрежимо мало, канон 0 Вт.
