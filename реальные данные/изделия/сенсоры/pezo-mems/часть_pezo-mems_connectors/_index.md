# Часть: часть_pezo-mems_connectors

## Описание

Комплект разъёмов и жгутов изделия: Промышленный стык пьезо-MEMS элемента — M8 3-контактный (питание, аналоговый выход) для интеграции в вибромониторинг. Референсное исполнение — M8 круговой, 3 контакта (IEC 61076-2-104, корпус с резьбой M8×1, оценка). Габариты 15×15×35 мм, масса 0.03 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_pezo-mems` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (M8 круговой, 3 контакта (IEC 61076-2-104, корпус с резьбой M8×1, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
