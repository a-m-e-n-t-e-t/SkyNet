# Часть: часть_ultrakorotkoimpulsnye_lazery_connectors

## Описание

Комплект разъёмов и жгутов изделия: ВЧ-стык ультракороткоимпульсного лазера с фотодиодным мониторчиком — 4.3-10 mini-DIN (малая PIM, стабильность до 18 ГГц). Референсное исполнение — 4.3-10 mini-DIN ВЧ-разъём (50 Ом, корпус Ø16 мм, оценка). Габариты 16×16×30 мм, масса 0.025 кг — оценка по типовым изделиям класса. ## Принцип работы

Стыковка по схеме «вилка/розетка» (4.3-10 mini-DIN ВЧ-разъём (50 Ом, корпус Ø16 мм, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
