# Часть: часть_mems-imu_core

## Описание

MEMS-инерциальный модуль — 3-осевые гироскопы и акселерометры на одном кристалле (BMI088 класс: ±300°/с, 24g). Референсное исполнение — Bosch BMI088 (LGA 3×4.5×0.95 мм, ~0.2 г). Габариты 3×4.5×1 мм, масса 0.0002 кг — паспортные данные (Bosch BMI088). Материал — si: монокристаллический кремний.

Родитель: `izdelie_mems-imu` (подсистема: сенсоры).
