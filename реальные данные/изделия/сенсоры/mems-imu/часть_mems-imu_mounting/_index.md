# Часть: часть_mems-imu_mounting

## Описание

Виброизолированный кронштейн MEMS-IMU (ядро Bosch BMI088, LGA 3.0×4.5×0.95 мм, 16-pin): алюминиевая рама 45×35×10 мм с платой-носителем, 4× демпферными опорами M3 и зоной отгиба креплений. Масса ≈25 г (5% номинала 0.5 кг).

## Принцип работы

Плата с BMI088 сидит на раме через демпферы — корпусной резонанс вынесен выше рабочего диапазона гироскопа по рекомендации Bosch; рама отсекает изгибы несущей конструкции, которые в LGA-корпусе без развязки дают смещение нуля.
