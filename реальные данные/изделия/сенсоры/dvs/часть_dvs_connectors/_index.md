# Часть: часть_dvs_connectors

## Описание

Комплект разъёмов и жгутов изделия: Силовой/сигнальный разъём камеры DVS (DAVIS346 класс) — M12 8-контактный: питание 12/24 В, Ethernet 100BASE-TX для потока событий. Референсное исполнение — M12 круговой A-code, 8 контактов (IEC 61076-2-101, корпус с резьбой M12×1). Габариты 19.5×19.5×52 мм, масса 0.045 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_dvs` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (M12 круговой A-code, 8 контактов (IEC 61076-2-101, корпус с резьбой M12×1)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
