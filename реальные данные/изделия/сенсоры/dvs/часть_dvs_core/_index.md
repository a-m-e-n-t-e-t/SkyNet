# Часть: часть_dvs_core

## Описание

Динамический сенсор зрения (DVS/DAVIS) — пиксели реагируют только на изменение яркости (микросекундная задержка, 120 дБ динамический диапазон). Референсное исполнение — камера DVS класса iniVation DAVIS346 (~50×48×35 мм). Габариты 50×48×35 мм, масса 0.09 кг — паспортные данные (камера DVS класса iniVation DAVIS346). Материал — al_6061-t6: конструкционный алюминиевый сплав 6061-T6.

Родитель: `izdelie_dvs` (подсистема: сенсоры).
