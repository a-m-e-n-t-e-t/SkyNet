# Часть: часть_kaskadnyi_stirling-kriokuler_connectors

## Описание

Комплект разъёмов и жгутов изделия: Герметичные проходные соединители каскадного стирлинг-криоохладителя — Micro-D 21-контактный со стеклянной герметизацией для цепей компрессора и датчиков температуры. Референсное исполнение — Micro-D MIL-DTL-83513, корпус /01-21 (21 контакт, герметичное исполнение). Габариты 26.16×5.33×8.13 мм, масса 0.03 кг — паспортные данные стандарта/каталога. Материал — becu: бериллиевая бронза (контакты, CuBe; золотое покрытие по Ni).

Родитель: `izdelie_kaskadnyi_stirling-kriokuler` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Micro-D MIL-DTL-83513, корпус /01-21 (21 контакт, герметичное исполнение)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
