# Часть: часть_tverdotelnyi_mmwave_radar_connectors

## Описание

Комплект разъёмов и жгутов изделия: ВЧ-стык твердотельного ммW-радара (IWR6843 класс) — SMP для антенно-фидерного тракта 60–81 ГГц. Референсное исполнение — SMP ВЧ-разъём (50 Ом, корпус Ø5.7 мм, оценка). Габариты 5.7×5.7×9.5 мм, масса 0.004 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

## Принцип работы

Стыковка по схеме «вилка/розетка» (SMP ВЧ-разъём (50 Ом, корпус Ø5.7 мм, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
