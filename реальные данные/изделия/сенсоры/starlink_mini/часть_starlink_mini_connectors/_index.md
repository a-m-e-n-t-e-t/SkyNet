# Часть: часть_starlink_mini_connectors

## Описание

Комплект разъёмов и жгутов изделия: ВЧ-стык антенного модуля Ku-диапазона (Starlink Mini класс) — SMPM с врезным соединением (blind-mate) для ФАР-плат без переходных кабелей. Референсное исполнение — SMPM микроминиатюрный ВЧ-разъём (50 Ом, корпус Ø3.7 мм, оценка). Габариты 3.7×3.7×8 мм, масса 0.003 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_starlink_mini` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (SMPM микроминиатюрный ВЧ-разъём (50 Ом, корпус Ø3.7 мм, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
