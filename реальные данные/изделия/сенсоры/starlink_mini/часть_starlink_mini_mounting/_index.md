# Часть: часть_starlink_mini_mounting

## Описание

Откидная опора-кикстенд терминала (антенна Starlink Mini класса 1.10 кг, кикстенд +0.06 кг по спецификации): штанга из нержавеющей стали AISI 304 240×30×12 мм с осевым шарниром и упорной полкой под два угла наклона. Масса ≈25 г (5% номинала 0.5 кг).

## Принцип работы

Штанга вращается на осевом шарнире и садится полкой в один из упоров — распор между корпусом и основанием держит расчётный угол возвышения ФАР без отдельного кронштейна; нержавеющая сталь держит осевой люфт при ветровой нагрузке и допускает складывание для транспортировки.
