# Часть: часть_pmut_core

## Описание

Пьезоэлектрический MEMS-ультразвуковой преобразователь (PMUT) — тонкая мембрана с AlN: воздушный ультразвук, тональная визуализация. Референсное исполнение — PMUT-массив (8×8×1). Габариты 8×8×1 мм, масса 0.0003 кг — паспортные данные (PMUT-массив). Материал — aln: нитрид алюминия (AlN, пьезоэлектрик).
