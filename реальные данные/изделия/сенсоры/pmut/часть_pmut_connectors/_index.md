# Часть: часть_pmut_connectors

## Описание

Комплект разъёмов и жгутов изделия: РЧ-стык PMUT-массива — коаксиальный jack MHF4 для съёма ультразвукового сигнала на миниатюрной плате. Референсное исполнение — коаксиальный jack MHF4 (Hirose, футпринт ~2.6×3.3 мм, 50 Ом, оценка). Габариты 3.3×2.6×2.4 мм, масса 0.002 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_pmut` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (коаксиальный jack MHF4 (Hirose, футпринт ~2.6×3.3 мм, 50 Ом, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
