# Часть: часть_pezo-sensor_mounting

## Описание

Консольный зажим пьезоплёнки (TE LDT0-028K: PVDF 28 µm + полиэстер 0.125 мм, лепесток 41×13 мм): алюминиевый блок 25×18×6 мм с пазом 13.4×1.6 мм под корень лепестка и прижимом 2× M2. Масса ≈8 г (1.6% номинала 0.5 кг).

## Принцип работы

Корень плёнки зажимается в паз на глубину 6 мм (консольная схема по mounting note TE) — контакт идёт через клеммы выводов, плёнка не пережимается в зоне деформации, свободная длина сохраняет расчётный резонанс консоли.
