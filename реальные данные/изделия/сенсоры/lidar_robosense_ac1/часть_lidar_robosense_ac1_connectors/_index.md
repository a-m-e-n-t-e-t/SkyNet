# Часть: часть_lidar_robosense_ac1_connectors

## Описание

Комплект разъёмов и жгутов изделия: Синхронизационный ВЧ-стык лидара RoboSense AC1 — N-type jack для GPS/PPS-сигнала точного времени; питание лидара — через клеммный жгут. Референсное исполнение — N-type ВЧ-разъём (IEC 61169-16, 50 Ом, резьба 5/8″). Габариты 24×24×32 мм, масса 0.04 кг — паспортные данные стандарта/каталога. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_lidar_robosense_ac1` (подсистема: сенсоры).

## Принцип работы

Стыковка по схеме «вилка/розетка» (N-type ВЧ-разъём (IEC 61169-16, 50 Ом, резьба 5/8″)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
