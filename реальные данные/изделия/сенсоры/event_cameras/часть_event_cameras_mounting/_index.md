# Часть: часть_event_cameras_mounting

## Описание

Переходный кронштейн событийной камеры (модуль iniVation DAVIS346 класса 40×60×25 мм, 100 г без объектива, корпус с точками крепления 1/4-20 UNC и M3): алюминиевый кронштейн 45×30×5 мм с центральным резьбовым гнездом 1/4-20 и рядом отверстий M3. Масса ≈14 г (2.8% номинала 0.5 кг).

## Принцип работы

Кронштейн связывает штатное резьбовое гнездо 1/4-20 корпуса камеры с посадочными M3 базовой рамы — ориентация сенсора настраивается поворотом вокруг оси до затяжки; анодированный алюминий исключает гальваническую пару с корпусом камеры.
