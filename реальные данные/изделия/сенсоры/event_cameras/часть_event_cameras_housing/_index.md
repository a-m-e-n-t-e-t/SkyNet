# Часть: часть_event_cameras_housing

## Описание

Корпус (housing) узла «Модуль event-камеры» — защитный кожух ядра (модуль event-камеры класса Prophesee IMX636 EVK): жёсткая оболочка с монтажными лапами, съёмной крышкой и локальными кабельными вводами; экранирует ядро от внешних ЭМИ-полей и механических воздействий. Габариты 52×41×15 мм — габарит ядра (45×35×12) с припуском ~15 % на стенки и крепёж. Масса 0.023 кг — оценка (оболочка ≈ 90 % массы узла). Материал — al_6061-t6: жёсткость, ЭМИ-экранирование, коррозионная стойкость; крепёж — нержавеющие винты M3/M4.

Родитель: `izdelie_event_cameras` (подсистема: сенсоры).
