# Часть: часть_granatomet_m320_mounting

## Описание

Быстроразъёмный кронштейн (mounting bracket) подствольного гранатомёта M320 / M320A1 (H&K GLM, 40×46 мм SR). Передний кронштейн охватывает ствол карабина M4 (M320A1) / винтовки M16 (M320) и фиксируется рычагом quick-release на нижней планке MIL-STD-1913 (Picatinny); допускает установку и снятие гранатомёта без инструмента. В standalone-варианте тот же узел стыкуется со съёмным прикладом. Масса кронштейна ≈ 0,15 кг — 10% от массы пусковой трубы 1,5 кг (3,3 фунта) по данным Wikipedia/army.mil; общая длина гранатомёта 350 мм, ствол 280 мм.

Родитель: `izdelie_granatomet_m320` (подсистема: встроенное_оружие).

## Принцип работы

Рычажный зажим: при повороте рычага quick-release зажимная колодка стягивает кронштейн с планки Picatinny, пазы которого воспринимают отдачу выстрела 40×46 мм SR (дульная энергия низкая — начальная скорость гранаты 76 м/с). Алюминий 6061-T6 выбран за удельную прочность и анодирование против коррозии; титановый крепёж для данного узла избыточен.
