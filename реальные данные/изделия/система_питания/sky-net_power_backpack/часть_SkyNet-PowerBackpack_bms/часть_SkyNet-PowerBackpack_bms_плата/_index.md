# Часть: часть_SkyNet-PowerBackpack_bms_плата

## Описание

Плата управления BMS класса JBD Smart 7S-24S (габарит платы 128×70×15 мм — типовой форм-фактор серии): AFE-измерение 7 групп, MCU с балансировкой ±20 мА (резистивные шунты), MOSFET-банк разрыва до 120 А (пик), OVP 4.25 В / UVP 2.5 В, телеметрия UART/RS485/CAN с автодетектом числа секций (линейка 40–150 А непрерывных). Датчик тока — шунт 75 мВ/120 А в силовом тракте.

## Технические характеристики

| Параметр | Значение | Источник |
|---|---|---|
| форм-фактор платы | 128×70×15 мм | JBD 7S-24S smart BMS (серия 40A-80A spec) |
| число секций | Li-ion 7–17S (конфигурация 7s) | JBD Smart BMS 7-17S 40-150A line |
| непрерывный ток (линейка) | 40–150 А (реализация: 120 А разрыв) | JBD Smart BMS 7S-24S 40A-150A |
| телеметрия | UART / RS485 / CAN, автодетект строк | JBD Smart BMS product line |
| габариты (Д×Ш×В) | 128×70×15 мм | JBD 7S-24S spec |
| выработка тепла | 9 Вт | расчёт: 58²×2.5 мОм + AFE/MCU |

## Принцип работы

MCU опрашивает AFE по каждой из 7 последовательных групп (по NTC на группе), при выходе за окно 2.5–4.25 В открывает MOSFET-банк разрыва (общий порт); балансировочные шунты разряжают верхние группы по ±20 мА. Ток канала измеряется шунтом 75 мВ/120 А, телеметрия SoC/SoH уходит по CAN в вычислительную подсистему. MOSFET-банки тепловым интерфейсом прижаты к алюминиевому основанию узла.
