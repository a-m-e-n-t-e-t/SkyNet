# Часть: часть_induktivnyi_nakopitel_core

## Описание

Ламинированный магнитопровод индуктивного накопителя `izdelie_induktivnyi_nakopitel` — стержневой (core-type) стек из кремнистой электротехнической стали M-19 (ASTM A677, non-oriented fully processed, Si 1.8–3.0%): 2 стержня сечением 75×90 мм, 2 ярма, окна обмотки 2×60×150 мм; габарит стека 210×90×300 мм при высоте 300 мм и глубине 90 мм. Листы 0.355 мм (29 gauge) с изоляционным покрытием, стек-фактор ~0.95. Масса стали: объём заполнения 4.05 л (габарит 5.67 л минус окна 1.62 л) × ρ 7650 кг/м³ = 31.0 кг ≈ canon 30 кг. Рабочая индукция 1.5 Тл (насыщение M-19 ~1.9–2.0 Тл), удельные потери 3.0–3.4 Вт/кг при 1.5 Тл / 60 Гц (W15/60, Epstein-проба). Обмотка `часть_induktivnyi_nakopitel_coil` охватывает оба стержня; конструкция соответствует практике реакторов IEEE C57.16.

Родитель: `izdelie_induktivnyi_nakopitel` (подсистема: энергетическая).

## Принцип работы

Магнитопровод замыкает магнитный поток обмотки накопителя: энергия запасается в воздушном/магнитном поле цепи, а сердечник проводит поток с минимальным магнитным сопротивлением, повышая индуктивность при заданном числе витков. Ламинирование 0.355-мм листами с изоляцией разрывает вихревые токи — без него сечение 75×90 мм при переменном/импульсном намагничивании греется на порядки сильнее; удельные потери M-19 (3.0–3.4 Вт/кг @ 1.5 Тл / 60 Гц) масштабируются с частотой и амплитудой цикла. Рабочая точка 1.5 Тл выбрана ниже колена кривой намагничивания (~1.9–2.0 Тл насыщения): при насыщении индуктивность резко падает, ток растёт и накопитель теряет управляемость. Стержневая конфигурация с окнами 60×150 мм оставляет место для медной обмотки 47.5% массы родителя и охлаждающих каналов `часть_induktivnyi_nakopitel_cooling`; ламинированный стек стянут шпильками с изоляционными втулками, исключающими короткозамкнутые витки вокруг стержней.
