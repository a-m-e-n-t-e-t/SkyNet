# Часть: часть_copv_core

## Описание

Композитный баллон высокого давления (COPV) — тонкостенный металлический лайнер с намоткой углеволокна T1100, хранение рабочего газа 300+ бар. Референсное исполнение — COPV малого класса (Ø300×500, углеволокно BF3-обмотка, оценка по типовым). Габариты 300×300×500 мм, масса 3.5 кг — оценка по типовым изделиям класса (COPV малого класса (Ø300×500, углеволокно BF3-обмотка, оценка по типовым)). Материал — cfrp_t1100g: углепластик на волокне T1100.
