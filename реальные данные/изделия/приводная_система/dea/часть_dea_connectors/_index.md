# Часть: часть_dea_connectors

## Описание

Комплект разъёмов и жгутов изделия: Высоковольтный стык диэлектрического эластомерного актуатора (DEA) — SHV: рабочее напряжение 3–10 кВ, безопасная коаксиальная развязка. Референсное исполнение — SHV высоковольтный ВЧ-разъём (5 кВ, 50 Ом). Габариты 14.3×14.3×42 мм, масса 0.02 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_dea` (подсистема: приводная_система).

## Принцип работы

Стыковка по схеме «вилка/розетка» (SHV высоковольтный ВЧ-разъём (5 кВ, 50 Ом)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
