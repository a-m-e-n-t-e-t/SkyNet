# Часть: часть_zubchataya_mufta_core

## Описание

Зубчатая муфта — компенсация несоосности валов (до 1.5°) с передачей крутящего момента через обойму с внутренними зубьями. Референсное исполнение — зубчатая муфта Ø80 (типовая зубчатая компенсирующая). Габариты 80×80×60 мм, масса 0.9 кг — паспортные данные (зубчатая муфта Ø80). Материал — stal_st3: конструкционная сталь Ст3.

## Принцип работы

Ядро — зубчатый механизм муфты: пара ступиц с наружными зубьями,
огибаемых обоймой с внутренними зубьями. Крутящий момент передаётся
через зацепление зубьев; бочкообразный (crowned) профиль зуба допускает
угловую подвижность в каждом зацеплении, что компенсирует несоосность
валов до 1.5°. Зазор зацепления заполнен консистентной смазкой, которая
заменяется через пресс-маслёнки без разборки узла. При износе зубьев
механизм заменяется целиком как собранный модуль (Dodge/Lovejoy:
coupling = hub pair + sleeve + accessory kit), поэтому ядро — неделимая
закупочная позиция.

## Состав

Неделимая часть (уровень 2) — атомарный зубчатый механизм муфты
(ступицы + обойма поставляются собранными); дочерних частей не имеет
(глубина декомпозиции не ограничена, v9.48).
