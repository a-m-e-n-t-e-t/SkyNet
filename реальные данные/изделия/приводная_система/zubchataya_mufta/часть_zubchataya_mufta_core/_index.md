# Часть: часть_zubchataya_mufta_core

## Описание

Зубчатая муфта — компенсация несоосности валов (до 1.5°) с передачей крутящего момента через обойму с внутренними зубьями. Референсное исполнение — зубчатая муфта Ø80 (типовая зубчатая компенсирующая). Габариты 80×80×60 мм, масса 0.9 кг — паспортные данные (зубчатая муфта Ø80).
