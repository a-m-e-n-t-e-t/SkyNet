# Часть: часть_fleksury_8_diskov_po_0_15_mm_core

## Описание

Неделимый упругий элемент (пружина) — пакет из 8 идентичных гибких дисков по 0,15 мм из бериллиевой бронзы, работающий как прецизионный флексурный подвес без трения и люфта. Диски пакета идентичны (не разные подузлы) и неразъёмно соединены с концевыми втулками заводской пайкой (brazing) либо электронно-лучевой сваркой для высоких температур — полевая разборка разрушает элемент; при обслуживании пакет заменяется целиком. Закупочные аналоги — Riverhawk Free-Flex® Pivot (flexpivots.com) и C-Flex Pivot Bearings: продаваемые цельные узлы, «simply packaged, compact and easily installed limited rotation bearing», ход ±30°. Референсное исполнение — пакет гибких дисков 8×0.15 мм (BeCu); габариты 50×50×8 мм, масса 0.012 кг. Материал — becu: бериллиевая бронза.

Родитель: `izdelie_fleksury_8_diskov_po_0_15_mm` (подсистема: приводная_система).

## Принцип работы

Пакет тонких дисков образует упругий параллелограмм: при повороте вокруг оси внутренняя втулка смещается относительно наружной без металлического контакта поверхностей — движение обеспечивается изгибом дисков в пределах предела упругости BeCu. Отсутствие трения, люфта и стикциона даёт повторяемое позиционирование для прецизионных приводов; упругая деформация распределяется по 8 дискам, снижая напряжение в каждом (аналогично замене 4×0.5 мм на 8×0.15 мм). Ход ограничен углом ±30° (до 60° полного хода по Riverhawk Free-Flex).

## Состав

Неделимая часть (уровень 2): единый упругий элемент (пружина), заводская неразъёмная сборка. Дочерних частей нет — корпус, крепёж, разъёмы и монтаж являются соседними частями уровня 2.
