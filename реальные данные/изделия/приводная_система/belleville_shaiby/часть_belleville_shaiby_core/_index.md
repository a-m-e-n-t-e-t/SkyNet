# Часть: часть_belleville_shaiby_core

## Описание

Неделимый закупочный пружинный элемент (пакет тарельчатых (бельвильских) дисковых пружин DIN 2093) — осевая упругая связь с высокой жёсткостью в компактном объёме: конические шайбы в стеке, число шайб задаёт характеристику заказа. Шайбы пакета идентичны (не разные подузлы), при обслуживании пакет заменяется целиком. По каталогу Schnorr (metricmcc.com) DIN 2093 disc springs — «conical spring washers used with threaded fasteners to maintain preload and counteract joint settling and thrust loads» (пружинный крепёж). Референсное исполнение — пакет Ø25 (типовой стек DIN 2093); габариты 25×25×15 мм, масса 0.03 кг. Материал — stal_st3 (форма: строительные_конструкции_и_крепёж).

Родитель: `izdelie_belleville_shaiby` (подсистема: приводная_система).

## Принцип работы

Осевая нагрузка сжимает конические шайбы: высота конуса уменьшается, шайба сплющивается к плоскости — жёсткость нелинейна (растёт при подходе к плоскому состоянию). Пакет из нескольких шайб, сложенных последовательно (конусы попеременно), суммирует ход; параллельный стек суммирует усилие. Демпфирование трением между шайбами даёт высокую рассеивающую способность при компактных габаритах.

## Состав

Неделимый (уровень 2, Стратегия A): цельный закупочный пружинный пакет DIN 2093 — шайбы стека идентичны (множественные экземпляры одного атомарного компонента, параметр «количество», не структурные подузлы BOM); характеристика задаётся при заказе, при обслуживании пакет заменяется целиком.
