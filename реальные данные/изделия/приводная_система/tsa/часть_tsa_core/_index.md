# Часть: часть_tsa_core

## Описание

Твист-струнный привод (TSA) — мотор скручивает пучок UHMWPE-шнуров: сокращение до 20 % длины при высоком усилии. Референсное исполнение — TSA-привод (twisted string actuator, UHMWPE-шнур 250 мм). Габариты 250×10×10 мм, масса 0.01 кг — паспортные данные (TSA-привод). Материал — spectra: UHMWPE Spectra/Dyneema.

Родитель: `izdelie_tsa` (подсистема: приводная_система).
