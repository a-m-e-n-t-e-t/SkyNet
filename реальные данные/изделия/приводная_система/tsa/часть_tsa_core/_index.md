# Часть: часть_tsa_core

## Описание

Неделимый приводной элемент (twisted string, «скрученный шнур»): пучок UHMWPE-шнуров Spectra/Dyneema, закручиваемый электродвигателем — при скручивании длина пучка сокращается до 20 %, развивая высокое усилие на нагрузке. По патенту US20150343647A1 twisted string actuator содержит «twisted string comprised of a pair of cords» — шнур целостен, отделение волокон = разрез. Референсное исполнение — UHMWPE-шнур 250 мм; габариты 250×10×10 мм, масса 0.01 кг. Материал — spectra (форма: высоконагруженные_тонкие_шнуры, S-1000: минимальный диаметр при максимальной tenacity 34–43 gpd).

Родитель: `izdelie_tsa` (подсистема: приводная_система).

## Принцип работы

Электродвигатель вращает один конец шнура при фиксированном другом: витки укладываются в двойную спираль, осевая длина пучка сокращается (до ~20 %) при росте натяжения — малый крутящий момент преобразуется в большое линейное усилие (геометрическое передаточное отношение зависит от угла скручивания); реверс мотора раскручивает шнур и возвращает ход.

## Состав

Неделимый (уровень 2, Стратегия A): целостный пучок UHMWPE-шнуров — непрерывные гель-прядёные волокна Spectra/Dyneema; разрез или раскрутка = разрушение элемента. Чек-лист v9.48: тросы/канаты/шнуры — атомарные. Декомпозиция на «волокна» невозможна: каталожных UHMWPE-фибрилл в реальные данные/материалы/ нет — вне скоупа.
