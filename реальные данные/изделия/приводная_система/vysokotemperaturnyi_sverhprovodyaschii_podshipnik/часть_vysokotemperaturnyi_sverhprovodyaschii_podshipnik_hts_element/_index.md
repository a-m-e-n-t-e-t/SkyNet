# Часть: часть_vysokotemperaturnyi_sverhprovodyaschii_podshipnik_hts_element

## Описание

HTS-элемент высокотемпературного сверхпроводящего подшипника — массивный керамический блок YBCO, создающий пассивное магнитное подвешивание над постоянными магнитами (эффект Мейснера + пиннинг потока). Референсное исполнение — массивные YBCO-блоки CAN Superconductors: типовой элемент 30×30×15 мм, левитационная сила до 100 Н при 77 К, работает в жидком азоте. Габариты 30×30×15 мм — типовой выпускной размер блока; масса 0,080 кг при плотности YBCO ~6,0 г/см³ (13,5 см³ → 81 г). Материал — ybco (YBa₂Cu₃O₇).

Родитель: `izdelie_vysokotemperaturnyi_sverhprovodyaschii_podshipnik` (подсистема: энергетическая).

## Принцип работы

YBCO-блок — статор магнитного подвеса: после охлаждения ниже Tc (77 К, LN2) захватывает поток PM-ротора (field-cooled) и левитирует его силами Мейснера/пиннинга без механического контакта. Омических потерь в сверхпроводнике нет (DC-режим пиннинга), но при вращении ротора его поле в точке статора переменно: неоднородность поля сегментов + анизотропия намагниченности создают вихревые токи и гистерезисные циклы в объёмном YBCO — это главный вращательный механизм потерь HTS-подшипника (Deng 2015; Murakami 2002: 8.03 Вт при 6000 об/мин для класса 838 Н; на 10 кг класс при номинальных оборотах — ~0.3 Вт). Потери выделяются в объёме блока и снимаются жидким азотом криостата; при 0 об/мин остаётся только дрейф пиннинга (мВт) — блок не нагружает тепло-баланс.
