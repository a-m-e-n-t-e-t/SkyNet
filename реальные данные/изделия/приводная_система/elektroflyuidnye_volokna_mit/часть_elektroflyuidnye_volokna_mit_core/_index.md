# Часть: часть_elektroflyuidnye_volokna_mit_core

## Описание

Электрофлюидное волокно — гибкое волокно с микроканалом, заполненным ионной жидкостью (EMIM-TFSI): исполнительный/сенсорный элемент мягкой робототехники. Референсное исполнение — электрофлюидное волокно (MIT, канал с ионной жидкостью, оценка). Габариты 100×5×5 мм, масса 0.002 кг — оценка по типовым изделиям класса (электрофлюидное волокно (MIT, канал с ионной жидкостью, оценка)). Материал — ionnaya_zhidkost_emim_tfsi: ионная жидкость EMIM-TFSI.

Родитель: `izdelie_elektroflyuidnye_volokna_mit` (подсистема: приводная_система).

СТРАТЕГИЯ A (неделимый): электрофлюидное волокно MIT — монолит волоконного формата. По публикации «Electrofluidic fiber muscles» (Science Robotics 33, 2026, DOI 10.1126/scirobotics.ady6438, MIT Media Lab) волокно толщиной 2 мм интегрирует в замкнутом гидравлическом контуре антагонистические флюидные актуаторы и электрогидродинамические (EHD) насосы с впрыском заряда, без внешнего резервуара жидкости — рабочая ионная жидкость EMIM-TFSI герметично заперта в микроканале волокна. Разъёмных соединений нет: вскрытие канала (перерезка волокна) разрушает контур и необратимо теряет жидкость; дозаправка в полевых условиях невозможна. Отказ → замена волокна целиком (масштабирование набором пучка волокон, не разборкой). Прецеденты: непрерывный монофиламент (TCP-мышца), герметичный модуль (TMR core).

## Принцип работы

EHD-насосы с впрыском заряда перегоняют ионную жидкость EMIM-TFSI по замкнутому контуру внутри волокна между антагонистическими флюидными актуаторами: электрическое поле создаёт кулоновскую силу на ионах и перекачку жидкости без механических насосов; дисбаланс давления сжимает одну сторону волокна и растягивает другую — волокно сокращается на 20 % (время отклика 0.3 с, удельная мощность 50 Вт/кг — уровень скелетных мышц). Режим работы программируется соотношением насосов и актуаторов в волокне; пучок волокон масштабирует усилие.

## Состав

Неделимая часть (уровень 2, СТРАТЕГИЯ A — монолит волоконного формата, см. Описание). Дочерних частей нет: EHD-насосы, антагонистические актуаторы и ионная жидкость EMIM-TFSI образуют единый замкнутый контур, герметично интегрированный внутри волокна толщиной 2 мм.
