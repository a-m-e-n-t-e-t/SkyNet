# Часть: часть_elektromagnitnye_poroshkovye_mufty_i_tormoza_bearings

## Описание

Подшипниковые опоры валов электромагнитной порошковой муфты/тормоза (изделие по DIN VDE 0580): референс — однорядный радиальный шариковый подшипник SKF 61805, посадочные размеры 25×37 мм, ширина 7 мм, динамическая грузоподъёмность 4.36 кН, статическая 2.6 кН (каталог SKF, productid-61805). Тонкий узкий ряд 618xx выбран для муфт малой высоты: минимальная осевая габаритность при радиальной нагрузке от натяжения приводной нагрузки. Кольца и шарики — подшипниковый металл 100Cr6 (GCr15).

Масса 0.3 кг — канон декомпозиции (агрегирует полный комплект опор изделия: реальный подшипник 61805 ~20 г). Габарит 25×37×7 мм — по каталогу SKF, не дефолтный fallback.

Родитель: `izdelie_elektromagnitnye_poroshkovye_mufty_i_tormoza` (подсистема: энергетическая).
