# Часть: часть_tcp_connectors

## Описание

Комплект разъёмов и жгутов изделия: Стык TCP-мышцы (twisted and coiled polymer) — вилка KK 254 2-контакта: цепь токового подогрева нити и термодатчик. Референсное исполнение — Molex KK 254 вилка, шаг 2.54 мм, 2 контакта (оценка). Габариты 7.1×7.6×5 мм, масса 0.0015 кг — оценка по типовым изделиям класса. Материал — poliimid: полиимид (термопластичные корпуса/шлейфы).

Родитель: `izdelie_tcp` (подсистема: приводная_система).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Molex KK 254 вилка, шаг 2.54 мм, 2 контакта (оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
