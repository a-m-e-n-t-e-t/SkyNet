# Часть: часть_tcp_core

## Описание

Искусственная мышца TCP (twisted and coiled polymer) — нейлоновая нить 6/6, скрученная и коилед: нагрев током сокращает до 40 % длины. Референсное исполнение — TCP-мышца (twisted and coiled polymer, нейлон 6/6, 150 мм). Габариты 150×3×3 мм, масса 0.0005 кг — паспортные данные (TCP-мышца). Материал — neilon_6_66: нейлон 6/6 (полиамид).

Родитель: `izdelie_tcp` (подсистема: приводная_система).
