# Часть: часть_tcp_mounting

## Описание

Натяжной концевой узел TCP-мышцы (скрученная коил-полимерная нить нейлона 6,6 по Haines et al. Science 2014): планка из алюминия 6061-T6 40×15×6 мм с двумя цанговыми зажимами нити Ø0.5 мм на концах и отверстиями M3 для тензодатчика. Масса ≈15 г (1.5% номинала 1 кг).

## Принцип работы

Концы коила заводятся в цанговые зажимы планки — фиксация без пережатия горячекоил-структуры; планка держит предварительный натяг (~10% длины, режим training по Haines) и передаёт сокращение до 49% на нагрузку через разнесённые оси зажимов.
