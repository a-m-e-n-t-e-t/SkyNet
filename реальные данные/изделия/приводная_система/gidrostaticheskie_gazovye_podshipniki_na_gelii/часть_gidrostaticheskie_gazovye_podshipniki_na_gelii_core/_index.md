# Часть: часть_gidrostaticheskie_gazovye_podshipniki_na_gelii_core

## Описание

Газостатический подшипник на гелии — внешний компрессор подаёт газ через дроссели в зазор ~10–20 мкм: трение практически отсутствует. Референсное исполнение — газостатический подшипник Ø60 (гелий, оценка по прецизионным). Габариты 60×60×40 мм, масса 0.35 кг — оценка по типовым изделиям класса (газостатический подшипник Ø60 (гелий, оценка по прецизионным)). Материал — stal_st3: конструкционная сталь Ст3.
