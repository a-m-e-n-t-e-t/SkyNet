# Часть: часть_hasel_core

## Описание

Мягкий актуатор HASEL (hydraulically amplified self-healing electrostatic) — жидкий диэлектрик между электродами: электростатическое сжатие даёт мышечное движение. Референсное исполнение — HASEL актуатор (Keplinger 2018, Nature 559: электрогидравлический мягкий привод). Габариты 50×50×3 мм, масса 0.005 кг — паспортные данные (HASEL актуатор). Материал — halve_p_vdf-trfe-cfe: P(VDF-TrFE-CFE) релаксорный ферроэлектрик.

Родитель: `izdelie_hasel` (подсистема: приводная_система).
