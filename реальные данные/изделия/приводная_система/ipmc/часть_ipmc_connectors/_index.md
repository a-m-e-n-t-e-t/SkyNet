## Описание

Комплект разъёмов и жгутов изделия: Стык IPMC-плёнки (ионный полимерно-металлический композит) — гнездо JST SH 2-контакта: низковольтный приводной ток 1–5 В на шлейфе. Референсное исполнение — JST SH гнездо, шаг 1.0 мм, 2 контакта (серия SH, оценка). Габариты 5.9×4.4×3.3 мм, масса 0.0008 кг — оценка по типовым изделиям класса. Материал — poliimid: полиимид (термопластичные корпуса/шлейфы).

Родитель: `izdelie_ipmc` (подсистема: приводная_система).

## Принцип работы

Стыковка по схеме «вилка/розетка» (JST SH гнездо, шаг 1.0 мм, 2 контакта (серия SH, оценка)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
