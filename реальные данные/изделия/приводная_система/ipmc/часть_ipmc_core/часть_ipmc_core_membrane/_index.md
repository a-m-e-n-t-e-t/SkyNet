# Часть: часть_ipmc_core_membrane

## Описание

Ионообменная мембрана — несущий функциональный слой ядра IPMC-актуатора: перфторсульфоновая (PFSA) плёнка Nafion N117 толщиной 183 мкм (EW 1100, Chemours), обеспечивающая ионную проводимость между электродами. Референсное исполнение — плёнка 30×10 мм, вырезанная из листа N117; масса мембраны 0.00085 кг — 85 % массы ядра (базовая плотность Nafion 360 г/м² даёт для 30×10 мм расчётные 0.108 г; канонная масса ядра 1 г распределена по реальному соотношению мембрана:электроды ≈ 86:14).

Толщина мембраны — ключевой параметр производительности IPMC: исследования (Oh et al., RSC Adv. 9, 2019) показывают, что более тонкие мембраны дают больший изгиб при том же напряжении, но жёсткость и блокирующая сила падают; сортамент Chemours квантует толщину (N211 25 мкм / N212 50 мкм / N115 125 мкм / N117 183 мкм). Перед металлизацией поверхность плёнки активируется (плазменная обработка / механическое шерохование) для адгезии электродного слоя.

Родитель: `часть_ipmc_core` (подсистема: приводная_система) — мембрана + два электродных слоя.

## Принцип работы

Мембрана работает как ионообменный «мускул» IPMC: сульфоновые группы фиксированного заряда в полимерной матрице допускают миграцию только катионов (Li+/Na+) вместе с сольватными оболочками. При приложении 1–5 В между электродами катионы дрейфуют к катодной стороне, создавая осмотическое давление и набухание у катода — плёнка изгибается в сторону анода; смена полярности меняет направление изгиба. Толщина мембраны определяет баланс подвижности и силы: тонкие плёнки (N211 25 мкм) дают большой изгиб при малой силе, толстые (N117 183 мкм) — меньший ход при большей блокирующей силе. Ионные потери проводимости выделяют ~0.1 Вт тепла (оценка: ~10 % тепловыделения ядра — остальное приходится на джоулевы потери в электродах).

## Состав

Атомарная часть (уровень 3, неделимый): покупная PFSA-плёнка, в полевых условиях не разбирается. Дочерних частей нет.
