# Часть: часть_stm32h743_connectors

## Описание

Комплект разъёмов и жгутов изделия: Стык контроллера STM32H743 — гнездо USB Type-C: питание PD и USB 2.0/FS отладочный канал; контакты бериллиевая бронза с золотым покрытием. Референсное исполнение — USB Type-C receptacle (8.94×7.35×3.26 мм, 24 контакта). Габариты 8.94×7.35×3.26 мм, масса 0.004 кг — паспортные данные стандарта/каталога. Материал — becu: бериллиевая бронза (контакты, CuBe; золотое покрытие по Ni).

Родитель: `izdelie_stm32h743` (подсистема: система_связи).

## Принцип работы

Стыковка по схеме «вилка/розетка» (USB Type-C receptacle (8.94×7.35×3.26 мм, 24 контакта)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
