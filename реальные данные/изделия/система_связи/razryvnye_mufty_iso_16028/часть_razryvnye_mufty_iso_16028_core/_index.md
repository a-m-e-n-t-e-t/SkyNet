## Описание

Разрывные гидравлические муфты ISO 16028 — разъединение под нагрузкой с блокировкой потока с двух сторон. Референсное исполнение — разрывные муфты ISO 16028 (типоразмер 12). Габариты 40×40×95 мм, масса 0.28 кг — паспортные данные (разрывные муфты ISO 16028). Материал — stal_st3: конструкционная сталь Ст3.

Родитель: `izdelie_razryvnye_mufty_iso_16028` (подсистема: система_связи).
