# Часть: часть_radiatsionno-stoikii_neiromorfnyi_tmr_connectors

## Описание

Комплект разъёмов и жгутов изделия: Жгут радиационно-стойкого нейроморфного вычислителя — Micro-D 79-контактный: шины TMR-троированных каналов, питание и телеметрия; аудиту SEU-стойкости соответствует монтаж с экранированным жгутом. Референсное исполнение — Micro-D MIL-DTL-83513, корпус /01-79 (79 контактов). Габариты 71.07×5.33×8.13 мм, масса 0.08 кг — паспортные данные стандарта/каталога. Материал — becu: бериллиевая бронза (контакты, CuBe; золотое покрытие по Ni).

## Принцип работы

Стыковка по схеме «вилка/розетка» (Micro-D MIL-DTL-83513, корпус /01-79 (79 контактов)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
