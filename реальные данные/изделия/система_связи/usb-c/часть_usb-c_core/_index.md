# Часть: часть_usb-c_core

## Описание

Разъём USB Type-C — 24-pin симметричный разъём: до 240 Вт PD, 40 Гбит/с USB4, бериллиевая бронза с золотым покрытием контактов. Референсное исполнение — разъём USB Type-C (8.94×7.35×3.26 мм).
