# Часть: часть_usb-c_mounting

## Описание

Монтажная пластина разъёма USB Type-C (receptacle 8.94×7.35 мм по USB-IF): пластина 30×15×3 мм из нерж. стали AISI 304 с вырезом под разъём и 2× винтами M2 через фланцевые уши, противовырывное удержание разъёма при 20K циклов сопряжения (USB-IF). Масса ≈8 г.

## Принцип работы

Разъём type-C вкладывается в вырез пластины, фланцевые уши притягиваются 2× M2 — усилие извлечения кабеля передаётся на пластину, а не на пайку SMD-выводов; нерж. сталь AISI 304 исключает коррозию контактной пары и перекос при затяжке.
