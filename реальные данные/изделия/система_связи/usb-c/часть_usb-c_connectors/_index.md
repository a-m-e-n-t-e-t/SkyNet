# Часть: часть_usb-c_connectors

## Описание

Комплект разъёмов и жгутов изделия: Сетевой разъём блока питания USB-C станции — входной inlet C14 (корзиночный тип, термопластичный корпус с латунными штырями). Референсное исполнение — сетевой inlet IEC 60320 C14 (27×19.5 мм, 10 А / 250 В). Габариты 27×19.5×10.7 мм, масса 0.015 кг — паспортные данные стандарта/каталога. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_usb-c` (подсистема: система_связи).

## Принцип работы

Стыковка по схеме «вилка/розетка» (сетевой inlet IEC 60320 C14 (27×19.5 мм, 10 А / 250 В)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
