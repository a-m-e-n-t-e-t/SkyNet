# Часть: часть_flat-face_couplings_iso_16028_connectors

## Описание

Комплект разъёмов и жгутов изделия: Электрический стык плоскостыковых муфт ISO 16028 — M12 5-контактный: датчики стыковки, соленоиды запирания шарового клапана. Референсное исполнение — M12 круговой A-code, 5 контактов (IEC 61076-2-101). Габариты 19.5×19.5×50 мм, масса 0.045 кг — оценка по типовым изделиям класса. Материал — latun_c36000: латунь C36000 (корпуса/контакты, покрытие Au/Ni).

Родитель: `izdelie_flat-face_couplings_iso_16028` (подсистема: система_связи).

## Принцип работы

Стыковка по схеме «вилка/розетка» (M12 круговой A-code, 5 контактов (IEC 61076-2-101)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
