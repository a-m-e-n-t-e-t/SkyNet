# Часть: часть_stm32_connectors

## Описание

Комплект разъёмов и жгутов изделия: Панельный разъём контроллера STM32 — DA-15: шина управления и дискретные I/O; гальваническая развязка на стороне платы. Референсное исполнение — D-sub DA-15 (IEC 60603-2, размер A-корпуса 39.14×12.55 мм). Габариты 39.14×12.55×8.6 мм, масса 0.03 кг — паспортные данные стандарта/каталога. Материал — stal_st3: конструкционная сталь Ст3 (корпуса с цинковым покрытием).

Родитель: `izdelie_stm32` (подсистема: система_связи).

## Принцип работы

Стыковка по схеме «вилка/розетка» (D-sub DA-15 (IEC 60603-2, размер A-корпуса 39.14×12.55 мм)): фиксация и уплотнение — по стандарту семейства; контакты с золотым покрытием по никелевому подслою держат стабильное переходное сопротивление (миллиомный диапазон, ресурс сотни циклов сочленения). Тепловыделение — потери I²R на контактах, менее 0.1 Вт в сигнальных цепях.
