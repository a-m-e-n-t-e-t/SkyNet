# Часть: часть_obd-ii_core

## Описание

Диагностический разъём OBD-II (SAE J1962) — 16-pin: питание, CAN/K-Line/LIN для доступа к бортовым контроллерам. Референсное исполнение — разъём OBD-II SAE J1962 (типовой 16-pin 48×26×33). Габариты 48×26×33 мм, масса 0.03 кг — паспортные данные (разъём OBD-II SAE J1962). Материал — peek: PEEK (полиэфирэфиркетон).

Родитель: `izdelie_obd-ii` (подсистема: система_связи).
