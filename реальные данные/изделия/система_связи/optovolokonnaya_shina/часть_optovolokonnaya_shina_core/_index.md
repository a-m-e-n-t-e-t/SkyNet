# Часть: часть_optovolokonnaya_shina_core

## Описание

Оптоволоконная шина — коммутационный узел с волоконными каналами: иммунитет к ЭМИ, гальваноразвязка высокоскоростных линий. Референсное исполнение — оптоволоконная шина (коммутационный блок 130×85×28, оценка). Габариты 130×85×28 мм, масса 0.2 кг — оценка по типовым изделиям класса (оптоволоконная шина (коммутационный блок 130×85×28, оценка)). Материал — al_6061-t6: конструкционный алюминиевый сплав 6061-T6.

Родитель: `izdelie_optovolokonnaya_shina` (подсистема: система_связи).
