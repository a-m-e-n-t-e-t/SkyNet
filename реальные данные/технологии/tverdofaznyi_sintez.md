## Описание

Твердофазный синтез (solid-state reaction route) — классический двухстадийный метод получения поликристаллических керамических фаз из оксидных/карбонатных прекурсоров механическим смешиванием с последующей высокотемпературной термообработкой. Для гранатового твёрдого электролита Li₇La₃Zr₂O₁₂ (LLZO): прекурсоры Li₂CO₃ + La₂O₃ + ZrO₂ (+ Al₂O₃ как легирующая добавка 0.2–0.4 Al/формульную единицу) шарово-мелют 12–24 ч, прессуют в таблетки и кальцинируют при 750–900 °C для разложения карбоната лития и образования кубической гранатовой фазы; затем повторное измельчение, гранулирование и спекание при 1100–1230 °C.

Полное наименование (как в CSV): `твердофазный синтез`

## Физический принцип

Реакция идёт твёрдофазной диффузией: контакт между частицами прекурсоров обеспечивает взаимную диффузию катионов (Li⁺, La³⁺, Zr⁴⁺) через точечные дефекты при температурах 0.5–0.7 T_пл; Li₂CO₃ разлагается с выделением CO₂, создавая пористость, поэтому требуются промежуточное кальцинирование и переизмельчение для однородности фазы. Кубическая фаза c-LLZO (Ia-3d) стабилизируется supervalent-легированием Al/Ta (вакансии по литию), тогда как стехиометрический LLZO при охлаждении переходит в тетрагональную фазу с проводимостью на ~2 порядка ниже.

## Типичные применения

- твёрдые электролиты для твердотельных Li-аккумуляторов (гранатовый LLZO, NASICON LATP/LAGP)
- получение керамических порошков сложных оксидов (перовскиты, гранаты, шпинели)
- серийное производство керамических мишеней и прекурсоров для тонкоплёночных процессов

## Альтернативы

- золь-гель синтез (ниже температура, лучше гомогенность, дороже прекурсоры)
- соосаждение и раствор-горение (нанопорошки, но больше примесей)
- механохимический синтез в высокоэнергетических мельницах (без кальцинирования для некоторых фаз)
- горячее изостатическое прессование (hip) — для уплотнения уже синтезированного порошка LLZO до >95 % теоретической плотности
