## Описание

Анодирование (Type II, сернокислое) — электрохимическое формирование оксидного слоя Al2O3 на алюминии: коррозионная стойкость, изоляция, возможность окрашивания. По reference guide Anodizing Council: ванна 15 % H2SO4 @ 20 °C, ток ~12 А/кв.фт (≈1.3 А/дм²); толщина Type II 0.0002–0.001 дюйма (5–25 мкм), диапазон ванны 18–24 °C.

## Входные ресурсы

Алюминиевая деталь (6061-T6 анодируется стандартно), серная кислота электролит, катодные свинцовые пластины, источник постоянного тока.

## Операции

Обезжиривание → травление (щелочное) → осветление (HNO3) → анодирование (18–24 °C, 1.2–2.4 А/дм²) → (окрашивание) → уплотнение (горячая вода/пар, 95 °C).

## Параметры режима

15–20 % H2SO4 по весу, 18–24 °C, ~1.3 А/дм²; толщина слоя 5–25 мкм по ASTM B244.

## Выходной результат

Твёрдый пористый оксид Al2O3 5–25 мкм, адгезионно-совместимый с красками/клеями, диэлектрический.

## Ограничения и допуски

Контактная точка остаётся неанодированной (нужна токоподводка); для теплоотводов анодирование повышает тепловое излучение (~0.8 ε против 0.05 у голого Al).
