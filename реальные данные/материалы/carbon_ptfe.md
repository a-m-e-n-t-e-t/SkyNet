# Материал: PTFE-связанный углеродный композит (GDE)

## Описание

Композит газодиффузионного электрода (GDE): токопроводящая углеродная сажа, связанная политетрафторэтиленом (PTFE, ~20% по данным Gaskatel для воздушного электрода MOC), с токосъёмником из никелевой сетки; для каталитических вариантов — MnO₂ (MOC), Ag (OxAg) или Pt на углероде (Pla-CC). Гидрофобный PTFE формирует в порах стабильные газовые каналы и не даёт щелочному электролиту затопить поровое пространство, углерод обеспечивает электронную проводимость и развитую трёхфазную границу. Типовая толщина коммерческих GDE для металл-воздушных батарей — 350 мкм (вариант с дополнительным PTFE-слоем — 400 мкм), поставка листами 10×10 см (Gaskatel MOC, позиция 82010, Германия).

## Состав и роли компонентов

- **Углеродная сажа** — токопроводящий каркас и носитель катализатора (ацетиленовая/печная сажа);
- **PTFE (~20%)** — гидрофобное связующее (ASTM D4894); температура плавления 327 °C, химически инертен в KOH;
- **MnO₂ / Ag / Pt** — катализатор восстановления кислорода (ОРР); в MOC — диоксид марганца;
- **Никелевая сетка** — токосъёмник и механическая поддержка (никель стоек в щелочных электролитах).

## Физические свойства

| Свойство | Значение | Примечание |
|---|---|---|
| Эффективная плотность (пористый лист) | ~800–1200 кг/м³ (оценка) | пористость >50% |
| Поверхностная плотность | ~200–400 г/м² (оценка) | для толщины 350 мкм |
| Толщина | 350 мкм (400 мкм с PTFE-слоем) | Gaskatel MOC |
| Плотность тока ОРР | 200 мА/см² @ 0.75 В vs. RHE | Gaskatel MOC, щелочной электролит |

| Электропроводность | ~10⁴–10⁵ См/м (оценка) | сажа+PTFE композит |

## Применение

Воздушные катоды металл-воздушных батарей (Al-air, Zn-air), топливные элементы на щелочных электролитах, датчики кислорода (ОРР-электрод).
