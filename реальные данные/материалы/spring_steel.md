# Материал: Пружинная сталь (music wire ASTM A228)

## Описание

Высокоуглеродистая пружинная сталь (music wire / piano wire) по ASTM A228/A228M-18 — наиболее распространённый материал для навитых пружин высокого напряжения и хорошего сопротивления усталости. Холоднотянутая (после патентирования) проволока: максимальная прочность на растяжение среди деформируемых углеродистых сталей, равномерные механические свойства по длине проволоки. Состав: C 0.70–1.00%, Mn 0.20–0.60%. Модуль упругости 30×10⁶ psi (207 ГПа), модуль сдвига 11.5×10⁶ psi (79.3 ГПа), твёрдость HRC 41–60, минимальная прочность на растяжение 230–399 ksi (1586–2751 МПа в зависимости от диаметра). Максимальная рабочая температура 121°C (250°F); не коррозионностойка (для влажной среды требуется покрытие).
