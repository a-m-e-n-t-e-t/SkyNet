## Описание

CuCr1Zr — осаждаемо-твердеющий высокопроводящий медный сплав: медная гцк-матрица упрочняется когерентными bcc-выделениями хрома и дисперсоидами циркония после закалки (950–1000 °C) и старения (425–500 °C). Компромисс, недостижимый для чистой меди: 80 % IACS (σ 4.65×10⁷ См/м) и k 320 Вт/(м·К) при σт 300 МПа и HB 130 — прочность силового крепежа при проводимости, достаточной для токоведущих штырьков и выводных рамок. Температура разупрочнения 450–500 °C выдерживает пайку и термоциклы силовых модулей (−55…+175 °C). В репозитории материал закрывает две роли в вычислительных изделиях: выводные штырьки/шарики нейроморфных процессоров (intel_loihi_2, brainchip_akida_2, halve — части *_pins_balls, доля_массы 0.10) и выводную рамку SiC-MOSFET (lead frame, доля_массы 0.475 — главный массовый носитель). Классические применения CW106C вне репозитория — сварочные электроды (Zr против прилипания на оцинковке) и токоведущие узлы фьюжена (heat sink divertor ITER).

## Химический состав

Cu — баланс; Cr 0.8 % (номинал, диапазон 0.5–1.2); Zr 0.06–0.08 % (номинал, до 0.3); прочие ≤0.05 (EN). Механизм: при старении хром выделяется из пересыщенного твёрдого раствора в виде когерентных bcc-частиц (~10–50 нм), цирконий образует дисперсоиды Cu₅Zr и чистит границы зёрен — оба механизма дают твердение без разрушения решётки проводимости (Cr/Zr в матрице после старения — следовые, рассеяние электронов минимально → 80 % IACS).

## Физические свойства

- Плотность: 8.9 г/см³ (8900 кг/м³, copperalloys.net CW106C; C18400 8.89 г/см³) — на 0.5 % ниже чистой меди (8.94).
- Интервал плавления: 1070–1080 °C (CW106C) — ниже меди 1084.
- Теплопроводность: 320 Вт/(м·К) (CW106C datasheet; copper.fyi 300 — против меди 394) — номинал 320, 81 % чистой меди.
- КТР: 16.45×10⁻⁶ 1/K (0–250 °C, copperalloys.net) — на 3 % ниже меди (17×10⁻⁶).
- Магнитная проницаемость: 1.01 (практически немагнитен — важно для датчиков).

## Механические свойства

- Прочность по состояниям (copper.fyi KB): σв 220–540 МПа (отожжённое → наклёп); σ0.2 100–440 МПа; CW106C-товарный (старение): σв 380, σт 300 МПа, ε 15 %, HB 130 (copperalloys.net).
- Твёрдость: HV 55–175 по состояниям; номинал 130 HB / ~140 HV состаренное.
- Ударная вязкость: Izod 35 Дж при 20 °C (copperalloys.net) — в поле null (КС-Дж/см² без надрезанного образца не пересчитывается корректно).
- Модуль Юнга: в открытых datasheets не показан (Applus portal — paywall) — обоснованный null; типовой диапазон дисперсионно-твердеющих Cu-сплавов ~110–130 ГПа.
- Пуассон: 0.34 (типовое для медных сплавов — Guide to Copper Alloys).
- Усталостная прочность: не нормируется в открытых источниках — обоснованный null.

## Тепловые свойства

- Теплопроводность 320 Вт/(м·К) делает сплав полноценным тепловым мостом для lead frame: тепло кристалла SiC отводится в выводы и печатную плату.
- Разупрочнение 450–500 °C (softening ~10 %) — верхний термобюджет монтажа; закалённо-состаренное состояние сохраняется при рифлоу ~260 °C.
- Теплоёмкость: в datasheets не нормируется — обоснованный null (опорная точка чистая медь 385 Дж/(кг·К)).

## Электрические свойства

- Электропроводность: 80 % IACS; удельное сопротивление 2.15 мкОм·м при 15 °C (copperalloys.net) → σ = 4.65×10⁷ См/м (проверка: 1/2.15×10⁻⁸ = 4.65×10⁷ ✓; 4.65/58 = 80.2 % IACS ✓).
- Для сигнальных штырьков PGA/BGA 80 % IACS означает снижение затухания на переходном сопротивлении против сталей и сплавов CuZn; для силовых рамок — минимум Джоулевых потерь при токах в сотни ампер.
- Наклёп снижает проводимость до ~65–70 % IACS — для токоведущих элементов выбирают состаренное состояние.

## Технологии получения

Электролитическая катодная Cu → плавка с Cr/Zr (порошки/лигатуры, вакуум/индукция) → непрерывное литьё/полунепрерывное → гомогенизация-закалка 950–1000 °C (выдержка для растворения Cr) → холодная прокатка/волочение (деформация 30–60 %) → старение 425–500 °C (выделение Cr/Cu₅Zr) → правка, резка, штамповка lead frame → покрытие Ni/Pd/Au (световая рамка) или Sn (паяемые выводы). Аддитивный маршрут: LPBF-порошок EOS CopperAlloy CuCrZr (спец. легирование под спекаемость), печати >99 % плотности, последующее старение восстанавливает проводимость. Свариваемость: точечная/шовная — сам является электродным материалом; пайка мягкими припоями стандартна.

## Аналоги и заменители

Максимальная прочность на изгиб при жёстких требованиях к упругости контактов: BeCu C17200 (σт до 1100 МПа) — но 22 % IACS делает его непригодным для токоведущих штырьков (в каталоге отдельный material_becu). Дешёвый массовый lead frame: CuFe2P C19400 (k ~260, σт ~380) — для больших партий бытовых модулей. Выше теплостойкость: CuNiSi C7025 (σт до 600, разупрочнение ~550 °C) — тонкие ленты высокоплотных рамок. Для межсоединений внутри кристалла (где прочность не нужна) — чистая медь Cu-ETP (material_copper): 100 % IACS. Криогенные токоподводы: CuAg0.1 или OFHC Cu при требовании максимальной k при 4 K.
