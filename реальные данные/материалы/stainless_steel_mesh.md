# Материал: Stainless Steel Mesh (сетка/войлок 316L для регенератора Стирлинга)

## Описание

Прессованный войлок из нержавеющих волокон 316L с пористостью ~85 % — стандартный материал насадки регенератора свободнопоршневых Стирлинг-конвертеров (класса NASA GRC ASC-E, Sunpower SRSC). Размещается кольцевой насадкой вокруг холодного теплообменника: рекуперирует тепло рабочего тела между фазами расширения и сжатия цикла Стирлинга, определяя КПД конвертера (≈38 % для ASC-E). Спечён при 1100–1200 °C в водородной атмосфере для сварки межволоконных контактов.

## Химический состав волокна

AISI 316L / EN 1.4404 (X2CrNiMo17-12-2): Fe — основа; Cr 16.0–18.0 %, Ni 10.0–14.0 %, Mo 2.0–3.0 %, C ≤0.03 %, Mn ≤2.0 %, Si ≤0.75 %, P ≤0.045 %, S ≤0.030 %, N ≤0.10 % (Cleveland-Cliffs, ASTM A240). Низкоуглеродистая 316L (а не 316) выбрана для исключения сенсибилизации при спекании 1100–1200 °C —避免了 Cr23C6 выделения на границах зёрен, которые в обычной 316 привели бы к межкристаллитной коррозии в термоциклах.

## Принцип работы в регенераторе Стирлинга

В цикле Стирлинга рабочее тело (гелий) перетекает между горячим (heater head) и холодным (cooler) теплообменниками через регенератор. На такте расширения газ проходит через насадку от cooler к heater, отдаёт тепло волокнам; на такте сжатия — возвращается, забирая тепло обратно. Эффективность регенерации 95–99 % означает, что только 1–5 % тепла цикла пропадает, остальное запасается в теплоёмкости насадки. Высокая пористость 85 % минимизирует мёртвый объём (газ не «застревает» в насадке) и гидравлическое сопротивление (низкий ΔP = низкие потери на проталкивание).

316L выбран за:
- коррозионную пассивность в гелии рабочего тела при 650–850 °C (отсутствие окисления в восстановительной атмосфере)
- низкую КТР (16.0 мкм/(м·К)) — стабильность насадки в термоциклировании
- высокую усталостную прочность аустенита в циклах расширения/сжатия (~10⁹ циклов за ресурс конвертера)
- пассивность по отношению к гелию (не выделяет газов, не сорбирует)

## Технологии получения

Волочение проволоки 316L → рубка в волокна 0.5–3 мм → смешивание со связующим → формование в пресс-форме → спекание 1100–1200 °C в H₂ → калибровка по пористости (RAFIHIHET Wire Mesh, Bekaert). Технология: `vakuumnoe_spekanie` (вакуумное/восстановительное спекание).

## Применение в изделиях

- `часть_nasa_asc-e_srsc_regenerator` — кольцевая насадка 40×40×60 мм (масса 0.3 кг) в свободнопоршневом Стирлинг-конвертере ASC-E (NASA GRC, Sunpower)
- `часть_asrg_regenerator` — регенератор ASRG (Advanced Stirling Radioisotope Generator, NASA/DuPont)

## Аналоги и заменители

- Войлок из нержавейки 304 — дешевле, но выше CTE и ниже коррозионная стойкость в гелии при 850 °C
- Сетка из Incotel 625/718 — для сверхвысоких температур (>900 °C), дороже
- Керамический войлок (ZrO₂, Al₂O₃) — для экстремальных температур, хрупкий
