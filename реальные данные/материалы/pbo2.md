## Описание

Диоксид свинца PbO₂ — сильный окислитель и активная масса положительных пластин свинцово-кислотных аккумуляторов. При разряде восстанавливается до PbSO₄, при заряде — обратно; толщина решётки положительной пластины (рамка) составляет 1.8–2.0 мм при 15–16 поперечных рёбрах (патент CN112103513A, Chaowei Power). Паста наносится на решётку из Pb-Sb/Pb-Ca сплава и формирует пористую структуру с развитой поверхностью. Кристаллическая β-фаза (рутильный тип) обеспечивает высокое напряжение разряда 2.1 В на ячейку.

## Физические свойства

- Плотность: **9400 кг/м³** (9.38 г/см³, Wikipedia Lead dioxide; минерал платтнерит — удельный вес 8.5–9.63, среднее 9.06).
- Цвет: тёмно-бурый, железо-чёрный; блеск полуметаллический до алмазного (платтнерит).
- Твёрдость по Моосу: **5.5** (твёрдый и хрупкий).
- Кристаллография (Wikipedia/Webmineral): β-PbO₂ — тетрагональная, пр. гр. P4₂/mnm (№136), Пирсон tP6, a = 0.491 нм, c = 0.3385 нм, Z = 2; α-PbO₂ (скрутиннит) — орторомбическая Pbcn (№60), oP12, a = 0.497, b = 0.596, c = 0.544 нм, Z = 4; β и α — диморфы.

## Тепловые свойства

- Температура плавления: не плавится — **разложение с 290 °C** (ступени 290/350/375/600 °C, Wikipedia; при нагреве до 650 °C образуется β-PbO).
- Теплопроводность: **7.3 Вт/(м·К)** — расчётная нижняя граница электронного вклада по Видеману–Францу: k_e = L·σ·T = 2.44×10⁻⁸ × 10⁶ × 298 ≈ 7.3 Вт/(м·К) при σ = 10⁶ См/м (ρ = 10⁻⁴ Ом·см, металлическая проводимость кислород-дефицитной фазы). Пометка: прямое справочное значение плотного PbO₂ в открытых источниках найти не удалось (поисковая инфраструктура недоступна в этом цикле: 429 rate-limit); для пористой активной массы (~50% пор, насыщение электролитом) эффективная k будет ниже.
- Удельная теплоёмкость: **256 Дж/(кг·К)** — Cp°(298 K) = 61.15 Дж/(моль·К), вычислено по Шомейт-коэффициентам NIST-JANAF (Chase 1998, ID C1309600, диапазон 298–1200 K): A=57.91116, B=48.88502, C=−34.77573, D=7.975415, E=−0.751526.

## Электрические свойства

- **Металлический тип проводимости** (при дефиците кислорода / избытке свинца): удельное сопротивление до **10⁻⁴ Ом·см** → σ ≈ 10⁶ См/м (Wikipedia Lead dioxide) — вырожденный полупроводник n-типа; электродные покрытия β-PbO₂ относятся к классу электропроводящих оксидов.
- Это делает PbO₂ пригодным для нерастворимых анодов (OER) и активной массы АКБ — ток отводится самой активной массой.

## Эксплуатационные характеристики

- Сильный окислитель (Pb⁴⁺/Pb²⁺, E° ≈ +1.46 В кисл. / 2.05 В в паре с Pb); ядовит (соединения свинца), UN 1872.
- Стабилен в кислых средах (H₂SO₄ электролит); разлагается при 290 °C.
- Рабочий диапазон АКБ: −40…+60 °C (электрохимия), сам материал термически стабилен до ~250 °C.

## Технологии получения

- Электролитическое осаждение β-PbO₂ из кислых растворов Pb(II) (анодные покрытия на Ti/графите).
- Химическое окисление соединений Pb(II) (сурик, плюмбит) — активная масса пасты положительных пластин; формование на решётке Pb-Sb/Pb-Ca + электрохимическое формование (formation).
- Минеральный платтнерит — окисленные зоны гидротермальных свинцовых месторождений.
