# Материал: Ионная жидкость [EMIM][TFSI]

## Описание

[EMIM][TFSI] — 1-этил-3-метилимидазолий бис(трифлуорометилсульфонил)имид (CAS 174899-82-2) — гидрофобная комнатнотемпературная ионная жидкость (RTIL): ионный расплав соли [C₈H₁₁N₂]⁺[C₂F₆NO₄S₂]⁻ с температурой плавления −18…−16 °C, т.е. жидкая при комнатной температуре. Родоначальник класса — синтез Bonhôte и соавт. (EPFL), Inorg. Chem. 1996, 35(5), 1168–1178: «Hydrophobic, Highly Conductive Ambient-Temperature Molten Salts» с температурами плавления от −30 °C до комнатной — перспективные среды для электрохимических, фотоэлектрических и синтетических применений. Отличается низким давлением паров, высокой термической стабильностью, хорошей проводимостью и широким электрохимическим окном (Sigma-Aldrich).

**Класс:** органический жидкий электролит (ионная жидкость; исходная пометка «полимер» исправлена — материал является жидкой солью, а не полимером)
**Кристаллическая структура:** аморфный (жидкость без дальнего кристаллического порядка)

## Химический состав

- катион: [EMIM]⁺ — 1-этил-3-метилимидазолий, C₈H₁₁N₂⁺;
- анион: [TFSI]⁻ — бис(трифлуорометилсульфонил)имид, C₂F₆NO₄S₂⁻ (F₃C–SO₂–N⁻–SO₂–CF₃);
- суммарная формула C₈H₁₁F₆N₃O₄S₂, молярная масса 391.31 г/моль (proionic);
- чистота: >99.5 % battery grade (Rocolab); электронный сорт H₂O <20 ppmw (proionic, кулонометрический Карл Фишер).

## Физические свойства

- плотность 1520 кг/м³ (1.52 г/см³ при 20 °C — proionic electronic grade);
- температура плавления −18…−16 °C при 1.008 гПа (proionic);
- вязкость 39.4 мПа·с (cP) при 20 °C (proionic);
- теплопроводность ~0.12 Вт/(м·К) — типичный порядок ионных жидкостей 0.12–0.15 Вт/(м·К) (Lishchuk 2023, Sci Rep/HAL);
- низкое давление паров, нелетучая (RTIL, Sigma-Aldrich).

## Электрические свойства

- электропроводность 6.63 мС/см = 6.63 См/м при 20 °C (proionic, Rocolab battery grade);
- широкое электрохимическое окно (Sigma-Aldrich; конкретное значение в TDS цикла не приводится — обоснованный null для количественных полей сверх проводимости).

## Механические свойства

Не применимы: жидкое агрегатное состояние. Прочность, текучесть, модуль упругости, Пуассон, ударная и усталостная вязкости, твердости, удлинение — обоснованный null.

## Тепловые свойства

- Tm −18…−16 °C; рабочее использование до ~280 °C — выше зафиксирована существенная эскалация реактивной опасности (Hung 2023, Processes 11:2966);
- теплоёмкость, ТКЛР — null (количественные значения в подтверждённых источниках цикла отсутствуют).

## Эксплуатационные характеристики

- термическая стабильность при умеренных температурах + нелетучесть → применение в герметичных электрохимических системах;
- гигроскопичность управляемая: гидрофобный, но сорбирует следы воды — сортность по H₂O (<20 ppmw electronic grade) критична для батарей;
- реактивная опасность при перегреве выше 280 °C — контроль температуры обязателен (Hung 2023);
- токсичность: раздражает глаза и кожу (Sigma-Aldrich MSDS); обращение по стандартной практике для ИЖ.

## Технологии получения

- алкилирование 1-этилимидазола (метилимидазол + этилирующий агент) → [EMIM]X;
- метатезис с Li[TFSI] в водной фазе → гидрофобная ИЖ; очистка промывкой, сушкой, фильтрацией (электронный сорт — до <20 ppmw H₂O);
- промышленные производители: proionic, IOLITEC, Sigma-Aldrich, Rocolab.
