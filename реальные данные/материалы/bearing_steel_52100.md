# Материал: Подшипниковая сталь AISI 52100 (100Cr6 / ШХ15)

## Описание

Высокоуглеродистая хромистая подшипниковая сталь AISI 52100 (эквиваленты: 100Cr6/DIN, SUJ2/JIS, ШХ15/ГОСТ, GCr15/GB) по ASTM A295 — базовый конструкционный материал антифрикционных подшипников и прецизионных роликовинтовых передач. Химический состав: C 0.98–1.10 %, Cr 1.30–1.60 %, Mn 0.25–0.45 %, Si 0.15–0.35 %. Плотность 0.2830 lb/in³ (≈7830 кг/м³, CarTech). После закалки 830–845 °C (масло) и отпуска 150–160 °C равномерно достигает 60–64 HRC по всему сечению (глубокая прокаливаемость), модуль упругости 190–210 ГПа, модуль сдвига 80 ГПа. Структура — отпущенный мартенсит с ~6–8 об.% карбидов хрома, что обеспечивает контактную выносливость >2 ГПа Hertz-напряжений.

## Варианты применения (варианты_по_применению)

1. **направляющие_и_шпиндели** — винты (шпиндели) роликовинтовых передач: холоднотянутый пруток/труба, закалка до 60–64 HRC, шлифовка профиля.
2. **тела_качения_роликовинтовых_передач** — ролики planetary roller screw: пруток/проволока → резка/шлифовка → закалка; ресурс определяется контактной усталостью.
3. **гайки_роликовинтовых_передач** — гайки/обоймы: обработка резанием (до закалки — мягкий стан) + шлифовка резьбовых дорожек.
