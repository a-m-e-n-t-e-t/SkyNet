## Описание

Диоксид титана в мемристорном применении — бислой рутил-структурного TiO₂ толщиной 50 нм: высокоомный стехиометрический слой плюс проводящий дефицитный TiO₂₋ₓ, заключённые между Ti (верхний, 5 нм — источник вакансий) и Pt (нижний, 5 нм) электродами. Именно на этой структуре HP Labs доказал существование мемристора — четвёртого пассивного элемента электрических цепей, теоретически предсказанного Леоном Чуа в 1971 (Strukov, Snider, Stewart, Williams, Nature 453, 2008, «The missing memristor found», >15 000 цитирований). Физика переключения: вакансии кислорода V_O⁺⁺ в рутиле — мобильные двухзарядные доноры; положительное напряжение на Ti дрейфует их в стехиометрический слой, сдвигая границу раздела TiO₂/TiO₂₋ₓ (низкое сопротивление), отрицательное возвращает (высокое). Рутил P4₂/mnm — равновесная фаза TiO₂: анатаз и брукит метастабильны и необратимо переходят в рутил при нагреве. В репозитории материал — переключающий слой кроссбара izdelie_memristornye_matritsy (доля_массы 0.28; сама часть crossbar описана на HfO₂-подобной 1T1R архитектуре — связка отражает родительскую BOM).

## Химический состав и дефектная структура

Стехиометрия TiO₂ (рутил, фаза Ti(IV)); дефицит кислорода TiO₂₋ₓ (x ≤ 0.5) вводится либо выращиванием на Ti-электроде (кислород уходит в Ti-геттер), либо обработкой в восстановительной атмосфере (Ar/H₂). Дефекты — кислородные вакансии V_O (двухзарядные доноры Ti³⁺-центры) — дают n-тип проводимость, которая растёт на порядки с увеличением x. Предельные члены восстановления — фазы Magnéli TinO₂n−1 (n = 4–10) с плоскостями кристаллографического сдвига: Ti₄O₇ (x = 0.25) — металлоподобная проводимость ~1000 См/см при керамической коррозионной стойкости (RSC 2025). В мемристоре этот же ряд реализуется локально: проводящий канал ON-состояния — нанодомен с обогащением вакансиями.

## Физические свойства

- Плотность (рутил): 4.26 г/см³ (4260 кг/м³) — самая плотная из полиморфных фаз (анатаз ~3.9, брукит ~4.1); для сравнения Al₂O₃ 3.9, HfO₂ 9.7.
- Плавление: 1840 °C (таблицы рутила) — одна из самых тугоплавких оксидных фаз среди материалов микроэлектроники.
- Теплоёмкость: ~690 Дж/(кг·К) при 300 K (пересчёт стандартного мольного значения ~55 Дж/(моль·К) для рутила).
- Кристаллография: тетрагональный рутил P4₂/mnm (a = 4.594 Å, c = 2.959 Å); линейная цепочка TiO₆-октаэдров вдоль оси c даёт выраженную анизотропию k и КТР.
- Термодинамика: рутил — единственная равновесная фаза TiO₂ во всём интервале температур до плавления (анатаз/брукит — метастабильные).

## Механические свойства

- Упругие константы монокристалла рутила (Wachtman Jr. et al., NBS 1962, резонансный метод, 16 монокристаллов): C11 = 270, C12 = 196, C13 = 147, C33 = 478, C44 = 124, C66 = 164 ГПа.
- Поликристаллические модули (Voigt–Reuss): модуль Юнга 270–284 ГПа (номинал 277), объёмный 205–208, сдвига 131–138; коэффициент Пуассона 0.232.
- Прочность: в открытых datasheets (AZoM) прочность изгиба рутиловой керамики не нормируется (сильно зависит от пористости и зерна) — обоснованный null; для плёнок 50 нм механика описывается упругими константами.
- Твёрдость: ~6.5 по Моосу (тверже стекла, мягче корунда 9); Knoop/Vickers в доступных datasheets не нормируется — обоснованный null.
- Усталостная прочность: null (хрупкая керамика); для мемристорных устройств нормируется endurance переключения (~10⁴–10¹⁰ циклов по типу устройства) — характеристика ячейки, не материала.

## Тепловые свойства

- Теплопроводность: монокристалл рутила 12.5 Вт/(м·К) вдоль оси c и 8.7 перпендикулярно; поликристалл ~10.5 (усреднение); AZoM даёт диапазон 4.8–11.8 (рутил+анатаз, пористость). Номинал 10.5 — поликристаллическая плёнка. Для сравнения: SiO₂ 1.4, HfO₂ ~1.2 — TiO₂ на порядок лучше отводит тепло среди барьерных оксидов.
- КТР: 9.2×10⁻⁶ (‖c) / 7.1×10⁻⁶ (⊥c) 1/K; поликристалл ~8.2×10⁻⁶ — компенсация анизотропии в плёнках на Si (2.6×10⁻⁶) требует управления текстурой (упругое напряжение ~0.5–1 ГПа при остывании от 600 °C).
- Термостабильность: рутил устойчив до плавления 1840 °C; анатазные плёнки кристаллизуются в рутил при отжиге ≥~700 °C — температурный бюджет пост-обработки мемристорных стеков.

## Электрические свойства

Полупроводник с запрещённой зоной 3.0 эВ (рутил, эксперимент; анатаз 3.2). Электрофизика управляется стехиометрией: стехиометрический рутил — высокоомное OFF-состояние; TiO₂₋ₓ с вакансиями — донорная проводимость, предельная фаза Ti₄O₇ ~1000 См/см (10⁵ См/м) — поле электропроводность записано для ON-состояния мемристорного канала (номинал). Мемристивная петля: сопротивление непрерывно модулируется сдвигом границы TiO₂/TiO₂₋ₓ в плёнке 50 нм; биполярное непрерывное переключение (аналоговое) — основа нейроморфных crossbar-матриц; на/выкл отношение по типу устройства ~10³–10¹⁰ (типовой литературный диапазон RRAM). Диэлектрическая проницаемость рутила высокая (~86 перпендикулярно оси c, ~170 вдоль — справочные значения, среди больших для простых оксидов).

## Технологии получения

Руда → богатый TiO₂ концентрат (рутил ~98 %) → хлоридный процесс (TiCl₄) → оксигидролиз/хлорирование → пигментный TiO₂. Для микроэлектроники: плёночные методы — ALD (TiCl₄/H₂O или TTIP, 100–350 °C, конформные 50 нм слои), реактивное магнетронное напыление Ti в O₂, sol-gel; дефицит TiO₂₋ₓ — отжиг в Ar/H₂ или рост с градиентом кислорода на Ti-электроде. Мемристорная ячейка: Pt (5 нм, лифтофф) → TiO₂ (50 нм, ALD/напыление) → Ti (5 нм, геттер) → Pt/TiN верхний электрод; формовочный electroforming при первом цикле либо forming-free для низкоомных плёнок. Стоп: стехиометрия контролируется XPS (Ti³⁺/Ti⁴⁺ отношение — прямая мера концентрации вакансий).

## Аналоги и заменители

Когда нужен тот же биполярный непрерывный механизм с лучшей стойкостью: HfO₂/HfO₂₋ₓ (современный индустриальный стандарт RRAM — CMOS-совместим, тоньше, выше endurance; именно его описывает файл часть crossbar), Ta₂O₅₋ₓ (стабильность), Al₂O₃₋ₓ (формирующие слои). Для электрохимических электродов вместо Ti₄O₇: платино-титановые композиты или стеклоуглерод — дороже либо менее стойки. Для фотокатализа рутил заменяется на анатаз (выше активность) или легированный N/Si-TiO₂ для видимого диапазона.
