# Материал: 8YSZ

## Описание

8YSZ — циркония диоксид, стабилизированный 8 mol% оксида иттрия (8 mol% Yttria-Stabilized Zirconia), полностью кубическая фаза.

Полное наименование (как в CSV): `8YSZ`

**Класс:** керамика (твердый оксидный электролит)
**Кристаллическая структура:** кубическая (флюорит) — 8 mol% Y₂O₃ полностью стабилизируют кубическую фазу ZrO₂; по данным отраслевого справочника, «The 8 mol% composition represents the thermodynamic optimum for suppressing the tetragonal-to-monoclinic transformation while maintaining the oxygen vacancy concentration needed for useful ionic conductivity».

## Химический состав

ZrO₂ + 8 mol% Y₂O₃ (Zr₀.₉₂Y₀.₀₈O₁.₉₆); чистота ≥99.9% (предпочтительно 99.99%), суммарные примеси SiO₂+Al₂O₃+Fe₂O₃+TiO₂ ≤ 0.1 wt%.

## Физические свойства

- Теоретическая плотность: ≈6050 кг/м³ (6.05 г/см³, справочное значение для полностью плотного 8YSZ)
- Размер частиц порошка D50: 0.3–0.8 мкм (стандарт закупки для литья электролитных лент)
- Максимальная рабочая температура: ~1200°C

## Электрические (ионные) свойства

- Ионная проводимость по кислороду: 0.10–0.13 S/cm при 1000°C (таблица спецификации 8YSZ)
- Чистый ионный проводник: перенос O²⁻ по кислородным вакансиям решётки, электронная проводимость пренебрежимо мала

## Применение

Стандартный электролит SOFC/SOEC и материал тепловых барьерных покрытий (TBC) турбин. Для SOFC: плотная беспористая мембрана, литьё ленты (tape casting) или мокрый напыляемый осаждение с совместным спеканием с электродами при 1350–1450°C. Современные стеки (Bloom Energy, Fuel Cell Energy) используют плёнки электролита <10 мкм, что снижает ASR и позволяет работать при 700–750°C вместо традиционных 900–1000°C.
